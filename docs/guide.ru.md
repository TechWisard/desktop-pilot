# Руководство

## Первый запуск

На первом экране выбираются язык, автоматические изменения, автозапуск, учёт закреплений панели задач и свободная область для 1–8 ярлыков. Само открытие экрана не включает наблюдение и автозапуск. Кнопка **Начать работу** устанавливает программу для текущего пользователя, собирает каталог ярлыков и запускает фоновый процесс с треем. Можно оставить только наблюдение без автоматических изменений.

Пути определяются через Windows Known Folders, включая перенаправленный рабочий стол. Сканируется рабочий стол текущего пользователя и папки с ярлыками до трёх уровней вложенности. Ссылки файловой системы, распространённые папки исходников/зависимостей и архивы ярлыков пропускаются. Ярлыки общего рабочего стола и меню «Пуск» можно добавить вручную на вкладке «Приложения». Инвентаризация всех установленных программ не выполняется.

## Повседневное использование

- **Обзор:** текущие быстрые ярлыки, применение выбора и откат последнего изменения.
- **Приложения:** причины рейтинга, обновление каталога, добавление существующего ярлыка, правила «Всегда», «Автоматически», «Не добавлять».
- **Настройки:** русский/английский язык, пауза наблюдения или изменений, интервалы, область размещения, принятие геометрии и очистка статистики.
- **История:** локальный журнал изменений и ошибок.

Кнопка с флагом в правом верхнем углу доступна во всех разделах, включая первоначальную настройку. Выберите English или Русский: язык сразу меняется и сохраняется, остальные несохранённые настройки при этом не применяются. Для остальных изменений нажмите «Сохранить настройки». Правила приложений сразу передаются фоновому процессу; для изменения состава используйте «Применить сейчас». Смена правил или уменьшение числа мест может убрать больше ярлыков, чем обычный лимит замены. Если ручных закреплений больше доступных мест, изменения блокируются до устранения противоречия.

Перемещённый или переименованный быстрый ярлык закрепляется на выбранном месте. Удаление или перенос с рабочего стола запрещает автоматическое возвращение. При изменении содержимого файла программа прекращает управлять им. Проверка ручных действий выполняется примерно раз в минуту. Тематические папки не переупорядочиваются.

## Рейтинг

За каждый локальный календарный день:

```text
балл дня = 5 × min(запуски быстрых ярлыков, 20)
         + 2 × min(сеансы активного окна, 12)
         + 0,4 × ln(1 + min(активные секунды, 3600) / 60)
вес      = 2 ^ (-возраст в днях / период полураспада)
итог     = сумма(балл дня × вес)
```

Активное приложение проверяется раз в две секунды. Сеанс засчитывается после примерно десяти секунд активности; повторные сеансы в пределах двадцати минут объединяются. Бездействие и длинные перерывы наблюдения не засчитываются как активная работа. Порог бездействия по умолчанию — 120 секунд.

Активное окно не доказывает клик по ярлыку. Запуски через управляемые быстрые ярлыки учитываются отдельно. Один EXE с разными аргументами или рабочими каталогами имеет разные идентификаторы; неоднозначные сопоставления пропускаются. Для игр Steam учитывается уникальный каталог установки, для приложений Windows — уникальный идентификатор приложения.

На новом профиле нужны три разных дня активности. Первоначальное заполнение может занять все места. Затем пересмотр происходит раз в семь дней, при бездействии от пятнадцати секунд, вне полноэкранного приложения и перетаскивания мышью. Обычно меняется не более одного ярлыка; новый должен опережать прежний в 1,5 раза и минимум на 3 балла. Действующие ярлыки не исчезают только из-за очистки или устаревания статистики.

Ручные решения приоритетнее рейтинга. Закрепления панели задач исключаются по умолчанию. Для приложений, запускаемых через контекстное меню, файлы или горячие клавиши, задавайте **Не добавлять**: автоматически надёжно определить такое предпочтение нельзя.

## Размещение и восстановление

Используется сетка Проводника на основном мониторе. При первом запуске выбирается свободная область. Позиции существующих объектов включаются в общую операцию размещения, чтобы Проводник их не сдвинул. Резервируется целая ячейка сетки с местом для подписи. Длинные имена быстрых копий сокращаются; оригинальное имя и ярлык остаются в каталоге.

Изменение геометрии, неизвестный формат панели задач, занятая область или незавершённая операция останавливают размещение. Устраните указанную причину либо явно отключите фильтр панели задач. **Принять текущую геометрию** подтверждает текущую конфигурацию экранов, сохраняя позиции значков.

Перед изменением файлов сохраняются предыдущие/новые параметры и резервные байты. Откат проверяет контрольные суммы. При ручном изменении файла он останавливается без перезаписи. После отката автоматика приостанавливается. Запуск приложения выполняется через исходный ярлык Windows с его аргументами, рабочим каталогом и правилами повышения прав.

## Отключение и удаление

Распакуйте архив релиза и выполните:

```powershell
powershell -NoProfile -File .\disable.ps1
```

Скрипт останавливает фон, выключает наблюдение и автозапуск и откатывает управляемые изменения. С ключом `-KeepShortcuts` быстрые ярлыки сохраняются; для запуска им всё ещё нужны установленная программа и база.

Данные остаются для восстановления. После успешного завершения отката, когда управляемых ярлыков больше нет, можно удалить `%LOCALAPPDATA%\DesktopPilot` и ярлык Desktop Pilot в меню «Пуск». Не удаляйте эту папку при сохранённых быстрых ярлыках. Конфликт отката нужно устранить до удаления программы.

## Обновление

Закройте настройки и выберите «Выход» в трее. После завершения процесса скопируйте локальную папку данных в резервную копию. Замените только `desktop-pilot.exe` в `%LOCALAPPDATA%\DesktopPilot` файлом нового релиза и запустите его. Настройки и история хранятся отдельно. Обновление ручное; фоновой загрузки нет.

## Исходный код

| Модуль | Назначение |
| --- | --- |
| `model.rs` | Идентификаторы, настройки, рейтинг и стабильный выбор |
| `native.rs` | Windows Shell, геометрия, активность, панель задач |
| `engine.rs` | Каталог, управление ярлыками, операции, откат и наблюдение |
| `store.rs` | Локальная база SQLite |
| `setup.rs` | Первоначальная установка для пользователя |
| `ui.rs`, `i18n.rs`, `tray.rs` | Двуязычные настройки и трей |
