Desktop Pilot 0.2.63 предотвращает незаметную подмену выбранного пользователем режима работы при одновременном изменении настроек.

## Что изменилось

Режимы «Ручной», «Наблюдение» и «Автоматический» теперь согласуются как единое решение. Раньше, если пользователь менял режим в открытых настройках, а фоновый процесс или другая команда в это время изменяли режим, отдельные флаги могли объединиться в комбинацию, которую пользователь не выбирал. Например, после отключения Desktop Pilot попытка сохранить устаревший выбор «Наблюдение» могла завершиться сообщением об успехе, хотя фактически оставался ручной режим.

Теперь при конфликтующих изменениях сохранение безопасно отклоняется с понятным сообщением. Исходный режим, отключение, ручные закрепления, история, пользовательские файлы и отмена размещения не изменяются. Независимые настройки, не конфликтующие с режимом, по-прежнему сохраняются совместно; предусмотренная пауза сбора статистики не удалена.

Сценарии проверяются на настоящем сохранении настроек, SQLite и изолированных ярлыках: конфликт разных режимов, одновременная пауза сбора статистики, явное отключение и сохранение правил/истории/Undo.

Скачайте **DesktopPilot-0.2.63-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.63 makes operating-mode choices atomic when concurrent settings changes are merged. Previously, independently changed automation and collection flags could silently combine into an operating mode neither side chose, or a stale Observe save could be reported as successful after an explicit Turn off. Conflicting choices now produce an actionable error before any write or restart. Unrelated changes still merge normally; deliberate collection pause remains available.

Actual asynchronous Settings/SQLite regressions cover competing modes, collection pause, Turn off, preserved original files, manual rules, history and Undo. No added settings, dependencies, telemetry or background services. The Windows x64 executable is unsigned.
