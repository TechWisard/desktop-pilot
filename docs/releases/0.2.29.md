Desktop Pilot 0.2.29 быстрее подхватывает приложения, которые пользователь добавляет вручную во время работы программы.

## Что изменилось

После добавления исходного ярлыка в каталог запущенный фоновый процесс теперь обновляет свой список приложений при следующем опросе, не дожидаясь очередного шестичасового сканирования файлов и не требуя перезапуска. Это особенно важно для нового рабочего проекта или редкого приложения: при включённом учёте его можно распознавать сразу после добавления.

Добавление целой группы ярлыков отправляет одно локальное уведомление об изменении каталога. Повторный выбор неизменённого оригинала или уже управляемой быстрой копии не запускает ненужное обновление. Настройки, ручные правила, исключения, исходные файлы, расположение и безопасная отмена не меняются.

Регрессионные проверки выполнили настоящий фоновый цикл, Windows-парсер ярлыков и SQLite: на предыдущей версии два новых сценария завершились ошибкой, на исправленной прошли все 249 Rust-тестов, 28 нативных проверок и девять проверок публикации на обеих тестовых Windows. Синтетический предел обнаружения — семь секунд, это не измерение времени, сэкономленного реальными пользователями.

Скачайте **DesktopPilot-0.2.29-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.29 makes newly imported applications available to the running background monitor on its next poll, without waiting for a six-hour filesystem rescan or a restart. When activity tracking is enabled, newly added launch identities can be recognized promptly.

A single local catalog revision is committed per changed import batch. Reimporting an unchanged original or managed quick copy does not trigger a redundant reload. The original shortcuts, manual Always/Never choices, placement, history, Undo, privacy and scoring rules are unchanged. No dependencies, network service or telemetry were added.

The corrected Windows CI passes 249 Rust tests, 28 native integration checks and nine publication guards on both existing Windows runners. The bounded test is a software regression, not a human task-time measurement. Download the unsigned Windows x64 ZIP and verify SHA256SUMS.txt.
