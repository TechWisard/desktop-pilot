Desktop Pilot 0.2.15 сохраняет статистику работы с приложениями при резких изменениях системного времени.

## Что изменилось

Если часы Windows ошибочно переведены далеко вперёд, новый сеанс в одном приложении больше не удаляет недавние отметки использования других программ. После возвращения правильного времени краткое повторное обращение к приложению не превращается в ложный дополнительный сеанс только из-за утраченной отметки.

Очистка истории старше 90 дней теперь выполняется единственной защищённой процедурой SQLite, дополненной в 0.2.14. После очистки фоновый процесс согласует свою память с сохранёнными данными. Настройки, ручные закрепления и запреты, оригинальные ярлыки, расположение и откат не изменены.

Регрессионные тесты воспроизводят скачок на 120 дней, возвращение часов, повторный короткий сеанс и обычное истечение срока хранения на реальной логике SQLite и учёта активности. Это воспроизводимые искусственные события, а не испытание изменения часов на физическом ПК и не измерение экономии времени пользователя.

Скачайте **DesktopPilot-0.2.15-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы находятся в **SHA256SUMS.txt**. Программа работает локально без аккаунта, подписки и скрытой телеметрии. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.15 keeps other applications' recent usage-session checkpoints intact when the Windows system clock jumps far into the future. A genuine visit during a temporary clock error no longer removes unrelated session evidence and inadvertently manufactures new repeat visits when time is corrected.

Only the existing guarded SQLite housekeeping mechanism now expires time-based usage history. The background worker reloads its checkpoint cache after cleanup. The usual 90-day data retention remains; original shortcuts, manual Always/Never decisions, layout, undo and local-only processing are unchanged.

Regression tests exercise real SQLite, production usage recording, a simulated 120-day clock jump and correction, short repeat visits, and ordinary expiry. They do not constitute a physical Windows 11 clock test or a measurement of human task time.

Download **DesktopPilot-0.2.15-windows-x64.zip**, extract and run `desktop-pilot.exe`. Verify archives with **SHA256SUMS.txt**. The executable is unsigned.
