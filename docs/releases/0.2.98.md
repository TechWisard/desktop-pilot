# Desktop Pilot 0.2.98 — надёжное отключение автозапуска для именованных профилей

## Исправлено

Ранее сохранённая запись Windows «Автозагрузка» могла использовать параметр профиля в форме `--home=PATH`. Desktop Pilot уже поддерживал такую форму запуска, но при отключении автозапуска распознавал устаревшие записи только с формой `--home PATH`. В результате старая общая запись `DesktopPilot` могла оставаться в реестре и запускать программу при следующем входе в Windows даже после отключения этой настройки. При повторном включении могли оставаться два независимых запуска.

Теперь проверка старой записи понимает обе формы параметра и пути с пробелами, используя стандартный разбор командной строки Windows. **Чужие профили не затрагиваются:** противоречивые, повторяющиеся и незавершённые параметры не дают разрешения удалять запись. Сохранённая поддержка старых запусков из папки исполняемого файла остаётся неизменной.

Это точечное исправление. Настройки, статистика, ярлыки, правила «Всегда/Никогда», откат и локальное хранение данных не меняются. Новых разрешений, фоновых служб и телеметрии нет.

## Проверки

[Воспроизводимый сценарий](../research/2026-11-03-legacy-autostart-inline-profile.md) использует рабочую функцию распознавания старой записи и настоящий системный `CommandLineToArgvW` с разными вариантами путей, другим профилем, повторяющимися и отсутствующими параметрами. Он защищает границу удаления старой записи, не меняя реестр тестового компьютера.

Стандартная проверка выпуска включает Windows Server 2022/2025, `cargo fmt --check`, `cargo test --locked`, Clippy без предупреждений, сборку, нативные интеграционные сценарии, проверки выпуска и контроль архивов и SHA-256. Полноценный вход/выход пользователя на физической Windows 11 с изменением HKCU Run ещё не испытывался; экономия времени реальных пользователей не измерялась.

## Установка

Загрузите **DesktopPilot-0.2.98-windows-x64.zip**, распакуйте и запустите. Сверьте файл с **SHA256SUMS.txt**. Архив исходников: **DesktopPilot-0.2.98-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.98 fixes legacy Windows Run-entry cleanup for named profiles launched with `--home=PATH`. The previous matcher recognized only `--home PATH` when deciding whether the older shared startup entry belonged to the current profile. Turning off autostart could therefore leave a matching old entry behind, and enabling it could preserve an unnecessary duplicate.

Both spellings are now recognized using Windows command-line parsing, including correctly quoted paths with spaces. Ambiguous, missing or conflicting profile options cannot authorize deleting another profile's startup entry. Existing profile data, user rules, shortcuts, undo, local storage and privacy guarantees are unchanged.

The regression exercises the production matcher and Windows argument parser; real Windows 11 sign-in/reboot acceptance and human timing studies remain pending. The release workflow validates Windows builds, native integration, archive contents and SHA-256 before publication.
