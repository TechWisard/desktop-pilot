# Desktop Pilot 0.2.120 — точный поиск сохранённых веб-ярлыков

## Что изменилось

**Полный адрес сайта теперь находит именно тот ярлык, который открывает этот адрес.** Раньше при вставке URL в поиск раздела «Приложения» могли дополнительно показываться посторонние ярлыки, в заметках которых упоминалась та же ссылка, или другие страницы с более длинным адресом. Это затрудняло точное применение правил «Всегда» и «Никогда» к нужному ярлыку.

Теперь для полного HTTP(S)-адреса поиск сравнивает действительную цель запуска. Допускаются одинарные и двойные внешние кавычки. Регистр названия сайта и схемы несущественен, но регистр пути и параметров сохраняется, чтобы не перепутать разные страницы. Поиск по части домена без полного URL остаётся широким.

Исходные ярлыки, порядок рабочего стола, ручные правила, локальная история и настройки не изменяются. Фоновая телеметрия и новые службы не добавлены. Черновое упорядочивание рабочего стола (PR #98) в этот выпуск не включено.

## Проверки и ограничения

Регрессионный сценарий использует настоящие производственные поиск, ранжирование, каталог и SQLite Desktop Pilot. В синтетическом наборе сравниваются нужная веб-ссылка, посторонняя заметка, более длинный URL и страница с отличающимся регистром пути. Проверяются фильтры ручных правил и сохранность записей. Это проверка корректности совпадений, **не измерение экономии времени пользователей**.

[Windows CI для исходного изменения](https://github.com/TechWisard/desktop-pilot/actions/runs/42071876629): успешны Windows Server 2022 и 2025, Cargo tests, форматирование, строгий Clippy, сборка, нативные проверки и контроль публикации. Выпуск дополнительно должен пройти штатную проверку EXE, файлов и SHA-256. Непосредственные действия пользователя в Windows 11 и интерфейс при 100–200% масштабировании не проверялись.

[Исследование и воспроизводимые проверки](../research/2026-11-05-exact-web-address-search.md).

## Установка

Скачайте `DesktopPilot-0.2.120-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Проверяйте `SHA256SUMS.txt`; исходный архив — `DesktopPilot-0.2.120-source.zip`. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.120** finds a saved web shortcut by its exact HTTP(S) launch target when a complete address is pasted into Apps search. Notes and longer URLs no longer count as the requested destination; partial domain searches remain broad. Host and scheme are case-insensitive, while path and query remain distinct. Existing manual policies, desktop layout and local history stay unchanged. Production-path SQLite/catalog regressions and Windows CI check synthetic cases, not measured user time savings. The draft desktop organizer is not included.
