Desktop Pilot 0.2.24 уменьшает ненужные операции записи базы данных при повторной проверке неизменившихся ярлыков.

## Что изменилось

При обновлении списка программа больше не перезаписывает каждую сохранённую запись, если исходный ярлык и его проверенные свойства не изменились. Состояние закреплений панели задач также сохраняется повторно только при фактическом изменении. Особенно важно для больших библиотек ярлыков, когда фоновая проверка выполняется многократно.

Если пользователь действительно изменил значок исходного ярлыка или индекс значка, обновляется только соответствующая запись каталога. Временная недоступность оригинала по-прежнему учитывается, а повторные проверки без новых изменений не создают очередные записи.

Проверки настоящего механизма сканирования и SQLite показали сокращение операций обновления с **2 565 до 0** за пять неизменившихся проверок каталога из 512 элементов, с **65 до 1** при изменении одного значка из 64, с **99 до 0** при повторной проверке временно отсутствующего оригинала. Эти числа относятся только к операциям записи в тестах, а не к измеренной экономии времени, энергии или ресурса накопителя.

Ручные правила, порядок значков, история использования, исходные ярлыки и отмена действий сохранены. Новых зависимостей, настроек, служб и телеметрии нет.

Скачайте **DesktopPilot-0.2.24-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверьте контрольные суммы по **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.24 avoids rewriting SQLite catalog rows when a shortcut rescan finds no actual changes. Saved taskbar-pin verification is also written only if its value changes. Genuine icon metadata edits update only the affected app; temporary source outages still work as before.

Production-path Windows fixtures reduced measured SQLite updates from **2,565 to zero** across five unchanged scans of 512 shortcuts, **65 to one** after one icon change among 64 shortcuts, and **99 to zero** across three scans of an unchanged outage. These are deterministic database-operation counts, **not** user task-time, energy, SSD wear or startup latency measurements.

Manual choices, existing positions, sources, usage history and Undo remain intact. There are no new services, settings, dependencies, accounts or telemetry. Download **DesktopPilot-0.2.24-windows-x64.zip**, verify **SHA256SUMS.txt** and note that the executable is unsigned.
