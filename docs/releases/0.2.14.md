Desktop Pilot 0.2.14 защищает недавнюю историю использования от ошибочного удаления после резкого перевода системных часов вперёд.

## Что изменилось

Когда Windows сообщает, что между двумя проверками прошло более семи суток, Desktop Pilot теперь не считает это доказательством длительного отсутствия. Очистка истории использования и временных отметок сессий откладывается на ограниченный семидневный период. Если часы возвращаются назад, обычная очистка возобновляется. Это также относится к первому запуску обновлённого профиля с уже накопленной историей.

Обычное удаление данных старше 90 суток продолжает работать. Ограничение размера журнала событий и выполненных команд не приостанавливается. Ручные закрепления, запреты, исходные ярлыки, настройки и откат не изменяются.

Воспроизводимые тесты проверяют настоящий SQLite-профиль и последовательности резкого скачка вперёд, коррекции назад, обычного двухдневного перехода и обновления старого профиля. Семь суток — защитный инженерный интервал, а не доказанный срок восстановления часов или измеренная экономия времени пользователей.

Скачайте **DesktopPilot-0.2.14-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью; работа остаётся локальной без аккаунтов и скрытой телеметрии.

## English

Desktop Pilot 0.2.14 protects recently recorded usage history from accidental deletion following a large forward correction of the Windows system clock.

If more than seven days apparently pass between housekeeping checks, the program temporarily defers time-based deletion for a bounded seven-day observation window, including across restarts. A subsequent backward clock correction cancels that hold. A first housekeeping pass on an upgraded profile can also protect existing activity when its newest day appears unexpectedly old. Normal 90-day retention resumes after the window; count-bounded operational logs continue to be pruned.

This does not change manual decisions, original shortcuts, preferences, undo, local-only processing, or dependencies. The timings are conservative heuristics, not empirical human productivity measurements. Tests use the real SQLite Store with controlled clock inputs rather than changing the Windows system clock.

Download **DesktopPilot-0.2.14-windows-x64.zip**, extract and run `desktop-pilot.exe`. Check **SHA256SUMS.txt**. The executable is unsigned.
