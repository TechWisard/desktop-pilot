Desktop Pilot 0.2.27 защищает ручное размещение и исходные ярлыки при переименовании быстрой копии и временной недоступности программы или диска.

## Что изменилось

Если пользователь переименовал созданный Desktop Pilot быстрый ярлык, а исходный ярлык временно пропал, программа больше не принимает собственную копию за оригинал. Исходный путь, правило «Всегда» и ручное расположение сохраняются; после восстановления источника работа продолжается без лишней перестановки. Если пользователь также изменил цель копии, она не появляется как новое автоматически предложенное приложение.

Распознавание использует файловый идентификатор и учитывает ситуацию, когда старое имя уже занято другим файлом. Независимые дубликаты с отдельными файловыми идентификаторами по-прежнему могут восстанавливать исходный путь. Оригинальные файлы не переписываются. Новых настроек, зависимостей, телеметрии и сетевых служб нет.

Скачайте **DesktopPilot-0.2.27-windows-x64.zip**, распакуйте и запустите \`desktop-pilot.exe\`. Проверьте архив по **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.27 preserves manual desktop placement and original shortcut identity when a managed quick copy is renamed and the original temporarily disappears. The scanner no longer mistakes its own renamed shortcut for a new original, and an edited managed copy is not silently re-discovered as another automatically suggested application.

Stable file identity also protects against a replacement appearing at the old filename; genuinely independent duplicate originals still work. No source is rewritten. Manual rules, history, layout, Undo, offline operation and privacy settings remain unchanged. No new dependencies, telemetry or online services.

Download **DesktopPilot-0.2.27-windows-x64.zip** and verify **SHA256SUMS.txt**. The executable is unsigned. The regression fixtures are not measurements of user time savings or substitutes for physical Windows 11 testing.
