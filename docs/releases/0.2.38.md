Desktop Pilot 0.2.38 ускоряет добавление больших наборов ярлыков без изменения ручных правил и истории.

## Что изменилось

При массовом добавлении программа больше не сравнивает каждый новый ярлык со всем растущим каталогом. Соответствия строятся один раз на партию и обновляются вместе с ней. Это убирает квадратичный объём сравнений внутри транзакции базы данных.

Сохранены распознавание старых идентификаторов, разделение профилей запуска, защита быстрых копий, точные итоги импорта и отмена размещения. Неоднозначный ярлык по-прежнему получает отдельное сообщение, не мешая добавлению остальных. При ошибке записи партия откатывается целиком и может быть добавлена повторно.

Проверки используют настоящие наборы из 100, 1000 и 5000 ярлыков, повторный импорт, открытие сохранённого каталога при временно недоступной исходной папке и сбой записи SQLite. Числа времени в исследовательском отчёте относятся к тестовому серверу, а не к измеренной экономии времени людей.

Скачайте **DesktopPilot-0.2.38-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью. Новых настроек, зависимостей и телеметрии нет.

## English

Desktop Pilot 0.2.38 removes quadratic launch-identity comparisons from large manual shortcut imports. A transaction-local index preserves exact saved-ID precedence, unambiguous legacy matches, duplicate handling, original ownership, manual rules, history, accurate import counts and Undo. Failed database writes still roll back the entire batch and can be retried.

Production-path fixtures cover 100, 1,000 and 5,000 real inert shortcuts, saved-catalog search before source revalidation, duplicates, ambiguity and a forced SQLite write failure. CI timings are diagnostic measurements, not human productivity claims. No dependencies, persistent cache, settings or telemetry added. The Windows x64 executable is unsigned.
