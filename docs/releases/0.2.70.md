Desktop Pilot 0.2.70 — пауза наблюдения теперь действительно приостанавливает автоматическую перестановку ярлыков.

## Что изменилось

В адаптивном режиме пользователь может временно отключить сбор активности, сохранив выбранный режим для последующего возобновления. Ранее при таком сочетании настроек (automatic=true, collect=false) фоновая проверка могла переставить быстрые ярлыки по старой истории, несмотря на остановленное наблюдение. Окно настроек также могло отображать активную адаптацию.

Теперь **без разрешённого сбора активности автоматическая перестановка не выполняется**. В настройках отображается состояние «Наблюдение приостановлено» / «Observation paused». Ручное применение остаётся доступным, история и правила пользователя не удаляются. После возобновления наблюдения плановые изменения снова разрешены.

Дополнены испытания длительных переключений между проектами и исправления системных часов: восстановление одного сеанса не должно ошибочно изменять статистику другого. Эти сценарии не меняют выбранную ранее политику восстановления.

## Проверки и ограничения

Исправление сначала воспроизведено как отказ в регрессионном сценарии настоящего SQLite, изолированных файлов .url, рабочих функций выбора и применения. После исправления проверяются остановленная адаптация, возобновление, одна разрешённая замена, неизменность оригиналов и Undo. Выпуск формируется только после успешных штатных Windows 2022/2025 проверок (Rust, строгий Clippy, сборка, нативные сценарии и защита публикации). Отдельно не подтверждены физическая Windows 11 при 200% масштабе, настоящее отключение сетевых дисков и экономия времени реальных людей.

Для Windows x64 распакуйте **DesktopPilot-0.2.70-windows-x64.zip**, запустите desktop-pilot.exe. Контрольные суммы доступны в **SHA256SUMS.txt**. Программа не подписана цифровой подписью.

## English

Desktop Pilot 0.2.70 keeps unattended desktop rearrangement suspended while foreground activity collection is paused, even if an Adaptive preference remains stored for later. Settings correctly displays **Observation paused**. Explicit manual Apply still works; history, user-authored Always/Never policies, original shortcuts and Undo are preserved. Resuming collection restores normal scheduled adaptation.

Failure-first and corrected regression scenarios use actual SQLite Store, inert native .url shortcuts, production placement/Undo, and health-state rendering. Mixed-project clock-correction coverage also protects unrelated session history. Standard protected Windows Server 2022/2025 checks are required for release. No physical Windows 11 / disconnected network-drive usability or real-user task-time improvement is claimed. The x64 executable is unsigned.
