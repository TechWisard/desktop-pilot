Desktop Pilot 0.2.45 сохраняет выключенную фоновую работу при явных ручных действиях в настройках.

## Исправлено

Ранее выбор правила «Всегда» или «Не добавлять», нажатие «Применить сейчас» либо «Отменить» из открытых настроек могли пытаться запустить фоновый процесс даже после команды «Отключить Desktop Pilot». При повреждённом или недоступном пути установленной программы такое действие также не выполнялось, хотя сохранённые ярлыки и база данных были доступны.

Теперь состояние отключения проверяется под блокировкой запуска. Если фоновая работа отключена, запрошенная пользователем команда выполняется непосредственно через существующую проверенную логику, без автозапуска, скрытого сбора статистики или переустановки исполняемого файла. Применение и отмена сохраняют исходные ярлыки и проверяют принадлежность файлов. Возобновление фоновой работы остаётся отдельным явным действием.

Регрессионная проверка использует реальные SQLite, ярлык .url, созданную копию, правило Never, ручное применение и Undo при намеренно недоступном пути установки. Другие режимы и защитные проверки сохранены.

Архив **DesktopPilot-0.2.45-windows-x64.zip** содержит Windows x64-программу; контрольные суммы в **SHA256SUMS.txt**. Исполняемый файл не подписан. Новых зависимостей, настроек и телеметрии нет.

## English

Desktop Pilot 0.2.45 keeps background tracking turned off when the user explicitly edits a shortcut rule, applies a manual change, or uses Undo. Previously those actions attempted to restart the background process even after Turn off, and could fail if the installed executable path was obstructed.

Disabled profiles now execute explicit actions directly through the existing guarded command path. No monitoring, automatic placement, installation, or startup is silently resumed. Original shortcuts, history, manual choices and file-safe Undo remain protected. Active profiles still use the existing queued background-command path. No new dependencies, configuration, or telemetry. The Windows x64 executable is unsigned.
