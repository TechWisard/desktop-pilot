# Desktop Pilot 0.2.109 — привычные ярлыки остаются на месте

## Что изменилось

**Можно полностью запретить автоматические замены уже размещённых ярлыков, сохранив заполнение свободных мест.** В настройках частоты пересмотра параметр «Обычный предел замен за один пересмотр» теперь допускает **0**.

Это подходит для рабочего стола с устоявшимся расположением, когда программа должна предлагать новое полезное приложение только в действительно освободившееся место, а не менять местами знакомые значки после очередного изменения активности. Настройка не отключает сбор разрешённой пользователем статистики и не запрещает последующую адаптацию после освобождения места.

Команды пользователя «Всегда», «Никогда» и намеренное уменьшение числа мест продолжают действовать. Существующие установки сохраняют прежний предел замен: по умолчанию **1**, без принудительной смены поведения. Файлы оригинальных ярлыков, история, настройки и откат не удаляются.

## Проверка

Регрессионные сценарии работают с настоящей функцией выбора, сохранением конфигурации, SQLite, исходными Windows `.url`-ярлыками, предварительным просмотром и применением изменений. Проверяется отсутствие ненужной замены при новом высоком рейтинге, заполнение одной вакансии, действие явного ручного запрета, а также сохранность байтов, идентичности файла и позиции ранее размещённых ярлыков.

[Исследование, пользовательские сообщения, сценарии и ограничения](../research/2026-11-04-zero-replacements.md). Исправление проверено штатным CI для Windows Server 2022 и 2025: тесты Rust, строгий Clippy, форматирование, сборка и нативные проверки. Синтетический тест не означает подтверждённую экономию времени реальных пользователей. Для Windows 11 и масштабирования интерфейса 100–200% остаются физические приёмочные проверки.

## Установка

Скачайте **DesktopPilot-0.2.109-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверьте архив по **SHA256SUMS.txt**. Исходный код опубликован в **DesktopPilot-0.2.109-source.zip**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.109 lets users set **Normal replacement limit per review** to **0**. This protects familiar, already placed quick shortcuts from automatic displacement while still allowing qualifying new apps to fill genuinely vacant places. Explicit **Always/Never** choices and slot reductions retain precedence. The previous default of one replacement is unchanged; saved settings and shortcuts require no migration.

Regression tests exercise production ranking and selection, real Settings merge, SQLite state, Windows `.url` files, preview, apply and manual exclusion, including preservation of established file bytes, identities and positions. Standard Windows Server 2022/2025 CI includes Rust tests, strict Clippy, formatting, locked build and native integration. These synthetic checks do not demonstrate human productivity gains or replace physical Windows 11/DPI acceptance tests. See [research and acceptance boundaries](../research/2026-11-04-zero-replacements.md).
