# Desktop Pilot 0.2.97 — более спокойный рабочий стол и надёжный выбор профиля

## Что улучшено

**Без неожиданного обновления ярлыков после возвращения пользователя.** Автоматическая проверка могла начаться во время бездействия, но дойти до публикации подготовленных ярлыков, когда пользователь уже вернулся к работе. Теперь перед изменением рабочего стола повторно проверяются условия бездействия и полноэкранного режима. Если момент неподходящий, изменение откладывается, незавершённые временные файлы удаляются, а последующая возможность проверки сохраняется.

**Запуск нужного профиля из ярлыка Windows.** Теперь `--home="C:\\Профили\\Проект"` и `--home=C:\\Профили\\Проект` (при корректном экранировании пути командной строкой), а также варианты `--home PATH`, обрабатываются единообразно. Для пути с пробелами Windows-ярлык должен передавать значение как один аргумент. Аналогично поддерживаются `--out=FILE.json` и `--out FILE.json`. Повторяющиеся параметры, не-JSON файлы отчётов и перезапись без `--replace-out` по-прежнему запрещены.

Настройки, статистика использования, ручные правила, расположение ярлыков, откат, локальное хранение и отсутствие скрытой телеметрии сохранены.

## Проверки и ограничения

[Проверка отложенной автоматической перестановки](../research/2026-11-03-quiet-staging-boundary.md) выполняется на штатном коде размещения, реальных файлах ярлыков Windows и SQLite, включая сценарий возврата пользователя во время подготовки и откат.

[Проверка выбора профиля](../research/2026-11-03-launcher-equals-profile.md) использует штатный разбор аргументов и `profile::home`, повторно открывает сохранённую SQLite-базу и контролирует отсутствие подмены профиля. Все тесты синтетические; фактическая экономия времени у людей не измерялась.

Сборка и публикация допускаются только после штатных Windows Server 2022/2025 тестов, строгих проверок Rust, нативных интеграционных сценариев и сверки готовых архивов и SHA-256. Физическая проверка интерактивного рабочего стола Windows 11 и масштабирования интерфейса остаётся отдельной задачей.

## Установка

Скачайте **DesktopPilot-0.2.97-windows-x64.zip**, распакуйте и запустите. Сверьте контрольные суммы по **SHA256SUMS.txt**. Исходники — **DesktopPilot-0.2.97-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.97 rechecks idle and fullscreen conditions immediately before publishing staged desktop shortcuts. If the user returns, an automatic layout change is deferred, temporary staging files are cleaned up, and the next review remains available.

Windows launchers can now use `--home=PATH` and `--out=FILE.json` as well as the existing separated options. The same duplicate-option detection, JSON-only output restriction, overwrite consent, saved profile selection and local SQLite data continue to apply.

Regressions exercise production placement/filesystem/SQLite and real profile selection, not a simplified recommendation simulator. Standard Windows CI, native fixtures and release integrity checks protect publication. Physical Windows 11 interactive tests and real-user time savings have not been established.
