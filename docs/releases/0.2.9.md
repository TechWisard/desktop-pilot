Desktop Pilot 0.2.9 устойчивее к кратковременным блокировкам локальной базы статистики и понятнее объясняет неожиданные остановки фоновой работы.

## Что изменилось

- **Меньше внезапных остановок:** если SQLite ненадолго занята другой записью, сохранение подтверждённого использования автоматически повторяется, но не более трёх попыток. Каждая попытка охватывает всю транзакцию, поэтому повтор не удваивает время или количество сеансов. Неисправности диска, повреждения данных и другие ошибки не скрываются и не повторяются бесконечно.
- **Причина сбоя видна на главной странице:** если фоновый процесс остановился с сохранённой ошибкой, отображается причина, предлагается просмотреть историю и возобновить работу. Намеренное отключение не выглядит аварией.
- Ярлыки, ручные позиции, настройки, накопленная история, безопасный откат и локальная работа сохраняются. Скрытая телеметрия и новые сетевые службы отсутствуют.

## Проверки

[Windows CI для изменений](https://github.com/TechWisard/desktop-pilot/actions/runs/40331163215): Windows 2022 и Windows 2025, 170 тестов Rust, форматирование, Clippy без предупреждений, сборка, 28 нативных проверок и защита выпуска. Новые тесты используют настоящие SQLite-транзакции с конкурирующим подключением, а не упрощённую модель. Выпускной процесс дополнительно проверяет оптимизированный EXE, Windows x64, архивы и SHA-256. Физический Проводник Windows 11, диск с настоящим отказом и экономия времени реальных пользователей не измерялись.

Для установки скачайте **DesktopPilot-0.2.9-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Для контроля целостности предназначен **SHA256SUMS.txt**. Предварительный EXE не подписан.

## English

Desktop Pilot 0.2.9 makes local activity tracking more resilient to brief database write contention and gives users a clear explanation when background work unexpectedly stops.

- **Fewer unexpected stops:** transient SQLITE_BUSY/SQLITE_LOCKED errors on a complete usage write get up to three bounded attempts, preserving one committed set of seconds and sessions without duplicating activity. Persistent and non-lock failures are still reported, not silently bypassed.
- **Actionable Home error state:** a saved unexpected worker failure now appears on Home with access to History and Resume. Explicit disabling remains clearly distinct from a crash.
- Shortcuts, manual positions, preferences, local history and reversible changes are preserved. No additional telemetry, cloud account, network service or schema migration.

[Windows change verification](https://github.com/TechWisard/desktop-pilot/actions/runs/40331163215) passed formatting, 170 Rust tests, Clippy warnings denied, build, 28 native checks and release guards on Windows 2022/2025. New tests exercise genuine concurrent SQLite transactions. Publication separately verifies the release EXE, archives and SHA-256 digests. Physical Windows 11 Explorer interaction, genuine disk failures and human time savings were not measured.

Download **DesktopPilot-0.2.9-windows-x64.zip**, extract and launch `desktop-pilot.exe`. Verify the archives using **SHA256SUMS.txt**. The preview binary is unsigned.
