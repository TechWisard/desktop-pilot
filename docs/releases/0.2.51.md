Desktop Pilot 0.2.51 защищает отключённую фоновую работу от запоздавшего запуска процесса.

## Что исправлено

В прежнем варианте процесс, запущенный напрямую с `--background` (в том числе по сохранившейся записи автозапуска Windows), мог сбросить флаг остановки даже после явной команды «Отключить». Теперь начало фоновой сессии проверяет сохранённый запрет внутри транзакции SQLite и завершается без изменений при выключенном режиме. Проверка выполняется после захвата блокировки конкретного фонового экземпляра.

Одновременно явная команда «Включить» выдаёт разрешение **до** запуска дочернего процесса. Если запуск не удался, прежний режим «Отключено» восстанавливается и незавершённая сессия получает сигнал остановки. Это сохраняет привычное включение через настройки без скрытой активации после отказа.

Регрессии используют настоящую базу SQLite, исходный URL-ярлык, историю, настройки и исходный код входа в фоновый режим. Нативная проверка дополнительно запускает настоящий Windows EXE с `--background` после «Отключить», затем подтверждает отсутствие нового процесса и проверяет явное возобновление. Позиции, история, исходные ярлыки, ручные правила и Undo сохранены. Новых параметров, служб, зависимостей или телеметрии нет.

Скачайте `DesktopPilot-0.2.51-windows-x64.zip`; контрольные суммы приведены в `SHA256SUMS.txt`. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.51 prevents a delayed direct `--background` entry, including a stale Windows startup invocation, from re-enabling tracking after an explicit Turn off. The background singleton and SQLite admission gate now reject disabled profiles without resetting their shutdown state or changing saved data. Explicit Start authorizes its child before launch and restores the disabled state if startup fails.

Production-path regressions check preserved rules, usage, original shortcuts, and restart/failed-start semantics. The native Windows integration executes the installed-style background command after disabling, then verifies that a subsequent explicit resume still works. No new dependencies, settings, services or telemetry. The Windows x64 binary is unsigned.
