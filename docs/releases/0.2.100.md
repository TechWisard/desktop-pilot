# Desktop Pilot 0.2.100 — точнее рекомендации после прерываний

## Исправлено

**Временное отсутствие одного из профилей запуска больше не искажает статистику другого.** Если несколько ярлыков разных профилей используют общую папку приложения, временно недоступный ярлык по-прежнему учитывается при проверке неоднозначности работающего процесса. Desktop Pilot не приписывает всю активность оставшемуся профилю и не создаёт на этой основе неподтверждённые рекомендации. Если у программ действительно разные проверенные папки запуска, обычный учёт сохраняется.

**Коррекция системного времени назад больше не завершает учебный сеанс искусственно.** Неполные отрезки работы по разные стороны значительной коррекции часов не склеиваются в один подтверждённый пятиминутный сеанс. Уже завершённое обучение и короткие корректировки сохраняются.

Ручные правила «Всегда» и «Никогда», исходные ярлыки, сохранённое размещение, история, безопасная отмена изменений и автономная работа остаются без изменений. Скрытая телеметрия не добавлена.

## Проверка

[Сценарии нескольких профилей](../research/2026-11-03-shared-root-profile-attribution.md) используют нативные ярлыки Windows `.lnk`, реальную логику сопоставления, SQLite, запись подтверждённого использования и предварительный выбор. На старой логике Windows CI воспроизвёл ошибочное приписывание использования; исправление сохраняет корректные случаи с отдельными корнями. [Сценарии коррекции часов](../research/2026-11-03-learning-clock-rewind-partial.md) проверяют сохранение и восстановление накопленного обучения.

Штатный выпуск проверяет форматирование, Rust, строгий Clippy, сборку, нативные интеграционные сценарии и защиту публикации на Windows Server 2022/2025. Это синтетические проверки правильности, не измерение экономии времени пользователей. Физический Windows 11, интерактивное поведение Проводника и масштабирование 100–200% ещё требуют отдельного испытания.

## Установка

Загрузите **DesktopPilot-0.2.100-windows-x64.zip**, распакуйте и запустите. Сверьте SHA-256 по **SHA256SUMS.txt**. Исходники: **DesktopPilot-0.2.100-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.100 improves the accuracy of local adaptation in two interruption scenarios. A temporarily unavailable shortcut with the same observed process root as another saved launch profile no longer makes the remaining profile appear uniquely identified. Where roots are genuinely distinct, usage attribution continues as before. Separately, a large backward system-clock correction cannot combine incomplete foreground-learning fragments into one qualifying session.

Explicit Always/Never rules, original shortcuts, saved positions, Undo and local-only operation are preserved. Regressions use actual Windows shortcut parsing, SQLite, the production selection path and the learning gate. Standard Windows checks validate the changes and release packaging; interactive Windows 11 use and human time savings have not been measured.
