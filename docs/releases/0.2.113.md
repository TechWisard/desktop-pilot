# Desktop Pilot 0.2.113 — не меняет ярлыки, пока удерживается клавиша

## Что улучшено

**Автоматическое изменение быстрых ярлыков теперь откладывается, пока удерживается любая обычная клавиша, а не только Ctrl, Shift, Alt и Win.** Это важно при удержании пробела для перемещения холста в редакторе, стрелок для навигации и других клавиш, когда Windows не сообщает новых событий нажатия. До исправления проверка могла счесть компьютер бездействующим через 15 секунд и разрешить перестановку, хотя клавиша продолжала удерживаться.

Проверка использует штатный признак физически нажатой клавиши Windows. Сохраняются прежние запреты при удержании кнопок мыши, активном или полноэкранном окне, повторная проверка перед записью и приоритет ручных правил. Пока пользователь работает, предварительная проверка бездействия позволяет не выполнять расширенный перебор клавиш. Не добавлены новые службы, перехваты, настройки или сбор персональных данных; исходные ярлыки, история и возможность отмены не меняются.

## Проверки

Тест непосредственно вызывает ту же функцию проверки удерживаемых клавиш, что и рабочая программа. Синтетические состояния включают пробел, стрелки, букву, F1, все прежние модификаторы, кнопки мыши и случаи без нажатий. Связанные интеграционные сценарии на настоящих механизмах SQLite и размещения проверяют отмену автоматического изменения, когда поздняя проверка перестаёт считать компьютер свободным.

[Исследование, исходники и ограничения](../research/2026-11-04-held-ordinary-keys.md). Исправление прошло штатные проверки ветки на Windows Server 2022 и 2025: форматирование, тесты Rust, строгий Clippy, сборку, нативные сценарии и защиту выпуска. Проверки физического Windows 11 с отключённым автоповтором клавиш, масштабирования интерфейса 100–200% и фактической экономии времени пользователей не проводились. Дополнительная функция упорядочивания рабочего стола остаётся отдельным черновиком.

## Установка

Скачайте `DesktopPilot-0.2.113-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Сверьте архив с `SHA256SUMS.txt`. Код выпуска — в `DesktopPilot-0.2.113-source.zip`. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.113** now defers automatic shortcut layout changes while **any standard keyboard key is physically held**, rather than only Ctrl, Shift, Alt or Win. The idle input timestamp alone cannot reliably represent an ongoing Space, arrow, letter or function-key hold when repeat events are absent. The normal 15-second inactivity threshold, existing mouse/fullscreen/foreground safeguards, pre-commit recheck, explicit user decisions, sources, history and Undo remain unchanged.

The production key-state predicate is regression-tested against synthetic held and released states; existing real SQLite/placement scenarios verify deferral when the late quiet check is denied. Public Windows Server 2022/2025 checks passed on the source branch. These results do not replace physical Windows 11 keyboard/DPI acceptance or demonstrate measured human productivity savings. No new hooks, services, telemetry or network dependencies are introduced.
