Desktop Pilot 0.2.41 исправляет отображение последнего импорта при повторном выборе уже известных ярлыков.

## Что исправлено

После добавления одной группы ярлыков, затем другой, повторное добавление ярлыка из первой группы могло оставить на экране «Последний импорт» результаты второй группы. Это происходило, когда повторный импорт правильно не изменял базу данных: интерфейс ошибочно использовал старый фильтр.

Теперь список сразу отражает **последние выбранные ярлыки**, в том числе уже существующие в каталоге и ранее созданные быстрые копии. Для этого обновляется только фильтр в памяти; лишнее перечитывание каталога SQLite не требуется. Ручные правила, история, исходные файлы, позиции и отмена размещения не меняются.

Регрессионный тест воспроизводит несколько последовательных импортов на настоящем коде обработки ярлыков, SQLite и интерфейса, проверяет неизменность сохранённых данных и работу отмены. Это проверка корректности, а не измерение экономии времени реальных пользователей.

Скачайте **DesktopPilot-0.2.41-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы находятся в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью. Новых зависимостей, настроек и телеметрии нет.

## English

Desktop Pilot 0.2.41 keeps the **Last import** list in sync with the shortcuts most recently selected, even when all of them already exist in the catalog or include a managed quick copy. Previously a no-op import could leave the results from an earlier selection visible because the in-memory filter did not track its latest selected IDs.

Only the filtered view is invalidated; unchanged SQLite catalogs are not reloaded. Manual rules, history, original shortcut bytes, desktop positions and Undo remain intact. Regression coverage exercises real asynchronous import, native shortcut parsing, SQLite and the Settings filter. No dependencies, settings or telemetry were added. Windows x64 binaries are unsigned.
