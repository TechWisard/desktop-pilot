# Desktop Pilot 0.2.114 — поиск приложений по скопированному пути

## Что улучшено

**В списке приложений можно найти уже известный ярлык, вставив путь, скопированный из Проводника Windows.** Поиск распознаёт окружающие двойные кавычки и обратные или прямые разделители пути. Это упрощает поиск нужного профиля запуска, когда несколько приложений имеют одинаковые имена, и позволяет быстрее добраться до ручного правила «Всегда», «Авто» или «Никогда».

Изменён только механизм поиска в интерфейсе. Пути, идентификаторы и параметры запуска, избранные приложения, пользовательские правила, история наблюдений и файлы рабочего стола не меняются. Результаты по-прежнему можно фильтровать и сортировать, а поиск по названию сохраняет прежний приоритет.

## Проверки и ограничения

Регрессионный тест использует реальное хранилище SQLite и рабочий путь поиска в интерфейсе. Он проверяет скопированные пути с кавычками, оба вида разделителей, поиск по исполняемому файлу, сохранение фильтра «Никогда», отсутствие ложного совпадения и привычную сортировку по имени.

Код также подлежит штатным проверкам Windows Server 2022/2025: тесты Rust, форматирование, строгий Clippy, сборка, нативные интеграционные сценарии и защитные проверки выпуска. Синтетические данные не подтверждают экономию времени реальных пользователей. Физическая приёмка интерфейса Windows 11 при масштабировании 100–200% не проводилась. Черновая функция упорядочивания рабочего стола остаётся вне выпуска.

## Установка

Скачайте `DesktopPilot-0.2.114-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Сверьте контрольную сумму архива с `SHA256SUMS.txt`. Исходники опубликованы отдельно в `DesktopPilot-0.2.114-source.zip`. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.114** finds existing app shortcuts when you paste quoted paths copied from Windows File Explorer. Backslash and forward-slash path separators are treated equally for **search only**. This makes it easier to distinguish similarly named apps and launch profiles before changing manual placement rules. Stored paths, launch identities, history, rules and files are untouched.

SQLite-backed catalog regression tests cover quoted and unquoted paths, separator variants, executable targets, manual exclusions, negative matches and relevance ordering. The Windows CI and release packaging must pass before publication. Synthetic tests do not establish measured user productivity or replace a physical Windows 11 UI/DPI acceptance test.
