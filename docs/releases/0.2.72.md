Desktop Pilot 0.2.72 — новое расписание адаптации соблюдается даже при уже запланированной фоновой проверке.

## Что исправлено

Если фоновая проверка уже стала допустимой по прежнему периоду (например, каждые 7 дней), пользователь может увеличить интервал до 30 дней до начала самой перестановки. Ранее проверка могла всё равно изменить рабочий стол, хотя новое расписание ещё не разрешало перестановку.

Теперь непосредственно перед размещением программа повторно читает сохранённое расписание, состояние рабочего стола, готовность наблюдения и разрешения под существующей блокировкой изменений. Если новый период ещё не наступил, отложенная проверка отменяется и время последней проверки не изменяется. При возвращении прежнего периода обычная проверка снова доступна.

Ручное «Применить» работает независимо от расписания. Оригинальные ярлыки, «Всегда»/«Никогда», история и Undo сохранены. Новых процессов, сетевых зависимостей и телеметрии нет.

## Проверки и ограничения

До исправления на Windows Server 2022/2025 специальный регрессионный тест выявил преждевременную перестановку. После исправления штатные тесты Rust, строгий Clippy, форматирование, сборка, нативные сценарии и защитные проверки публикации прошли на обеих системах. Тест использует реальные SQLite, парсинг безопасных ярлыков .url, производственные функции выбора, применения и Undo. Сведения и ссылки сохранены в `docs/research/2026-10-31-queued-review-interval.md`.

Синтетический порядок событий не доказывает экономию времени реальных людей. Отдельно нужны физическая Windows 11 при масштабе 200%, настоящие отключения сетевых каталогов и длительная смена проектов.

Для Windows x64 распакуйте **DesktopPilot-0.2.72-windows-x64.zip**, запустите `desktop-pilot.exe`, проверьте SHA-256 по **SHA256SUMS.txt**. Программа не подписана цифровой подписью.

## English

Desktop Pilot 0.2.72 honours a changed automatic-review interval before placing shortcuts. A review queued under a former seven-day cadence will not rearrange the desktop after the user saves a longer interval such as 30 days. The worker rechecks the persisted schedule, state, observation readiness and permissions under the same Windows placement mutex; a no-longer-due review is cancelled without advancing its timestamp.

Manual Apply, original shortcuts, Always/Never rules, history and Undo remain intact. No telemetry, extra workers or remote dependencies. The failure-first Windows 2022/2025 regression reproduced the previous unintended replacement on actual SQLite and native inert .url shortcuts; the correction passed standard Windows Rust, strict Clippy, native and release-guard checks. These synthetic events do not measure human productivity. Physical Windows 11 high-DPI, network disconnections and long-term adaptation remain unverified. Windows x64 executable is unsigned.
