Desktop Pilot 0.2.62 исправляет обработку запоздалых ответов фонового процесса после остановки или перезапуска.

## Что изменилось

Если обновление ярлыков или другая команда была отменена при завершении фоновой работы, позднее сообщение старого обработчика больше не может заменить запись об отмене ложным успешным результатом. Повторные сообщения о завершении одной команды также не меняют уже зафиксированный результат и не создают лишние события в истории.

Проверки охватывают два реальных пути отмены — восстановление SQLite-очереди после перезапуска и явное отключение через настройки, а также обычное завершение и повторное получение результата. Управление исходными ярлыками, история использования, ручные правила и Undo не менялись.

Скачайте **DesktopPilot-0.2.62-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы включены в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.62 keeps canceled and already completed background commands final. A delayed response from an earlier worker cannot overwrite a restart/Turn off cancellation with a false success or add duplicate audit events. The production SQLite command queue remains transactional. Tests cover genuine recovery and Turn off paths, normal completion, unclaimed commands and repeated replies.

No new dependencies, settings, background services or telemetry. Existing shortcut files, user rules, usage history and Undo remain unchanged. The Windows x64 executable is unsigned.
