Desktop Pilot 0.2.55 — неверная строка больше не блокирует добавление остальных ярлыков.

## Что изменилось

Раньше одна опечатка, относительный путь или неподдерживаемый файл в списке вставленных путей останавливали всю операцию. Теперь Desktop Pilot проверяет каждый путь отдельно: корректные `.lnk` и `.url` добавляются, ошибочные строки остаются в диалоге с объяснением для исправления.

При частичном успехе сообщение показывает и число добавленных ярлыков, и предупреждение об ошибках. Дубли не создаются; неподдерживаемые и относительные пути не передаются системному обработчику ярлыков.

Исходные файлы, ручные правила, позиции, история и Undo сохранены. Нет новых настроек, служб, зависимостей или телеметрии. Windows x64 EXE не подписан цифровой подписью.

## English

Desktop Pilot 0.2.55 imports valid shortcuts from a pasted multi-line selection even when other entries are malformed or unsupported. Each invalid path is rejected before native shortcut decoding and retained for correction. Mixed-result feedback now reports both successful additions and failures. Duplicate handling, saved preferences, original files, history and Undo remain protected. No new settings, dependencies or telemetry. The Windows x64 executable is unsigned.
