# Desktop Pilot 0.2.86 — безопасное обновление JSON-отчётов

## Что изменилось

Desktop Pilot больше не перезаписывает существующий файл `.json` только потому, что его путь передан параметру `--out`. Например, `settings.json` может содержать настройки другой программы, а не ранее созданный отчёт Desktop Pilot. Теперь экспорт в существующий JSON-файл по умолчанию отклоняется **до открытия профиля и любых операций с ярлыками**. Для нового отчёта достаточно указать свободное имя:

```powershell
desktop-pilot.exe --inspect --out report-2026-11-02.json
```

Для намеренной перезаписи ранее созданного отчёта добавьте `--replace-out`:

```powershell
desktop-pilot.exe --inspect --out report.json --replace-out
```

Флаг не действует отдельно от `--out`. При обычном экспорте Windows не разрешает замену файла и на последнем этапе сохранения: даже если кто-то создал целевой JSON после предварительной проверки, его содержимое останется нетронутым. С явным разрешением сохраняется прежняя атомарная публикация. Внутренние диагностики `last-error.txt`, история, ручные правила, исходные файлы, откат, локальная работа и защита профиля не изменены. Новых служб, телеметрии и зависимостей нет.

## Проверка

Регрессионные сценарии вызывают реальный обработчик отчётов Windows и исполняемый файл на изолированных тестовых файлах: чужой JSON нельзя заменить случайно; файл, появившийся между проверкой и записью, остаётся неизменным; новый `.JSON` создаётся; экспорт с `--replace-out` работает. Сохраняются существующие проверки синтаксиса CLI, SQLite, отказа от перезаписи ярлыков и восстановления после прерываний.

Подробные доказательства, пределы и исходники исследования: [сценарии JSON и согласия](../research/2026-11-02-existing-json-consent.md). Windows CI выполняет Rust-тесты, форматирование, строгий Clippy, нативные интеграционные проверки, сборку и проверки выпуска на Windows Server 2022 и 2025. Физический рабочий стол Windows 11, масштабирование UI и экономия времени реальных пользователей этими тестами не подтверждаются.

Для Windows x64 распакуйте **DesktopPilot-0.2.86-windows-x64.zip** и запустите `desktop-pilot.exe`. Контрольные суммы находятся в **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.86 refuses to replace an existing `.json` file through `--out` by default. An unrelated application's JSON settings file can no longer be accidentally overwritten by a diagnostic export. Choose a new JSON filename, or deliberately add `--replace-out` for repeatable report exports. The Windows publication step itself rejects conflicting files created after preflight, while explicit overwrite retains atomic replacement. Existing internal error logs, local history, saved settings, manual choices, original shortcuts and Undo are unchanged.

Production-path native and Rust fixtures cover existing JSON files, an interleaved file creation, fresh uppercase `.JSON` destinations and explicit replacement. The usual Windows Server 2022/2025 CI and release gates apply. Neither physical Windows 11 interaction nor a measured real-world productivity gain is claimed. The Windows binary is unsigned.
