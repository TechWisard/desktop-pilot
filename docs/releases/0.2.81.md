Desktop Pilot 0.2.81 — ручные решения выполняются в заданном порядке, автоматическое размещение учитывает возвращение к работе.

## Что улучшено

**Последний выбор пользователя остаётся последним.** При временной блокировке локальной SQLite-базы команда на изменение правила ярлыка могла отложиться, а следующая команда — выполниться раньше неё. Например, пользователь последовательно выбирал «Всегда», затем «Никогда», но после снятия блокировки программа могла применить устаревшее «Всегда». Теперь очередь сохраняет порядок: если первое действие нельзя безопасно начать, новые действия ждут следующей штатной проверки. Изменение не повторяет уже выполненные операции и не переставляет пользовательские файлы.

**Меньше незапрошенных изменений.** Автоматический обзор проверяет бездействие и полноэкранный режим повторно непосредственно перед размещением ярлыков. Если пользователь вернулся к компьютеру, обзор откладывается. Явное ручное применение не ограничивается этой проверкой.

**Устойчивее к кратковременной занятости базы.** Периодические записи наблюдения, уведомления о состоянии и захват ожидающих команд безопасно переносят временные конфликты SQLite. Другие ошибки хранения остаются видимыми; история, настройки, отмена и сохранённые ручные правила не сбрасываются.

В английской и русской документации также убрана устаревшая версия из раздела совместимости. Новых настроек, сетевого отслеживания, скрытой телеметрии и зависимостей нет. Черновая функция организации рабочего стола из PR #98 и #101 в этот выпуск не входит.

## Проверки и ограничения

Регрессионные проверки выполняют настоящие SQLite-транзакции и очередь команд; детерминированно освобождают блокировку между первой и потенциальной второй попыткой, проверяют итоговое правило «Никогда», файлы и события. Отдельно проверяется остановка фоновой работы между командами. Проверка исходной ветки на Windows Server 2022 и 2025: [успешный CI](https://github.com/TechWisard/desktop-pilot/actions/runs/41330116214). Связанные исправления: [#114](https://github.com/TechWisard/desktop-pilot/pull/114), [#115](https://github.com/TechWisard/desktop-pilot/pull/115), [#116](https://github.com/TechWisard/desktop-pilot/pull/116), [#117](https://github.com/TechWisard/desktop-pilot/pull/117).

[Исследование последовательности команд](https://github.com/TechWisard/desktop-pilot/blob/main/docs/research/2026-11-01-queued-command-order.md). Сценарии используют искусственную последовательность событий, но штатную логику программы и реальные временные файлы/SQLite; это **не** измерение экономии времени людей. Физическое тестирование Windows 11/Explorer, длительных зависаний дисков и интерфейса при масштабировании 200% остаётся открытым.

Для Windows x64 распакуйте **DesktopPilot-0.2.81-windows-x64.zip**, запустите `desktop-pilot.exe` и сверьте SHA-256 с **SHA256SUMS.txt**. Исполняемый файл не подписан.

## English

Desktop Pilot 0.2.81 keeps successive manual shortcut preferences in order when a temporary SQLite writer conflict interrupts the first claim. Newer actions no longer overtake a deferred older action, preventing a user's latest Always/Never decision from being reversed. An automatic desktop review also rechecks active/fullscreen use just before placing files, and transient SQLite contention no longer unnecessarily stops advisory tracking or pending claims.

Regression scenarios use the production command dispatcher and real SQLite/shortcut files under deterministic simulated scheduling. The exact feature-branch Windows Server 2022/2025 CI succeeded: locked Rust tests, formatting, warnings-denied Clippy, build, native integration and release guards. The README compatibility description no longer pins an outdated release number. No telemetry, settings reset, automatic file migration or new dependencies. Windows 11 interaction, prolonged device stalls, and actual end-user time savings remain unverified. The Windows executable is unsigned.
