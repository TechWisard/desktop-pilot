# Desktop Pilot 0.2.104 — хранение истории не зависит от проверки ярлыков

## Исправлено

**Очистка устаревшей статистики продолжается, даже если поиск ярлыков долго не завершается.** Раньше программа удаляла записи старше установленного срока только после успешного сканирования источников ярлыков. Если сетевой диск, внешний накопитель или другая папка становились недоступны, фоновый учёт и ручные команды могли продолжать работать, но очистка старых записей откладывалась на неопределённое время.

Теперь обслуживание локальной базы данных запускается независимо от результата сканирования, с отдельным шестичасовым интервалом. Временная блокировка SQLite не выключает наблюдение: операция повторяется при следующей плановой проверке. Существующая защита истории от ошибочного перевода системных часов сохраняется.

Изменение не переставляет ярлыки, не меняет ручные правила, не удаляет пользовательские файлы и не добавляет телеметрию или новые настройки. Для уже защищённых записей и периода хранения действуют прежние правила.

## Воспроизводимая проверка

[Сценарий, исходные причины и ограничения](../research/2026-11-03-retention-with-blocked-scan.md). Интеграционный тест удерживает настоящий механизм поиска ярлыков на файловой операции и параллельно проверяет настоящую базу SQLite и фоновый монитор. Старая запись за 110 дней и устаревшая отметка сеанса должны удалиться; свежая запись остаётся. Сохраняются ручной запрет приложения, регулярное обновление состояния, целостность исходного ярлыка и завершение фонового процесса без ожидания зависшего сканирования.

В штатном CI выполняются форматирование, тесты Rust, строгий Clippy, сборка, нативные интеграционные проверки и защита публикации на Windows Server 2022 и 2025. Синтетически заблокированный источник не заменяет физические испытания на Windows 11 и не доказывает экономию времени пользователей.

## Установка

Скачайте **DesktopPilot-0.2.104-windows-x64.zip**, распакуйте архив и запустите программу. Сверьте SHA-256 с **SHA256SUMS.txt**. Исходники: **DesktopPilot-0.2.104-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.104 keeps its locally stored usage history bounded even when shortcut discovery stalls on an unavailable source. SQLite retention now follows an independent six-hour monitor cadence instead of requiring successful scan completion. Temporary database writer contention is retried later; existing clock-correction safeguards, current history, manual choices, original files, Undo and offline privacy are preserved.

The native integration regression blocks the production scanner while checking actual monitor and SQLite cleanup: a 110-day-old usage record and expired session timestamp are pruned, whereas recent evidence, user policy commands and safe shutdown remain intact. Windows CI verifies the build and release checks. Interactive Windows 11 behavior and real user time savings have not been measured.
