Desktop Pilot 0.2.82 — автоматическое размещение больше не начинается после возвращения пользователя во время длительной предварительной проверки.

## Что исправлено

При автоматическом обновлении ярлыков программа уже проверяла отсутствие активности после ожидания блокировки изменений. Но вслед за проверкой она могла долго читать каталоги приложений, уточнять ручные перестановки и проверять свободные позиции. Если пользователь за это время возвращался к работе, старое разрешение на перестановку оставалось действительным.

Теперь перед первой записью истории размещения или созданием временной копии выполняется ещё одна проверка активности и полноэкранного режима **после всей предварительной подготовки**. Если компьютер уже используется, автоматическое обновление откладывается без изменения ярлыков и даты последней проверки; позже оно снова станет доступным. Явная команда «Применить» работает независимо от автоматического ожидания.

Новые настройки и фоновые сервисы не добавлены. Локальная история, исходные файлы, ручные ограничения, журнал отката и отсутствие телеметрии сохранены.

## Проверки

Новый сценарий симулирует возвращение пользователя между двумя проверками активности, но использует настоящий механизм автоматического обновления, SQLite, разобранный штатным кодом интернет-ярлык, подготовку размещения и файловые операции. Он проверяет отсутствие изменений и отложенный повтор; после восстановления спокойного состояния программа выполняет одну перестановку без последующего дублирования.

Исследование и границы проверки: [возвращение после предварительной проверки](https://github.com/TechWisard/desktop-pilot/blob/main/docs/research/2026-11-01-automatic-review-post-preflight-quiet.md). Исправление: [PR #119](https://github.com/TechWisard/desktop-pilot/pull/119). На исходной ветке прошёл штатный CI на Windows Server 2022 и 2025: [Actions 41332649931](https://github.com/TechWisard/desktop-pilot/actions/runs/41332649931). Публикуемая версия дополнительно проходит собственные обязательные проверки сборки и дистрибутива.

Реальный рабочий стол Windows 11, длительные сетевые задержки, многомониторное размещение и интерфейс при масштабировании 200% требуют отдельных испытаний. Автоматизированный сценарий не измеряет экономию времени реальных пользователей.

Для Windows x64 распакуйте **DesktopPilot-0.2.82-windows-x64.zip**, запустите `desktop-pilot.exe` и проверьте хеш SHA-256 по **SHA256SUMS.txt**. Файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.82 defers unattended shortcut placement when someone resumes using the computer during a slow catalog/layout preflight. The automatic review checks idle/fullscreen permission once again after preparation and before staging shortcuts or advancing the review checkpoint. A deferred review remains due; explicit manual Apply is unchanged. Original shortcuts, manual choices, local history and reversible placement are preserved, with no new telemetry or service.

A deterministic scheduling regression exercises the actual SQLite/shortcut selection and copy path. Windows Server 2022/2025 source CI passed; the release workflow separately verifies the packaged executable. Physical Windows 11, slow removable/network drives, multi-monitor use and user time savings are not established by these tests. The Windows executable is unsigned.
