Desktop Pilot 0.2.77 — рабочие веб-ярлыки больше не вытесняются ссылками без адреса сайта.

## Что улучшено

Некорректный интернет-ярлык `.url` с неполным адресом вроде `https://`, `http://?q=1` или адресом без имени узла теперь не считается доступным приложением. Прежде при высоком накопленном рейтинге такой ярлык мог занять одно из ограниченных быстрых мест вместо корректной ссылки. Теперь место остаётся пригодному к открытию ярлыку; ни исходный `.url`, ни накопленная история не переписываются.

Проверяется только очевидно недопустимый адресный узел: пути с пробелами, обычные локальные адреса и поддерживаемые протоколы запуска не подвергаются лишней нормализации. Проверка не отправляет сетевые запросы, не проверяет доступность сайта и не собирает телеметрию.

## Проверки и ограничения

Два новых теста проверяют реальные файлы `.url`, штатный парсер, оценку пригодности и производственный предварительный выбор, включая ситуацию «сломанная ссылка с большим историческим рейтингом против рабочей при единственном месте». Для этого синтетического сценария до исправления неисправная ссылка могла занять 1 из 1 места, после — 0 из 1; рабочая выбирается без правки исходников.

Уточнён также существующий тест фонового сканирования: ручная команда принудительно обновляет сигнал активности процесса и заново отсчитывает его 15-секундный интервал. Поэтому прежнее измерение через 19 секунд после отправки команды могло преждевременно завершаться при загруженном тестовом стенде. Обновлённый сценарий по-прежнему удерживает настоящее сканирование, проверяет следующую самостоятельную запись SQLite, своевременность ручного решения, остановку и сохранность файлов. Логика программы для этих сигналов не изменена.

[PR №102](https://github.com/TechWisard/desktop-pilot/pull/102) проверен двумя независимыми [PR](https://github.com/TechWisard/desktop-pilot/actions/runs/41239693254) и [push](https://github.com/TechWisard/desktop-pilot/actions/runs/41239689767) прогонами на Windows Server 2022/2025: полный набор Rust-тестов, форматирование, Clippy без предупреждений, сборка, нативные интеграционные проверки и защитные проверки публикации. [PR №103](https://github.com/TechWisard/desktop-pilot/pull/103) дополнительно убрал ненужную загрузку диагностических архивов при успешной проверке, сохранив отчёты при ошибке. Проверка собранного выпуска и его контрольных сумм выполняется отдельным заданием выпуска.

Интерактивный интерфейс Windows 11, масштабирование 100/200%, реальные браузеры и сетевые диски этим набором тестов не охвачены. Сокращение времени работы реальных людей не измерялось. Новых кнопок, зависимостей и режимов не добавлено; ручные правила, размещения, история и отмена сохранены.

Для Windows x64 распакуйте **DesktopPilot-0.2.77-windows-x64.zip**, запустите `desktop-pilot.exe` и проверьте SHA-256 по **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.77 excludes obviously malformed hostless HTTP(S) Internet Shortcuts from quick-access placement. A broken `.url` with older high usage scores no longer displaces a working website shortcut. Existing files, usage history, manual decisions and Undo remain intact; no DNS or network request, telemetry, or added dependency.

Production-path regressions use real `.url` files, parsing and preview selection, and preserve original bytes. The unrelated blocked-scan heartbeat regression now observes the next ordinary SQLite heartbeat from the **forced manual-command** checkpoint instead of a premature fixed wall-time sample. The production timer is unchanged. Both Windows Server 2022/2025 PR and push checks passed, including Rust tests, formatting, warning-denied Clippy, build, native integration and publication guards. Successful CI runs no longer upload redundant native diagnostics; failure reports remain available. The release job independently verifies the executable and uploaded SHA-256 digests.

Physical Windows 11 UI, browser reachability and end-user time savings have not been validated. The executable is unsigned.
