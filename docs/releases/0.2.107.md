# Desktop Pilot 0.2.107 — сброс обучения не отменяется фоновым обзором

## Исправлено

**Ручной сброс обучения и изменение его порога теперь имеют приоритет над уже начатым фоновым обзором.** Раньше обзор мог прочитать накопленные сеансы, а затем — после того как пользователь сбросил статистику или повысил необходимое число сеансов — записать устаревшую отметку о завершении обучения. Это делало решение пользователя непредсказуемым.

Теперь перед сохранением завершения программа получает транзакционную блокировку записи SQLite, повторно читает актуальные настройки и прогресс и завершает обучение только при выполнении действующего правила. Если пользователь сбросил сеансы или поднял порог, старая запись не возвращается. Обычные обзоры, не меняющие состояние, по-прежнему не занимают лишнюю блокировку записи.

## Проверки и ограничения

[Воспроизводимый сценарий и первичные источники](../research/2026-11-04-idle-learning-reset-serialization.md). Два регрессионных теста используют действительный путь фонового обзора, профиль SQLite и независимое соединение настроек. На предыдущей версии оба сценария давали неправильный результат; исправленная версия сохраняет сброс и новый порог. Также сохраняются проверки повторных обзоров без записи, ручного управления и безопасности размещения.

Стандартные проверки Windows Server 2022 и 2025 включают Rust-тесты, форматирование, строгий Clippy, сборку, нативные интеграционные сценарии и защиту публикации. Эти технические проверки не заменяют испытания на физической Windows 11 и не подтверждают экономию времени пользователей.

## Установка

Скачайте **DesktopPilot-0.2.107-windows-x64.zip**, распакуйте и запустите программу. Проверьте **SHA256SUMS.txt**. Исходный код включён в **DesktopPilot-0.2.107-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.107 preserves explicit learning resets and increased learning thresholds when a background idle review was already preparing to mark initial learning complete. Previously, a stale completion write could override the user's later decision. The reviewer now takes the SQLite writer only for a possible completion, rereads the saved settings and learning progress within that transaction, and commits only when the current criteria still allow it. No-op reviews remain read-only.

Failure-first tests use the actual idle-review path, SQLite profile and independent Settings connection. Existing desktop placement, manual policies, original shortcuts, history, Undo and offline-only behavior are unchanged. Standard Windows Server 2022/2025 CI covers Rust tests, formatting, strict Clippy, build, native integration and publication guards. No physical Windows 11 UI or measured user time savings are claimed.
