# Desktop Pilot 0.2.117 — поиск ярлыков с различными формами Windows-путей

## Что изменилось

**Каталог теперь находит сохранённый ярлык, даже если его путь записан в расширенном формате Windows.** Раньше обычный путь, скопированный в Проводнике, например C:\Users\Editor\Team Alpha\editor.lnk, мог не находить сохранённую запись с эквивалентным префиксом \\?\C:\. Аналогичная проблема затрагивала сетевые UNC-пути, в том числе \\server\share и \\?\UNC\server\share.

При поиске полного пути к .lnk, .url или .exe используются существующие правила сопоставления файлов Windows. Программа по-прежнему не выбирает резервную копию, постороннее примечание либо другой исполняемый файл по совпавшему фрагменту пути. Различные профили запуска одного EXE остаются раздельными. Обычный поиск по словам, неполный путь к папке, сортировка и фильтры не изменились.

Исправление облегчает нахождение нужного приложения перед назначением правил «Всегда» и «Не добавлять». Исходные ярлыки, история использования, расположение файлов и пользовательские настройки не переписываются; новая фоновая служба или телеметрия не добавлены.

## Проверка и границы

Регрессионный тест использует настоящий каталог, ранжирование и SQLite. Он воспроизводит поиск по обычным и расширенным путям с диском, сетевыми UNC-путями, кавычками и пробелами, а также проверяет резервные копии, ручные фильтры, отсутствие ложных совпадений и сохранность записей. Это проверка корректности на синтетических данных, а не измеренная экономия времени.

Перед публикацией должны пройти штатные проверки Windows Server 2022/2025 (Rust, форматирование, строгий Clippy, сборка, нативная интеграция, проверки выпуска). Окончательный EXE и файлы архива проверяются отдельно. Работа в интерактивной Windows 11, масштабирование 100–200% и доступность настоящих сетевых путей требуют дополнительной проверки. Черновая функция упорядочивания рабочего стола не включена в этот релиз.

[Причина, исследования и воспроизводимый сценарий](../research/2026-11-05-extended-copied-path-search.md).

## Установка

Скачайте DesktopPilot-0.2.117-windows-x64.zip, распакуйте и запустите desktop-pilot.exe. Сверьте архив с SHA256SUMS.txt. Исходники доступны в DesktopPilot-0.2.117-source.zip. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.117** finds existing launch profiles when a complete copied Windows drive or UNC file path is expressed in ordinary form but the saved shortcut uses the equivalent extended Win32 namespace spelling. Exact shortcut-source and executable-target matching still excludes backup/notes decoys and preserves distinct launch profiles, manual policies, keyword search and saved data.

A regression exercises production catalog, ranking and SQLite with synthetic drive/UNC names, quoted paths, filters, decoys and unchanged records. Windows Server 2022/2025 checks and release asset verification are required before publication. Physical Windows 11 UI and real redirected-network scenarios remain separate acceptance tasks.
