Desktop Pilot 0.2.65 сохраняет понятное объяснение ручного запрета ярлыка даже при временной недоступности исходного файла.

## Что изменилось

Если пользователь выбрал для приложения «Не добавлять», этот запрет продолжает отображаться в рекомендациях как **«Исключено вручную»**, даже когда его исходный ярлык временно отсутствует или находится на отключённом диске. Раньше при таком сбое программа показывала только «Исходный ярлык или цель недоступны» — это затрудняло понимание, что ручное решение по-прежнему действует.

После восстановления исходного ярлыка выбор не сбрасывается. Сведения о недоступности по-прежнему доступны через состояние приложения и фильтр каталога. Для приложений без ручного запрета объяснения недоступности сохраняются.

Проверки включают реальный путь чтения .url, SQLite, обновление каталога и расчёт предложений на изолированном тестовом рабочем столе: исходный файл исчезает, затем восстанавливается; не создаются новые размещения, сохраняются правила, история и байты исходного файла. Это не измерение экономии времени у реальных пользователей.

Скачайте **DesktopPilot-0.2.65-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы опубликованы в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.65 keeps the **Never add** explanation visible when an original shortcut becomes temporarily unavailable. The recommendation continues to state that the app was excluded manually; an offline source does not make the user's explicit rule appear forgotten. Source availability remains visible in the catalog. Restoration preserves the choice. Regression checks exercise the real Windows URL shortcut parser, SQLite, catalog refresh and preview with an isolated source outage and recovery, protecting rules, usage history, original bytes and placement stability. No new services, telemetry, settings or dependencies have been added. The Windows x64 executable is unsigned.
