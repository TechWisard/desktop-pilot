Desktop Pilot 0.2.85 — безопасный экспорт JSON-отчётов без случайной замены личных файлов.

## Что исправлено

При использовании командного параметра `--out` путь к отчёту теперь должен заканчиваться на `.json` (без учёта регистра). Ранее пользователь мог случайно указать существующий `.txt`, `.jpg`, `.pdf` или `.zip`; диагностический JSON тогда заменял содержимое выбранного файла, хотя файл не был отчётом.

Неподходящий путь отклоняется до открытия профиля и до операций размещения либо отмены ярлыков. Обычные JSON-отчёты продолжают создаваться и обновляться атомарно. Внутренний диагностический файл `last-error.txt`, история, ручные правила, исходные ярлыки, настройки и механизм безопасного отката не изменены. Сеть, телеметрия и новые фоновые службы не добавлены.

## Проверка

Регрессионный тест проверяет разрешённые и запрещённые имена выходных файлов. Дополнительно нативный тест запускает реальный исполняемый файл Desktop Pilot с четырьмя заранее созданными документами и проверяет отказ, неизменность исходных байтов и отсутствие побочного создания профиля. Существующие испытания охватывают сохранение JSON, защиту баз данных и сценариев Windows, применение и откат размещения.

Пройдены обычные проверки исходников после объединения изменений в `main` на Windows Server 2022 и Windows Server 2025: тесты Rust, форматирование, строгий Clippy, сборка, нативные интеграционные сценарии и проверки публикации. [PR #123](https://github.com/TechWisard/desktop-pilot/pull/123), [CI итогового исходного кода](https://github.com/TechWisard/desktop-pilot/actions/runs/41353603652), [описание исследования](https://github.com/TechWisard/desktop-pilot/blob/main/docs/research/2026-11-02-json-report-destination.md).

Ограничение: если пользователь явно выберет другой существующий `.json` файл, он по-прежнему может быть заменён отчётом. Физическое взаимодействие с интерфейсом Windows 11 и экономия времени реальных пользователей не измерялись.

Для Windows x64 распакуйте **DesktopPilot-0.2.85-windows-x64.zip** и запустите `desktop-pilot.exe`. Проверьте архив по **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.85 prevents a mistyped `--out` report path from replacing ordinary user documents, images or archives with JSON data. CLI report filenames must now end in `.json`, case-insensitively, and are rejected before opening a profile or changing desktop shortcuts. Valid JSON report files retain atomic replacement semantics; the internal error log, settings, user shortcuts, history and undo remain unchanged.

Regression coverage exercises both the real CLI parser and a native executable invocation against synthetic existing TXT, JPG, PDF and ZIP files. Windows Server 2022/2025 source checks and native integration passed on merged main before preparing the release. An existing JSON file can still be explicitly overwritten; interactive Windows 11 UI tests and real-world time savings are not established. The Windows executable is unsigned.
