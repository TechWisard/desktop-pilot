# Desktop Pilot 0.2.92 — важные ярлыки рабочего стола не теряются при переполнении каталога

## Что улучшено

**Ярлыки, лежащие непосредственно на рабочем столе, теперь имеют приоритет при обнаружении приложений.** Раньше большая папка проекта, название которой стояло раньше имени ярлыка по алфавиту, могла заполнить весь лимит сканирования вложенными ссылками. В результате ярлык на самом рабочем столе не попадал в новый каталог и не мог получить полезную рекомендацию.

Программа сначала рассматривает непосредственно находящиеся в папке ярлыки, затем последовательно проверяет вложенные каталоги. Ограничение в 6 000 обнаруженных ссылок и порядок обработки остаются определёнными. Запреты и ручные закрепления, существующая история, откат и пользовательские файлы не изменяются; скрытая телеметрия не добавлена.

## Проверки

[Исследование и воспроизводимые сценарии](../research/2026-11-02-direct-shortcut-scan-priority.md) показывают проблему на настоящем обходе файловой системы. Из пяти реальных тестовых `.url`-ярлыков при лимите в два ранее находились два вложенных ярлыка и ни одного прямого. После исправления выбираются один прямой и один вложенный; результат одинаков независимо от порядка создания файлов. При лимите в четыре также сохраняется прямой ярлык. Отдельный регрессионный сценарий проверяет каталог из 5 000 ссылок и сохранение пользовательских правил после повторного сканирования. Это проверка корректности, а не замер экономии времени пользователей.

Используются обязательные Windows Server 2022/2025 проверки форматирования, тестов Rust, строгого Clippy, сборки, нативных интеграционных сценариев и процедуры выпуска. Перед публикацией дистрибутив проходит проверку Windows x64, зависимостей и контрольных сумм архивов. Прямые испытания интерфейса Windows 11, медленных каталогов и масштабирования 100–200% по-прежнему необходимы.

## English

Desktop Pilot 0.2.92 prioritizes direct desktop shortcuts during bounded catalog discovery. Previously, a large alphabetically early project subfolder could consume the entire 6,000-shortcut budget and leave visible desktop links undiscovered. Scanning now considers direct links first and then visits sorted child folders, retaining the same cap, exclusions, symlink protection, saved manual rules, local data, original files, and Undo.

A production filesystem-visitor regression demonstrates direct-link inclusion under two small capacity limits in both file-creation orders. Existing 5,000-link SQLite catalog and policy persistence tests remain part of the standard Windows 2022/2025 verification gate. These synthetic checks establish specific correctness properties; physical Windows 11/UI and user time-savings measurements are not claimed. The executable is unsigned.
