Desktop Pilot 0.2.50 защищает ручное управление ярлыками от конфликта с одновременным включением фоновой работы.

## Что исправлено

При запуске «Применить», первичного размещения или «Отменить» из командной строки программа проверяла, что фоновый процесс остановлен, а затем выполняла действие отдельно. Другое окно настроек могло включить фон между проверкой и изменением. Теперь ручная команда и проверка выполняются под общей блокировкой запуска, а импорт первоначального каталога защищён той же блокировкой.

Исходные ярлыки, сохранённые ручные правила, позиции, история и безопасный откат не изменяются. При уже работающем фоне прямые команды по-прежнему отклоняются, предлагая использовать настройки. Сервисов, зависимостей, телеметрии и новых параметров нет.

Реальный Windows-тест использует изолированную базу SQLite, настоящий исходный ярлык, размещённую копию, Undo и именованную блокировку. Результат демонстрирует правильный порядок операций, но не измеряет экономию времени реальных пользователей.

Скачайте `DesktopPilot-0.2.50-windows-x64.zip`; контрольные суммы находятся в `SHA256SUMS.txt`. Исполняемый файл Windows x64 не подписан цифровой подписью.

## English

Desktop Pilot 0.2.50 serializes direct command-line Apply, initial Apply, Undo and initial catalog import with an explicit background Start or Turn off from another Settings window. Previously a CLI action checked that background work had stopped, but released that decision before acting. Another Settings instance could begin startup in the gap. Direct commands now hold the per-profile startup mutex across the actual action and preserve all existing file, database, policy and rollback protections.

A reproducible production-path Windows regression covers a manually protected shortcut, real SQLite, actual Undo and a Win32 named mutex. No new settings, dependencies, external services or telemetry. The x64 executable is unsigned.
