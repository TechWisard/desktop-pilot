# Desktop Pilot 0.2.94 — больше приложений при совпадающих папках Windows

## Что исправлено

**При совпадении расположений системных папок ярлыки из других каталогов больше не теряются из-за повторного сканирования.** Desktop Pilot проверяет рабочий стол и меню «Пуск» с общим пределом в 6 000 ярлыков. Если две записи системных папок указывали на один путь, программа могла дважды потратить лимит на одни и те же файлы, не дойдя до следующей папки.

Теперь повторяющиеся расположения проверяются один раз. Это сохраняет доступность действительно разных ярлыков при переполненном каталоге и не меняет пользовательскую расстановку, правила «Всегда» и «Никогда», историю или файлы. Сортировка, защитные проверки файлов и общий предел сканирования остаются прежними.

## Проверки и ограничения

[Регрессионный сценарий](../research/2026-11-02-duplicate-known-folder-roots.md) использует настоящие папки и `.url`-файлы Windows: при лимите в два элемента повтор одного корня ранее занимал оба места, из-за чего отдельный ярлык меню «Пуск» не попадал в результаты. Теперь оба разных оригинала находятся, а их содержимое не меняется. Проверяется и обычный случай без дублирующихся корней.

Синтетический сценарий подтверждает корректность обхода, но не распространённость такой конфигурации у пользователей и не экономию времени. Публикация зависит от полного стандартного набора Windows Server 2022/2025: Rust, форматирование, строгий Clippy, сборка, нативные сценарии, проверки выпуска и контроль архивов. Для дополнительных испытаний остаются реальные перенаправленные сетевые папки, физический Windows 11, поведение Проводника и масштабирование 100–200%.

## Установка

Загрузите **DesktopPilot-0.2.94-windows-x64.zip**, распакуйте и запустите программу. Контрольные суммы — **SHA256SUMS.txt**, исходники — **DesktopPilot-0.2.94-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.94 prevents overlapping Windows Known Folder scan roots from consuming the shared shortcut budget more than once. This keeps distinct Start Menu candidates discoverable when a previous root appears twice. Existing directory ordering, file safeguards, the 6,000-shortcut cap, original user files, manual Always/Never rules, history and Undo remain unchanged. No new settings or telemetry are introduced.

A production-path regression uses real Windows directories and `.url` files with a two-entry boundary and confirms that a later unique shortcut is no longer starved, while both sources retain their bytes. This is a synthetic filesystem scenario, not a measured user-time improvement. The standard Windows CI, native tests, guarded package build and SHA-256 verification remain release requirements. The Windows x64 executable is unsigned.
