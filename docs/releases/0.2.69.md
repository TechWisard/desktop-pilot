Desktop Pilot 0.2.69 — меньше фоновых записей при неизменных ярлыках.

## Что изменилось

Когда Desktop Pilot проверяет уже размещённые быстрые ярлыки и не обнаруживает ручных изменений, он больше не перезаписывает то же состояние в SQLite. Аналогично, фоновый процесс не записывает повторно одинаковое сообщение о своём состоянии каждую минуту.

Это уменьшает ненужные обращения к единственному писателю SQLite и исключает обновления каталога настроек только из-за повторной записи прежних данных. Особенно полезно при длительной работе, большом каталоге ярлыков или параллельной работе окна настроек и фонового процесса. Это установленное устранение лишних операций, **а не заявка на измеренную экономию времени или заряда аккумулятора**.

При действительном изменении или удалении ярлыка по-прежнему сохраняются новое состояние, ручное исключение и запись о действии. Режимы управления, правила Always/Never, автоматический подбор, права пользователя, восстановление, Undo и содержимое исходных ярлыков не изменены. Никаких сетевых служб, скрытой телеметрии или новых зависимостей.

## Проверки

Регрессионные тесты проходят по рабочим функциям размещения и сверки с настоящими изолированными ярлыками `.url`, профилем SQLite/WAL и конкурирующим SQLite-писателем. SQL-триггеры контролируют число фактических обновлений: повторная проверка неизменного рабочего стола и неизменного статуса не должна записывать ничего, а удаление пользовательского ярлыка и изменение статуса должны фиксироваться. Проверены неизменность оригинала и сохранение ручного Never после удаления.

Изменения и штатные проверки протестированы на GitHub Actions в Windows Server 2022 и Windows Server 2025, включая Rust-тесты, строгий Clippy, сборку, нативные интеграционные сценарии и защитные проверки выпуска. Взаимодействие на физической Windows 11 при 200% масштабировании, настоящие сетевые отключения и время выполнения пользовательских задач остаются непроверенными.

Для Windows x64: распакуйте **DesktopPilot-0.2.69-windows-x64.zip**, запустите `desktop-pilot.exe`. SHA-256 файлов выпуска находятся в **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.69 skips redundant SQLite state writes when the already managed desktop is unchanged and skips identical periodic background status updates. This reduces unnecessary writer contention and catalog invalidation during long-running operation without changing shortcut selection or user control. Genuine edits, manual removal, exclusions and status transitions continue to persist; originals and Undo are preserved.

Regression tests exercise real Store/SQLite WAL, native Internet Shortcuts, the production apply/reconcile paths, a concurrent SQLite writer, and SQL triggers measuring actual writes. Full Windows Server 2022/2025 CI is required before publication. No real-world task-time or battery-life savings are claimed. The Windows x64 executable is unsigned.
