# Desktop Pilot 0.2.119 — точный поиск и добавление ярлыков

## Что изменилось

**Поиск и добавление ярлыков теперь правильно обрабатывают полные пути в одинарных кавычках**, например скопированные из PowerShell. Программа отличает такой путь от обычной фразы и не предлагает постороннее приложение только потому, что его заметка или резервная копия содержит тот же текст. Двойные кавычки из Проводника также поддерживаются.

Распознаются полные пути с переменной окружения Windows, например `%SystemRoot%\DesktopPilot Example\Rare Tool.lnk`. Импорт превращает такой путь в полный только при корректном разрешении переменной. Относительные пути всё ещё отклоняются. Существующие ручные правила «Всегда» и «Никогда», история, настройки, ярлыки и их расположение сохраняются. Никакой телеметрии или новых фоновых служб нет.

Черновая функция упорядочивания рабочего стола в этот выпуск не включена.

## Проверки и ограничения

Регрессионный сценарий использует настоящую SQLite-базу Desktop Pilot, производственный поиск, каталог и разбор списка импорта. Проверены одинарные и двойные кавычки, переменные окружения, дубли, резервные копии, ручные исключения, свободный поиск и неверные относительные пути. Это синтетическая проверка точности, **не** измерение экономии времени реальных пользователей.

Обязательны прежние Windows Server 2022/2025 проверки без ослабления: форматирование, Rust-тесты, строгий Clippy, сборка, нативные проверки и контроль публикации. Выпускной процесс дополнительно проверяет EXE, файлы и SHA-256. Физическая Windows 11 и визуальная приёмка в RU/EN при масштабировании 100–200% остаются непроверенными.

## Установка

Скачайте `DesktopPilot-0.2.119-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы: `SHA256SUMS.txt`. Исходный архив: `DesktopPilot-0.2.119-source.zip`. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.119** improves exact shortcut search and pasted import for PowerShell-style single-quoted paths and Windows environment-variable roots. Exact-source lookup avoids unrelated backup paths or notes; saved preferences and desktop layout remain unchanged. The production SQLite/search/import regression checks synthetic scenarios, not human time savings. Standard Windows CI and release asset verification apply. The draft desktop organizer is not included.
