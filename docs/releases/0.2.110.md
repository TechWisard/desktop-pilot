# Desktop Pilot 0.2.110 — сохранение привычных ярлыков при восстановлении

## Что улучшено

Исправлена ситуация, в которой Desktop Pilot после незавершённой первоначальной настройки или восстановления сохранённого профиля мог трактовать уже размещённые ярлыки как новые и не учитывать заданный предел автоматических замен.

Теперь ограничение замен действует и при первом пересмотре восстановленного профиля. Если в настройках стоит **0 замен**, программа не вытесняет знакомые ярлыки ради нового приложения с высоким рейтингом. При наличии свободного места подходящий новый ярлык по-прежнему может появиться сразу. При пределе в одну замен программа не заменяет два приложения за один пересмотр.

Ручные команды «Всегда» и «Никогда», изменение размера области, исходные файлы, локальная история и возможность отката продолжают работать. Новых разрешений, фоновых служб, телеметрии или переноса данных не требуется; прежние настройки остаются без изменений.

## Проверка и ограничения

Регрессионные проверки используют реальную логику рейтинга и выбора, сохранённое состояние SQLite, исходные Windows-ярлыки .url, предварительный просмотр и применение. Воспроизводится состояние с уже размещёнными файлами, но отсутствующим признаком завершения первого пересмотра; проверяется отсутствие вытеснения, сохранность байтов и положения существующих копий, заполнение вакансии и приоритет явного ручного выбора.

[Исследование и воспроизводимые сценарии](../research/2026-11-04-first-review-replacement-cap.md). Штатные проверки на Windows Server 2022 и 2025 охватывают Rust-тесты, форматирование, строгий Clippy, сборку и нативную интеграцию. Эти синтетические проверки не доказывают экономии времени у реальных пользователей; физическая проверка Windows 11, масштабирование интерфейса 100–200% и длительное восстановление после аварий остаются задачами приёмки.

## Установка

Скачайте **DesktopPilot-0.2.110-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Сверьте архив с **SHA256SUMS.txt**. Исходники доступны в **DesktopPilot-0.2.110-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.110 keeps the saved automatic replacement cap authoritative when an interrupted first review or restored profile already has managed shortcuts. A limit of **0** preserves familiar placements; eligible newcomers may still fill genuinely empty slots. A limit of one permits at most one ranked displacement per review. Explicit **Always/Never** choices, capacity changes, existing files, settings, local history and Undo remain effective.

Regression coverage uses production ranking and selection, SQLite Store, Windows .url originals, preview and apply, including preserved contents and positions across an unfinished first-review checkpoint. Standard Windows Server 2022/2025 CI checks locked Rust tests, formatting, strict Clippy, build and native integration. This does not replace physical Windows 11/DPI testing or measure saved time for real users. See [scenario research](../research/2026-11-04-first-review-replacement-cap.md).
