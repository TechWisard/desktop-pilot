Desktop Pilot 0.2.40 делает открытое окно настроек более отзывчивым при больших сохранённых каталогах ярлыков.

## Что исправлено

Раньше каждая регулярная двухсекундная проверка состояния заново считывала и разбирала весь каталог, пересчитывала рекомендации и перестраивала поиск, даже когда ничего не изменилось. Теперь неизменённый набор данных используется повторно. Изменения из фонового процесса и ручные записи в текущей сессии сразу вызывают полную проверку. Даже без изменений периодическое обновление сохраняется для оценок, зависящих от времени; состояние фонового процесса проверяется отдельно при каждом опросе.

Это не меняет правила размещения, параметры адаптации, пользовательские ярлыки, историю, позиции, отмену и порядок действий. Не добавлены зависимости, скрытый сбор данных или новые настройки.

Проверки выполнялись на реальных путях Settings, SQLite и поискового индекса с сохранёнными каталогами. Тесты проверяют неизменённый профиль, внешние и локальные изменения правил, завершение команд и принудительное обновление после истечения срока снимка. Измерения количества операций не являются подтверждённой экономией времени людей.

Скачайте `DesktopPilot-0.2.40-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Сборка x64 не подписана цифровой подписью; контрольные суммы в `SHA256SUMS.txt`.

## English

Desktop Pilot 0.2.40 avoids repeating a full SQLite catalog parse and ranking rebuild on every two-second Settings poll when nothing changed. Committed external updates, edits from the Settings connection itself, completed commands and time-dependent refreshes still invalidate the snapshot. Background process presence remains checked during each poll.

This reduces unnecessary work without changing placement decisions, manual rules, saved shortcuts, history, Undo, user configuration, dependencies or telemetry. The production-path tests exercise saved catalogs and real SQLite change visibility. Operation counts from CI are not a human productivity measurement. Windows x64 binaries are unsigned.
