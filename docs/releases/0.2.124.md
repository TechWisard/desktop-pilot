# Desktop Pilot 0.2.124 — точный поиск по путям командных файлов

## Что улучшено

**Полные пути к `.cmd` и `.bat` теперь обрабатываются как конкретные файлы, а не как произвольная строка поиска.** Когда несколько ярлыков используют однотипные названия, поиск на вкладке «Приложения» больше не предлагает чужой профиль только потому, что в заметке упомянут нужный путь или имя другого файла начинается так же.

Пользовательские правила «Всегда» и «Не добавлять» остаются привязаны к правильным записям. Поиск по части названия или каталога, сортировка и фильтры продолжают работать как раньше. Никакого перемещения файлов, перенастройки запуска, изменения истории, базы данных и положения значков не производится.

## Воспроизведение и проверки

[Регрессионный сценарий](../research/2026-11-07-copied-batch-targets.md) использует настоящие локальные файлы `.cmd`/`.bat`, сохранённые записи SQLite, собственный механизм поиска и ранжирования Desktop Pilot. Проверяются полные пути в кавычках и с разными разделителями, конкурирующие заметки и похожие имена, фильтры ручных правил, неизменность данных и обычный поиск по словам.

До исправления [запуск Windows CI](https://github.com/TechWisard/desktop-pilot/actions/runs/42343526128) обнаружил одну ожидаемую ошибку при 428 пройденных Rust-тестах на каждом Windows runner. Выпуск допускается только после успешного повторного прохождения форматирования, всех Rust-тестов, строгого Clippy, сборки, нативных сценариев и защитных проверок публикации. При выпуске отдельно проверяются PE x64, состав архивов, SHA-256 и соответствие версии бинарника исходному коммиту.

Это воспроизведение на синтетических каталогах, а не оценка экономии времени реальных пользователей. Интерактивная проверка поиска на физической Windows 11 и расширенные тесты пользовательских сценариев остаются отдельными задачами. Функция организации рабочего стола из [PR #211](https://github.com/TechWisard/desktop-pilot/pull/211) пока не включена.

## Установка

Скачайте архив `DesktopPilot-0.2.124-windows-x64.zip` из [релизов](https://github.com/TechWisard/desktop-pilot/releases) и проверьте контрольную сумму по `SHA256SUMS.txt`. Существующие пользовательские данные, профиль `usage.sqlite`, история и настройки сохраняются. Архив не имеет цифровой подписи.
