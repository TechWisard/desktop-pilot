Desktop Pilot 0.2.13 использует исправный дубликат ярлыка, когда прежний источник временно невозможно прочитать.

## Что изменилось

Если исходный ярлык заблокирован другим процессом или ещё не дописан, а в просматриваемой папке есть исправная копия с той же целью и параметрами запуска, программа использует её вместо отказа в размещении. История, ручное правило и заметка сохраняются под прежним идентификатором приложения.

Уже размещённый быстрый ярлык при смене источника не пересоздаётся и не перемещается. Исправный источник не меняется только потому, что найден очередной дубликат. Разные параметры запуска остаются отдельными профилями; личный профиль приложения не подменяет рабочий. Правило «Не добавлять» по-прежнему имеет приоритет.

Исходные ярлыки не исправляются и не перезаписываются. Новых настроек, сетевой телеметрии, подписки и зависимостей нет. Регрессионные проверки используют настоящие .url/.lnk, файловые блокировки Windows и локальную SQLite, но не заменяют испытания на физическом рабочем столе или замеры времени людей.

Скачайте **DesktopPilot-0.2.13-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы архивов находятся в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.13 can use a verified duplicate shortcut when its previous source is temporarily unreadable because of a sharing lock or partial rewrite. The replacement source must have the same complete launch identity; different launch arguments remain separate profiles.

The catalog ID, history, manual rule and note are preserved. An already managed quick copy is neither recreated nor moved, and healthy sources do not switch merely because another duplicate appears. Explicit Never remains authoritative. Original files are not repaired or overwritten. No new settings, dependencies, subscription or telemetry are introduced.

Download **DesktopPilot-0.2.13-windows-x64.zip**, extract and run `desktop-pilot.exe`. Verify archives with **SHA256SUMS.txt**. The executable is unsigned. Automated Windows/SQLite fixtures are not physical-desktop tests or measurements of human time savings.
