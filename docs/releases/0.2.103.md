# Desktop Pilot 0.2.103 — согласованное время первоначального обучения

## Исправлено

**Одна подтверждённая порция активности теперь имеет единую временную отметку.** Раньше фоновое обучение независимо считывало текущее время для накопления секунд, определения локального календарного дня и отметки завершения. Если за время записи в SQLite наступала полночь или корректировались системные часы, данные одного наблюдения могли оказаться в разных календарных моментах. Теперь программа получает одну локальную временную отметку до операции сохранения, использует соответствующие ей дату и секунды и сохраняет именно этот момент завершения, включая повторы записи после краткой блокировки базы.

Это исправление согласованности исходных данных при редких граничных событиях, а не изменение порога обучения и не обещание более быстрых рекомендаций. Исходные ярлыки, ручные правила, расположение значков, история, возможность отката и автономная работа сохраняются. Новые настройки, фоновые службы и телеметрия не добавлены.

## Воспроизводимая проверка

[Исследование и ограничения](../research/2026-11-03-single-learning-clock-snapshot.md). Проверка пропускает через настоящие транзакции SQLite и логику обучения 150 подтверждённых синтетических отсчётов по две секунды, пересекающих локальную полночь. Ожидается ровно один завершённый пятиминутный сеанс: 120 секунд в первый календарный день и 180 — во второй. Дополнительно проверяется, что временное отключение сбора до завершения обучения не записывает запрещённый отсчёт, а последующее разрешение его не искажает.

Штатный CI выполняет форматирование, тесты Rust, строгий Clippy, сборку, нативные интеграционные сценарии и проверки выпуска на Windows Server 2022 и 2025. Синтетический сценарий не заменяет испытания на реальном Windows 11 с корректировкой часов, масштабированием 100–200% и длительным изменением привычек пользователя.

## Установка

Скачайте **DesktopPilot-0.2.103-windows-x64.zip**, распакуйте архив и запустите программу. Сверьте SHA-256 с **SHA256SUMS.txt**. Исходники: **DesktopPilot-0.2.103-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.103 uses one local clock observation for each confirmed first-use learning sample. Its elapsed checkpoint, local calendar day and completion timestamp now agree even if midnight or an OS clock adjustment occurs while a SQLite transaction is pending. Retrying the write does not manufacture a later observation. User-created shortcuts, manual rules, stable placement, Undo, existing history, offline operation and local privacy remain unchanged.

The production SQLite regression replays 150 two-second observations across local midnight and rejects a sample while collection is temporarily paused. Windows CI verifies the source and release safeguards; physical Windows 11 UI and actual human productivity have not been measured.
