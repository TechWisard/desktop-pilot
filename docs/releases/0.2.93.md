# Desktop Pilot 0.2.93 — быстрее проверка папок с документами и ярлыками

## Что изменилось

**Сканирование смешанных папок выполняет меньше лишних операций.** В папках проектов часто находятся изображения, текстовые документы, журналы и лишь несколько ярлыков. Раньше программа сортировала все эти файлы и отдельно запрашивала метаданные каждого, хотя обычные файлы без расширения ярлыка не могли попасть в каталог приложений.

Теперь такие файлы исключаются до сортировки и дополнительных проверок файловой системы. Папки, символические ссылки и возможные ярлыки `.lnk` / `.url` по-прежнему проходят защитные проверки. Сохранены алфавитная стабильность, приоритет ярлыков непосредственно на рабочем столе, лимит 6 000 ссылок, ручные правила, история, файлы пользователя и безопасный откат. Новых настроек и передачи данных нет.

## Проверки и ограничения

[Регрессионный сценарий](../research/2026-11-02-irrelevant-scan-pruning.md) проверяет реальный обход файловой системы с 1 024 посторонними файлами и двумя допустимыми ссылками — прямой и вложенной в папку с именем `Archive.url`. Число явных обращений к `symlink_metadata` в этом сценарии сокращается с 1 027 до 3; оба ярлыка продолжают обнаруживаться в правильном порядке. Существующие тесты проверяют 5 000 настоящих `.url`-ярлыков с SQLite, ограничения обхода и сохранение ручных выборов. Это уменьшение количества операций в искусственном сценарии, а не доказанная скорость на компьютере пользователя.

Выпуск проходит обычные Windows Server 2022/2025 проверки тестов Rust, форматирования, строгого Clippy, сборки, нативных сценариев и упаковки. Для окончательной проверки необходимы работа с настоящими медленными или отключаемыми папками, интерфейс Windows 11 и масштабирование 100–200%.

## Установка

Загрузите **DesktopPilot-0.2.93-windows-x64.zip**, распакуйте и запустите программу. Контрольные суммы опубликованы в **SHA256SUMS.txt**. Архив исходников — **DesktopPilot-0.2.93-source.zip**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.93 reduces unnecessary catalog-scan work in folders containing documents, images and only a few shortcuts. Ordinary non-shortcut files are skipped before sorting and detailed metadata checks; directories, symlinks and potential shortcuts retain the existing safety checks. Direct-desktop priority, deterministic ordering, the 6,000-shortcut bound, original files, explicit user rules, local history and Undo remain unchanged.

The production visitor regression uses 1,024 unrelated files and two shortcut candidates, including a nested directory named `Archive.url`. It verifies a reduction in explicit `symlink_metadata` calls from 1,027 to 3, preserving the discovered results. The unchanged 5,000-URL SQLite and native integration checks remain in the Windows CI gate. This is a synthetic operations count, not measured human time saved or physical Windows 11 latency. The Windows x64 executable is unsigned.
