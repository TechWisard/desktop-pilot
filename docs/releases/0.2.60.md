Desktop Pilot 0.2.60 устраняет редкую, но важную ошибку восстановления при создании ярлыков.

## Исправление

Если Windows успевала переместить подготовленный ярлык на конечное место, но затем отказывала в изменении его атрибутов, программа сообщала об ошибке, однако могла оставить скрытый файл без записи о владении. Теперь после такого сбоя Desktop Pilot удаляет созданную копию только при подтверждённом совпадении идентификатора файла и его содержимого. Чужие, заменённые или изменённые файлы не удаляются. Если безопасная очистка невозможна, программа сообщает о проблеме, а не выдаёт её за устранённую.

Проверены сценарий частичного сбоя после реального переименования Windows, сохранность оригинала и повторное создание. Ручные правила, история, отмена изменений и обычная публикация ярлыков не меняются. Новых настроек, зависимостей, фоновых служб и телеметрии нет.

Скачайте архив **DesktopPilot-0.2.60-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы доступны в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.60 safely cleans up a newly created shortcut when Windows successfully renames its hidden staging file but then refuses the subsequent file-attribute update. Cleanup requires the same stable file identity and exact content hash. Changed, replaced or unverified user files are never deleted merely because a publish step failed. The source remains untouched, and users can retry. No settings, persistent state, dependencies, background services or telemetry were added. The Windows x64 executable is unsigned.
