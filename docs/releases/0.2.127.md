# Desktop Pilot 0.2.127 — точный поиск веб-ярлыков с эквивалентным адресом корня

## Улучшение

Если уже сохранён ярлык веб-сайта без косой черты в корневом URL, его теперь можно найти и по скопированному адресу с косой чертой, а также наоборот. Например, `https://example.invalid?view=Work` и `https://example.invalid/?view=Work` при поиске относятся к одному корневому веб-адресу по RFC 9110 §4.2.3. Раньше точный поиск мог показывать пустой результат и вынуждал искать нужное правило вручную.

Сопоставление действует **только во время поиска**. Полные цели запуска, идентификаторы профилей, правила «Всегда» / «Не добавлять», исходные файлы, положение значков и история не меняются. Разные сайты, HTTP/HTTPS, отличающиеся пути и регистр параметров по-прежнему разделены; сторонние заметки не дают ложных совпадений.

## Проверки

[Исследование и воспроизводимый сценарий](../research/2026-11-07-http-root-lookup.md) — настоящие временные файлы `.url`, чтение Windows-ярлыков, SQLite Store и поиск `CatalogCache::update` с четырьмя сохранёнными профилями. До исправления запрос с эквивалентной корневой формой не находил нужную запись, после исправления находит её без лишних результатов.

Два независимых запуска [Windows 2022/2025 — PR CI](https://github.com/TechWisard/desktop-pilot/actions/runs/42396051706) и [push CI](https://github.com/TechWisard/desktop-pilot/actions/runs/42396046622) прошли форматирование, Rust-тесты, строгий Clippy, сборку, нативные проверки и правила выпуска на точном исправленном коммите `4744614e`. Выпуск публикуется только после дополнительных проверок главной ветки, сборки EXE, архива и контрольных сумм.

Это воспроизведённая корректность поиска, а не измерение пользовательской экономии времени. Органайзер рабочего стола остаётся невыпущенным до отдельных испытаний на реальной Windows 11, нескольких мониторах, перенаправленном OneDrive и сценариях прерывания ([PR #211](https://github.com/TechWisard/desktop-pilot/pull/211)).

## Установка

Скачайте **DesktopPilot-0.2.127-windows-x64.zip** и `SHA256SUMS.txt` со страницы [релизов](https://github.com/TechWisard/desktop-pilot/releases), сравните SHA-256 и распакуйте. Приложение не имеет цифровой подписи. Существующие настройки и данные сохраняются.
