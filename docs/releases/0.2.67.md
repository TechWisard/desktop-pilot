Desktop Pilot 0.2.67 — сохранение ручного расположения после длительной недоступности исходного ярлыка.

## Исправлено

В режиме **Ручной** уже созданный быстрый ярлык теперь сохраняется, даже если исходный ярлык или его цель недоступны больше 72 часов. Раньше обычное нажатие «Применить» после длительного отсутствия (например, отключённого сетевого диска или выходных/отпуска) могло предложить убрать ранее созданную копию без явного решения пользователя.

Сообщение о недоступности исходника теперь учитывает выбранный режим: для сохранённых быстрых копий в ручном режиме не обещается автоматическое удаление через 72 часа.

**Не изменились:** явное правило «Не добавлять», изменение числа доступных мест, сохранение собственных перестановок, отказ от управления при изменении идентичности исходного ярлыка, отсутствие создания новых копий из недоступных источников, 72-часовой период в режимах наблюдения/автоадаптации, история и отмена операций.

Исправление проверяется регрессиями на реальной логике выбора и применения, SQLite и изолированных Windows `.url` ярлыках с временно отсутствующим источником и последующим восстановлением. Исходный файл и управляемая копия не должны изменяться. Это функциональные автоматические тесты, а не измерение времени, сэкономленного реальными пользователями; проверка на физической Windows 11 с сетевыми отключениями остаётся отдельной задачей.

Скачайте **DesktopPilot-0.2.67-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — в **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.67 preserves an existing managed quick shortcut in **Manual mode**, even when its unchanged original shortcut or target stays unavailable for more than 72 hours. Previously, a regular Apply could propose deleting the existing quick copy after a long absence without an explicit user decision. The source-unavailable warning now accurately describes Manual-mode retention rather than promising a 72-hour expiry.

Explicit Never, reduced capacity, changed launch identity, user-authored placement, new-shortcut safety and Undo remain authoritative. Observe/Adaptive retain their existing 72-hour grace. Production selection and apply are covered by regressions using isolated Windows `.url` files and SQLite. These automated fixtures do not measure actual human task-time gains or replace physical Windows 11/network-outage testing. The Windows x64 executable is unsigned.
