Desktop Pilot 0.2.43 объясняет рекомендации по фактически наблюдаемой активности, а не приписывает пользователю несуществующие привычки.

## Что исправлено

Раньше программа показывала «Повторяемое использование» даже для приложения, у которого был только сохранённый исторический приоритет без новых наблюдений, либо единственный длительный сеанс работы. Это создавало неверное впечатление о собранной статистике.

Теперь причина различает использование в разные дни, несколько обращений за день, продолжительную работу и прежний сохранённый приоритет при недостатке свежих данных. Формулировки не обещают гарантированной экономии времени. Ручные правила «Всегда» и «Не добавлять» и причины исключения остаются прежними.

Проверки используют настоящие ярлыки, локальную базу SQLite и рабочий расчёт рекомендаций, а также переводы для русского и английского интерфейса. Рейтинг, состав и порядок рекомендаций, размещение, история и отмена изменений не менялись. Не добавлены новые настройки, зависимости или телеметрия.

Скачайте `DesktopPilot-0.2.43-windows-x64.zip`, распакуйте его и запустите `desktop-pilot.exe`. Контрольные суммы находятся в `SHA256SUMS.txt`. Программа работает локально; исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.43 makes recommendation explanations match the evidence actually recorded. Previously an eligible shortcut could be labeled as "Repeated use" despite only a saved historical priority or one substantial focused session.

The UI now distinguishes usage on different days, multiple sessions in one day, extended work in one day, and a historical priority with little recent observation. The wording is conditional, not a claim of measured time savings. Existing exclusion reasons and deliberate Always/Never choices remain unchanged.

Regression coverage uses native-parsed shortcut files, the real SQLite usage Store, the production preview/ranking path, and translations in both languages. Scores, thresholds, selection, shortcut files, manual placement, history and Undo are unchanged. No dependency, settings, service or telemetry added. The Windows x64 executable is unsigned.
