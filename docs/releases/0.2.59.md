Desktop Pilot 0.2.59 — команда «Отключить» больше не зависит от доступа к автозапуску Windows, если автозапуск уже был выключен.

## Что изменилось

При уже отключённом автозапуске Desktop Pilot теперь прекращает фоновую работу, отменяет ожидающие команды и сохраняет состояние выключения, не пытаясь повторно менять реестр автозапуска. Прежде отказ записи в Windows мог заблокировать даже простое выключение фоновой работы.

Если автозапуск действительно был включён, его удаление остаётся обязательной проверяемой операцией. Ошибка Windows не маскируется ложным сообщением об успешном отключении.

Ручные правила, исходные ярлыки, расположение и история использования сохраняются. Новых фоновых служб, настроек, телеметрии и зависимостей нет.

Повторяемые проверки используют реальные SQLite-профили, исходный URL-ярлык и очередь команд, с контролируемым отказом интеграции Windows. Проверки не являются измерением производительности или пользовательской экономии времени.

Скачайте **DesktopPilot-0.2.59-windows-x64.zip** и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.59 lets Turn off complete without touching Windows startup registration when startup was already disabled. Pending commands are cancelled, the disabled state is persisted, and original shortcuts, manual choices and usage history remain intact. When startup was enabled, removing its registration still requires a successful Windows operation; failures are reported rather than hidden.

The production disable path is regression-tested with real SQLite, inert shortcut files and a controlled startup-registration refusal. No new service, dependency, persistent setting or telemetry. The Windows x64 executable is unsigned.
