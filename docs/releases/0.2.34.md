Desktop Pilot 0.2.34 защищает ручное размещение ярлыков от изменений во время фонового сканирования.

## Что изменилось

Если пользователь вручную добавляет быстрый ярлык, пока Desktop Pilot проверяет большой каталог, результат начатой ранее проверки больше не сможет ошибочно объявить собственную быструю копию исходным ярлыком. Это особенно важно, когда исходный диск или папка временно недоступны. Защита работает и при переименовании быстрой копии до завершения проверки.

При изменении состава управляемых ярлыков программа заново сверяет данные перед записью и, при необходимости, повторяет проверку один раз. Повторные изменения не вызывают бесконечных сканирований: вместо рискованной записи выдаётся понятное сообщение. Независимые оригиналы по-прежнему распознаются. Ручные правила, сохранённые позиции, история, файлы пользователя и безопасная отмена сохранены.

Новых зависимостей, настроек, сервисов, телеметрии и изменений формата данных нет. Скачайте **DesktopPilot-0.2.34-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Сверьте архив с **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.34 protects user-placed quick shortcuts during overlapping background catalog scans. When an original shortcut becomes temporarily unavailable, a scan started before the user placed or renamed a quick copy can no longer adopt that managed copy as the original source.

The scanner checks ownership inside the final SQLite transaction and retries once with current ownership instead of applying stale data. Repeated concurrent changes lead to an actionable error, not unbounded rescanning. Independent original aliases remain usable. Manual decisions, positioning, history, original files and conservative Undo are preserved. Undo never deletes a shortcut manually renamed by the user.

No new dependency, setting, schema, telemetry or network service is introduced. Download **DesktopPilot-0.2.34-windows-x64.zip**, compare it with **SHA256SUMS.txt**, and run `desktop-pilot.exe`. The executable is unsigned. Automated Windows regressions are not a measurement of real-world user time savings.
