Desktop Pilot 0.2.30 точнее учитывает использование приложений с разными профилями запуска.

## Что изменилось

Если ярлыки запускают один и тот же исполняемый файл с разными параметрами (например, рабочий и личный профили браузера), Desktop Pilot больше не приписывает активность неопределённого процесса одному из профилей. Это действует и когда второй ярлык временно недоступен. Так исчезает ложная статистика, способная влиять на автоматические рекомендации и расположение быстрых ярлыков.

Обычные ярлыки без параметров по-прежнему распознаются по процессу, когда нет конфликтующих профилей. Достоверная привязка по отдельному идентификатору приложения или уникальному каталогу игры сохраняется. Если профили нельзя различить по доступным данным Windows, пользователь может закрепить нужный ярлык вручную с правилом «Всегда».

Не изменены пользовательские файлы, история, существующие ярлыки, ручные запреты, откат, настройки, зависимости или телеметрия. Сценарии проверяются на настоящих Windows-ярлыках и SQLite; экономия времени реальных пользователей не измерялась.

Скачайте **DesktopPilot-0.2.30-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.30 stops assigning process-only foreground activity to a guessed launch profile when shortcuts share an executable but differ in arguments. This remains conservative if one profile's shortcut is temporarily unavailable. It prevents misleading usage history from influencing automatic shortcut suggestions.

Unambiguous shortcuts without arguments continue to work as before. Specific app IDs and unique observed game directories remain available as stronger evidence. Users can still explicitly choose Always for a specific profile.

No original files, existing history, user rules, Undo, settings, dependencies or telemetry were changed by this correction. Download **DesktopPilot-0.2.30-windows-x64.zip** and verify **SHA256SUMS.txt**. The executable is unsigned. Automated fixtures do not prove time savings for real users.
