# Desktop Pilot 0.2.118 — устойчивое открытие профиля при одновременном запуске

## Что изменилось

**Программа надёжнее открывает новый профиль, если два процесса запускаются почти одновременно.** Когда несколько обращений к ещё не инициализированной базе SQLite совпадали во времени, один процесс иногда получал ошибку блокировки, даже при стандартном ожидании SQLite. Это выявлено существующим регрессионным тестом при одновременном открытии четырёх подключений на Windows Server 2025.

Теперь только безопасный, повторяемый этап включения режима журнала WAL получает ограниченные повторные попытки при `SQLITE_BUSY`. Операции изменения пользовательских данных не повторяются, незавершённые транзакции не воспроизводятся заново. Прежние проверки схемы, внешних ключей, истории, ручных правил и настроек сохранены. Не добавлены новые службы, телеметрия или сетевые обращения.

## Проверка и ограничения

Доработан тест, который использует настоящий `Store::open` и SQLite: пять независимых новых профилей, в каждом четыре одновременно запускающихся потока, каждый записывает данные, после чего новый экземпляр Store проверяет все сохранённые значения. Проверяются не только успешные открытия, но и целостность данных. Это проверка синтетической гонки, а не измеренное сокращение запуска у реальных пользователей.

Исходная ошибка наблюдалась в CI, однако конкретный SQLite-вызов, на котором возникла блокировка, в первоначальном логе не определён. Соперничество при переходе к WAL — объяснение, основанное на исходниках и документации SQLite, но не доказанная первопричина всех возможных блокировок.

Перед публикацией обязательны неизменённые проверки Windows Server 2022/2025: Rust, форматирование, строгий Clippy, сборка, нативные тесты и проверки выпуска. Релизный EXE проверяется отдельно. Физическая Windows 11, интерактивный интерфейс и длительная нагрузка остаются дополнительными задачами. Черновая функция упорядочивания рабочего стола в релиз не включена.

Скачайте `DesktopPilot-0.2.118-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Сверьте SHA-256 по `SHA256SUMS.txt`. Исходники: `DesktopPilot-0.2.118-source.zip`. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.118** improves simultaneous first opening of a new local profile. The idempotent SQLite WAL-mode request receives bounded retries for `SQLITE_BUSY`, without replaying user writes or weakening schema validation. The native regression opens five distinct new profiles using four concurrent connections each, writes and reopens all saved records. This is synthetic concurrency correctness, not measured user startup speed.

The observed failing CI did not identify the exact busy SQL statement; WAL transition contention remains a source-grounded hypothesis. Standard Windows Server 2022/2025 gates and release asset verification are required before publication. Physical Windows 11 acceptance remains separate. The draft desktop organizer is not included.
