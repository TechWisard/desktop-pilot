Desktop Pilot 0.2.26 сохраняет выбранный пользователем исходный ярлык при одновременном обновлении каталога.

## Что изменилось

Во время длительной проверки ярлыков можно добавить другой исходный ярлык того же приложения. Ранее завершившаяся позже проверка иногда могла перезаписать этот ручной выбор устаревшим путём. Теперь проверка не заменяет запись, если приложение было импортировано или его исходный путь изменился за время сканирования. Ручные правила «Всегда» и «Не добавлять», история и местоположение быстрых копий остаются неизменными.

Незавершённое размещение теперь проверяется повторно непосредственно перед записью результатов сканирования: если оно возникло за время обхода файлов, обновление каталога откладывается без частичного изменения данных. Обычное обновление иконок и проверка доступности оригиналов продолжают работать.

Исправлены инструкции первого запуска в английском и русском README: теперь они указывают на архив для Windows x64 из последнего релиза, а не на устаревшее имя версии. Старая история изменений сохранена.

Никаких новых настроек, облачных служб, зависимостей и телеметрии. Скачайте **DesktopPilot-0.2.26-windows-x64.zip**, распакуйте и проверьте архив по **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.26 keeps a user's newly selected original shortcut authoritative when importing it overlaps with a slower catalog rescan. The scan skips obsolete source results rather than restoring an older path or replacing a concurrently inserted catalog entry. A newly prepared placement transaction also blocks the final catalog write.

Manual Always/Never decisions, usage history, managed copies, saved positions and Undo remain unchanged. Normal source-metadata refresh and no-op rescans are preserved. English and Russian first-run instructions now point to the latest Windows x64 archive rather than naming an old release.

No new services, controls, dependencies, accounts or telemetry. Download **DesktopPilot-0.2.26-windows-x64.zip**, verify **SHA256SUMS.txt**, and note that the executable is unsigned. Controlled Windows fixtures do not measure real-user time savings.
