# Desktop Pilot 0.2.99 — предупреждение о конфликте ручных мест

## Исправлено

Если ярлык уже размещён пользователем вручную, но у приложения оставлено правило «Авто», а для другого приложения выбрано «Всегда», обе позиции требуют свободного места. Ранее окно приложений считало только правила «Всегда» и могло не показывать предупреждение, хотя применение нового состава закономерно отклонялось.

Теперь перед применением видно полное число **различных мест, занятых ручными решениями**: учитываются правила «Всегда» и сохранённые ручные позиции, включая защищённые копии временно недоступных ярлыков. Повторяющиеся записи одной позиции не увеличивают счётчик. Отменённые правила «Никогда» и неподтверждённые источники не блокируют свободные места. Подсказка предлагает увеличить число мест либо освободить ручную позицию или правило.

**Размещение без разрешения пользователя не меняется.** Файлы, история, сохранённые позиции, отмена изменений, автономная работа и отсутствие телеметрии сохранены.

## Проверки и границы

[Воспроизводимые сценарии](../research/2026-11-03-manual-slot-conflict-feedback.md) используют реальные пути выбора/предпросмотра, нативные ярлыки Windows `.url`, SQLite и существующую ручную позицию. Проверены конфликт в одном месте, отмена и возврат правила, дубли исторических записей и шестидневное отсутствие источника. Исправление не меняет сам защитный отказ от небезопасной перестановки.

Штатные проверки включают форматирование Rust, тесты, строгий Clippy, сборку, нативные сценарии на Windows Server 2022/2025 и защиту выпуска. Это искусственные воспроизводимые сценарии, не измерение времени людей. Реальная работа интерфейса Windows 11, масштабирование 100–200%, доступность экранным дикторам и взаимодействие с Проводником требуют отдельного испытания.

## Установка

Загрузите **DesktopPilot-0.2.99-windows-x64.zip**, распакуйте и запустите. Проверьте контрольную сумму по **SHA256SUMS.txt**. Исходники: **DesktopPilot-0.2.99-source.zip**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.99 improves the explanation of desktop slot conflicts. A manually positioned Auto shortcut and a separate Always rule may both require space, even though the old Apps warning counted only Always rules. The Apps screen now counts distinct manually reserved positions, accounts for retained offline owned shortcuts and legacy duplicate rows, and explains how to resolve the conflict before Apply.

The safeguard that rejects over-capacity changes remains in force. User-owned files, manual choices, saved profiles, Undo and local-only behavior are unchanged. Regressions cover native-parsed Internet Shortcuts, actual SQLite persistence, a manual owned copy, explicit rule reversal and prolonged source absence. Windows 11 interactive UI and accessibility acceptance remain outstanding. The normal release process verifies Windows builds and checks archive contents and SHA-256 before publication.
