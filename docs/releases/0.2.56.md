Desktop Pilot 0.2.56 — надёжное добавление ярлыков из текстовых списков и точные инструкции.

## Что изменилось

При вставке списка путей с начальной меткой кодировки UTF-8 (BOM) первый правильный ярлык больше не считается ошибочным относительным путём. Программа убирает только эту начальную метку; другие строки не изменяются и проверяются независимо, поэтому опечатка по-прежнему не мешает добавлению правильных файлов.

Проверки используют реальный обработчик импорта Windows-ярлыков, SQLite, повторное добавление, ручное закрепление, историю, предпросмотр и Undo. Исходные файлы, правила, выбранные позиции и возможность отмены сохраняются.

В русском и английском руководствах исправлен прежний предел поиска 3000 на фактические 6000 ярлыков и уточнён фильтр «Последний импорт»: в нём отображаются и уже известные ярлыки при повторном выборе. Автоматическая проверка документации сопоставляет предел с исходным кодом.

Нет дополнительных настроек, служб, зависимостей или телеметрии. Windows x64 EXE не подписан цифровой подписью. Контрольные суммы архивов находятся в SHA256SUMS.txt.

## English

Desktop Pilot 0.2.56 accepts a correctly quoted first shortcut in a pasted text list carrying a leading UTF-8 BOM. Only the initial signature is removed; all later path characters remain unchanged and invalid entries are still reported individually. Real Settings import, SQLite, preserved preferences, reimport and Undo are covered by regressions.

English and Russian guides now state the actual 6,000-shortcut scan limit and the behavior of the “Last import” filter, including reselected existing entries. The documentation guard checks the actual scanner constant. No new settings, dependencies, telemetry or service. Windows x64 executable is unsigned.
