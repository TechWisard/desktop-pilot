Desktop Pilot 0.2.6 сохраняет привычные быстрые ярлыки при временной недоступности исходного файла или цели запуска.

## Исправления

- **Кратковременная недоступность:** если накопитель отключился, источник синхронизируется или цель запуска исчезла на время, уже созданный и находящийся под управлением ярлык больше не удаляется сразу при очередном пересмотре. С момента первого обнаружения недоступности предусмотрена отсрочка до 72 часов. Если источник остаётся недоступным, программа может убрать копию при следующем пересмотре после истечения этого срока.
- **Безопасность:** недоступное приложение не может получить новый ярлык; новое размещение по-прежнему требует проверки оригинала. Ручной запрет «Не добавлять», изменение идентификатора цели и уменьшение числа мест действуют без ожидания. Существующие пользовательские ярлыки не перезаписываются.
- **Восстановление:** когда исходный файл или цель вновь доступны, таймер недоступности сбрасывается, а уже размещённая копия и её файловый идентификатор сохраняются.

## Проверки и границы

Новые регрессионные сценарии используют производственные функции каталога, выбора и применения, проверяют исходный файл, цель, восстановление, явный запрет, смену идентичности и истечение отсрочки. Windows CI проверяет форматирование, модульные и нативные интеграционные тесты, Clippy и сборку на Windows Server 2022 и 2025; релизный EXE дополнительно проверяется перед упаковкой и сверкой SHA-256. Испытание физического отсоединения внешнего накопителя и интерактивное поведение рабочего стола Explorer не подтверждены. Никаких новых облачных вызовов, телеметрии и фоновых таймеров не добавлено.

Для обновления закройте настройки, распакуйте **DesktopPilot-0.2.6-windows-x64.zip** и запустите новый `desktop-pilot.exe`. Пользовательские настройки, история, ручные позиции и данные отката сохраняются. Проверьте архив по `SHA256SUMS.txt`. Версия предварительная и без цифровой подписи.

## English

Desktop Pilot 0.2.6 avoids unnecessary layout churn when an existing shortcut source or launch target temporarily disappears.

- **Temporary outages:** when an already managed shortcut's unchanged original or launch target becomes unavailable, a review holds the existing desktop copy for up to 72 hours from first detection. If not restored, a later review after the interval may remove it; no new timer is scheduled.
- **Respect for ownership:** unavailable sources are never used for new shortcut placement. A manual **Never add** rule, a changed launch identity and an explicitly reduced number of slots take priority. Original user shortcuts are not overwritten.
- **Recovery:** the unavailable timestamp resets after the original or target is valid again, without replacing the existing desktop file.
- **Regression coverage:** production catalog, ranking, preview and apply flows are covered by synthetic isolated source/target loss and restoration tests, expiry, changed identity and explicit user overrides.

Windows CI checks formatting, tests, Clippy, compilation and native fixtures on Windows Server 2022 and 2025. The packaged release is checked again, and SHA-256 digests are verified. Physical removable-drive unplugging and interactive Explorer desktop behavior remain unverified. The application stays local, unsigned, and telemetry-free.

Close Settings, extract **DesktopPilot-0.2.6-windows-x64.zip**, run the new `desktop-pilot.exe`, and verify `SHA256SUMS.txt`.
