Desktop Pilot 0.2.78 — некорректные веб-адреса с ошибочными портами не занимают быстрые места.

## Что улучшено

Интернет-ярлык `.url` с адресом вида `https://example.invalid:word/project` прежде мог считаться пригодным для открытия. При высоком накопленном приоритете он мог занять ограниченное быстрое место, вытеснив рабочий ярлык. Теперь Desktop Pilot проверяет числовой диапазон порта и корректность IPv6-адресов в квадратных скобках до отбора.

Корректные ссылки с именами хостов, `localhost`, IPv6, числовыми портами и пробелами в путях остаются допустимыми. Пустой указанный порт сохраняет стандартную интерпретацию «порт не задан». Проверка остаётся локальной: никаких обращений к сайту, фонового сетевого опроса или телеметрии. Существующие файлы `.url`, история, исключения пользователя, ручное расположение и возможность отмены не меняются.

## Проверки и ограничения

Для регрессии созданы два реальных файла `.url`: неработоспособная ссылка с высоким сохранённым условным приоритетом и корректная с меньшим. Тест использует штатное чтение ярлыков и реальный предварительный выбор на одно быстрое место, а также проверяет неизменность обоих файлов. **До исправления** проверка пригодности нечислового порта завершалась ошибкой регрессии на Windows Server 2022 и 2025: [контрольное воспроизведение](https://github.com/TechWisard/desktop-pilot/actions/runs/41242024233), по 346 остальных тестов прошло. **После исправления** в [полном прогоне](https://github.com/TechWisard/desktop-pilot/actions/runs/41242553128) на каждой из двух Windows-систем прошло **347 Rust-тестов, 29 нативных интеграционных проверок и 9 защитных проверок выпуска**; также прошли форматирование, строгая проверка Clippy и обычная сборка. [Изменение PR #104](https://github.com/TechWisard/desktop-pilot/pull/104); [исследование и сценарий](https://github.com/TechWisard/desktop-pilot/blob/main/docs/research/2026-11-01-web-shortcut-port-authority.md).

Это синтетический сценарий исправления ошибочной рекомендации, а не измерение экономии времени пользователей. Реальные браузеры, интерактивная Windows 11 и экранный масштаб 200% не проверены. Новых интерфейсных режимов, зависимостей и сборов данных нет.

Для Windows x64 распакуйте **DesktopPilot-0.2.78-windows-x64.zip**, запустите `desktop-pilot.exe` и сверьте SHA-256 по **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.78 prevents malformed HTTP(S) Internet Shortcuts with nonnumeric or out-of-range ports or invalid bracketed IPv6 addresses from taking scarce quick-access slots. Existing valid localhost, IPv6, credential-bearing and numeric-port links continue to work, without network requests or telemetry. Files, history, manual decisions and Undo are preserved.

The production-path regression reads two real `.url` fixtures and uses the actual native validity and preview selection logic. The failure was reproduced on both Windows Server 2022 and 2025, then corrected. Both runners passed 347 Rust tests, 29 native integration checks, 9 publication guards, rustfmt, strict Clippy and build. This does not establish end-user time savings or physical Windows 11 GUI acceptance. The executable is unsigned.
