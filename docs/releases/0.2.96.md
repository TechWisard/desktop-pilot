# Desktop Pilot 0.2.96 — точнее учёт коротких обращений к приложениям

## Что улучшено

Быстрые переключения между окнами больше не продлевают срок старых, незавершённых наблюдений за приложением. Раньше кратковременный возврат к окну, не подтверждённый дальнейшей работой, мог обновлять время последнего наблюдения. Несколько таких обращений в течение часа позволяли старым секундам активности накопиться до порога учёта и влиять на рекомендации рабочего стола.

Теперь двадцатиминутный срок частичного наблюдения обновляется **только при подтверждённой последовательной активности**, а не при одиночном переключении фокуса. Подтверждённые короткие посещения внутри этого срока по-прежнему суммируются, поэтому полезность часто используемых справочников, чатов и приложений с короткими сеансами не теряется.

Не изменились правила «Всегда» и «Никогда», расположение ярлыков, автоматические пороги рекомендаций, настройки, локальное хранение, откат и конфиденциальность. Новых разрешений и телеметрии нет.

## Проверки

[Воспроизводимый сценарий](../research/2026-11-03-short-visit-glance-expiry.md) выполняется на рабочем алгоритме накопления активности и настоящей SQLite-базе. Пять двухсекундных измерений создают восемь подтверждённых секунд; затем следуют четыре одиночных кратких возврата примерно через девятнадцать минут и один дальнейший подтверждённый тик. Раньше мог появляться ошибочный десятисекундный сеанс, теперь запись не создаётся. В парном сценарии реальное возвращение в пределах двадцати минут по-прежнему сохраняет десять секунд и один сеанс. Другие тесты длительной работы, отключения учёта и ручного управления не изменены.

Результаты синтетических тестов не означают, что измерена экономия времени у пользователей. Публикация требует штатных Windows CI: форматирование, Rust-тесты, строгий Clippy, сборка, нативные интеграционные проверки и проверка содержимого архива. Работа на реальном рабочем столе Windows 11 и получение подтверждённых отзывов людей требуют отдельных испытаний.

## Установка

Скачайте **DesktopPilot-0.2.96-windows-x64.zip**, распакуйте и запустите приложение. Сверяйте архив по **SHA256SUMS.txt**. Исходники — **DesktopPilot-0.2.96-source.zip**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.96 avoids extending stale partial foreground-usage evidence when the user merely glances at a window. The existing 20-minute in-memory window now refreshes only on confirmed consecutive activity. Verified short visits within that window still accumulate toward useful recommendations. This reduces false-positive usage attribution without changing personal rules, desktop positions, thresholds, local storage, Undo, permissions or telemetry.

Two regression cases exercise the production accumulator and real SQLite storage: isolated focus glances after an eight-second partial observation no longer fabricate a ten-second session; a confirmed return within twenty minutes still records real use. These deterministic synthetic fixtures are not a measure of real-world user time savings. Standard Windows CI, native integration, release packaging and integrity checks remain mandatory. The Windows x64 executable is unsigned.
