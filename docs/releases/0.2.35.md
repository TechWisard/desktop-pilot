Desktop Pilot 0.2.35 помогает быстрее находить нужное приложение в большом списке ярлыков.

## Что изменилось

При поиске по приложениям точное совпадение названия теперь показывается раньше частичных совпадений и совпадений только в путях или категориях. Это особенно полезно, когда поисковое слово встречается в общей папке сотен или тысяч ярлыков: раньше нужное приложение могло оказаться на дальней странице результатов.

Ни один результат не скрывается. В списке сортировки при поиске явно показано «По соответствию», но при желании можно выбрать «По алфавиту». Сортировка по рейтингу или времени использования также сохраняет приоритет. Пустая строка поиска по-прежнему показывает алфавитный список. Ручные правила, расположение ярлыков, история и откат не затронуты; новых настроек и телеметрии нет.

[Исследование, сценарии и ограничения](https://github.com/TechWisard/desktop-pilot/blob/v0.2.35/docs/research/2026-10-28-catalog-search-relevance.md)

## English

Desktop Pilot 0.2.35 makes exact application-name matches easier to find in large saved shortcut catalogs. With the default search order, exact titles come before partial title matches and matches found only in a shared profile path or category. Previously a common folder name could push the exact app behind hundreds or thousands of unrelated names.

All search results remain available, the sort menu explicitly labels the default as **By relevance** and allows **Alphabetically** during search; explicit ranking/usage-time sorts still take precedence, and an empty query retains alphabetic order. User-defined rules, shortcut positions, history and Undo are unchanged. No new panels, dependencies, account requirements or telemetry.

Download **DesktopPilot-0.2.35-windows-x64.zip** and verify **SHA256SUMS.txt**. The executable is unsigned. Synthetic catalog tests are not measurements of actual user time saved.
