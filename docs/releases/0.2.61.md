Desktop Pilot 0.2.61 исправляет достоверность ручного обновления каталога ярлыков.

## Исправление

Когда пользователь нажимал «Обновить» (F5) во время уже выполнявшейся фоновой проверки, программа могла сообщить об успешном обновлении по результатам старого обхода. Новый ярлык оставался невидимым. Теперь такие запросы объединяются в одну следующую проверку, которая действительно начинается после предыдущей. Успех или ошибка показываются после выполнения соответствующего запроса, без ложного подтверждения.

Проверены два повторных запроса, добавление оригинального ярлыка после начала обхода, очередь реального фонового процесса и сохранность исходников. Ручной режим не создаёт лишних ярлыков. Не изменены правила, история, Undo, настройки и механизм безопасной остановки. Новых зависимостей, служб или телеметрии нет.

Архив **DesktopPilot-0.2.61-windows-x64.zip** содержит программу для Windows x64. Контрольные суммы находятся в **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.61 makes manual catalog refresh acknowledgements accurate during a background scan. Refresh requests arriving after a scan started are coalesced into one subsequent verified scan, rather than being marked complete using the earlier enumeration. Manual choices, source files, history, Undo, background responsiveness and cancellation remain unchanged. No additional settings, dependencies, services or telemetry. Windows x64 executable is unsigned.
