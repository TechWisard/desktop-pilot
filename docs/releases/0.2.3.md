Desktop Pilot 0.2.3 делает список приложений удобнее, добавляет масштаб до 200% и исправляет ошибки длительной работы, отката и повторного запуска.

## Интерфейс и настройка

- **Список приложений без лишних подробностей:** крупные имена, состояние и правило остаются в строке. Причины выбора, статистика и пути открываются по кнопке «Подробнее». Кнопка закрытия остаётся видимой при прокрутке подробностей.
- **Удобнее большой каталог:** поиск и сортировка используют подготовленные данные; можно ввести номер страницы. Переход показывает новую страницу с начала. В узком окне дополнительные фильтры свёрнуты. F5 повторяет поиск установленных приложений.
- **Масштаб 100–200%:** выбор в шапке и Ctrl+плюс / Ctrl+минус / Ctrl+0 меняют одну сохраняемую настройку. Отображаемый процент больше не расходится с размером интерфейса.
- **Понятное сохранение правила:** выбранное значение и индикатор остаются у конкретного приложения до ответа фонового процесса. При ошибке показывается сохранённое правило и причина отказа.
- **Установка при недоступном меню «Пуск»:** ошибка создания ярлыка настроек становится предупреждением. Приложение продолжает настройку; следующий запуск окна повторяет попытку без перезаписи чужих ярлыков.

## Исправления

- Откат использует фактическую последовательность операций. Перевод системных часов назад больше не заставляет его отменять более старое размещение вместо последнего.
- Короткое переключение после длительной работы в приложении не создаёт лишний сеанс. Двадцатиминутный перерыв отсчитывается от последнего подтверждённого использования; это состояние сохраняется при перезапуске.
- Временная ошибка чтения существующего исходного ярлыка сохраняет работающую быструю копию и показывает предупреждение. Новая копия требует успешного чтения актуального оригинала.
- Повторный запуск ждёт завершения уже останавливающегося фона и готовности нового процесса. Сигнал остановки не очищается преждевременно.
- При обновлении списка Проводника имя, путь и положение объекта берутся по одному идентификатору. Изменение порядка объектов между запросами не связывает позицию одного значка с именем другого.
- Отказ открыть постороннюю базу или выполнить диагностику в непустой папке не создаёт и не перезаписывает там журнал ошибок. В принятом профиле журнал сохраняется атомарно, без изменения другого файла через жёсткую ссылку.

## Обновление

Закройте окно настроек, распакуйте **DesktopPilot-0.2.3-windows-x64.zip** и запустите новый `desktop-pilot.exe`. Настройки, правила, история и данные отката сохраняются; предыдущий EXE остаётся в резервной копии. Полностью отключённый профиль останется отключённым.

Сборка предназначена для **Windows 10/11 x64** со стандартным рабочим столом Проводника. Это предварительный выпуск без цифровой подписи. Среда выполнения C включена в EXE. Контрольные суммы архивов находятся в **SHA256SUMS.txt**.

Перед публикацией выполняются тесты на Windows Server 2022 и 2025, 28 нативных сценариев и проверка состава и SHA-256 загруженных файлов. Интерфейс отдельно проверяется на вымышленных данных в обычных, небольших и 4K окнах; границы физического тестирования описаны в отчёте.

## English

Desktop Pilot 0.2.3 simplifies the app list while keeping text and controls large. Each row shows the app, state and rule; details open separately. Large catalogs have direct page selection, prepared search data and reliable scroll reset. Narrow windows collapse secondary filters. Rule changes remain visible beside the affected app until confirmed.

Interface scaling now supports 100–200%. The selector and Ctrl+plus / Ctrl+minus / Ctrl+0 shortcuts share one persisted setting, keeping the displayed percentage accurate. If the Start menu cannot accept a Settings shortcut, setup continues with a visible warning and retries when Settings opens again.

The release fixes undo order after a backward clock adjustment, extra sessions after brief switches following long use, removal of working copies when an original is temporarily unreadable, and false startup success while a previous worker is stopping. Shell item paths and positions now resolve from the same identifier. Rejected profile folders remain untouched, and error logs are replaced atomically without changing another file through a hard link.

To upgrade, close Settings, extract **DesktopPilot-0.2.3-windows-x64.zip** and run `desktop-pilot.exe`. Your profile and an exact backup of the previous executable are retained. Disabled profiles remain disabled. This is an unsigned preview for Windows 10/11 x64 with Explorer; the C runtime is included. Verify the archive against **SHA256SUMS.txt**.
