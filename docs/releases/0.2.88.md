# Desktop Pilot 0.2.88 — корректная проверка неполных ярлыков

## Что изменилось

**Неисправный ярлык больше не вытесняет рабочий.** Сохранённый интернет-ярлык `.url` с неполной целью запуска — например, только `steam://`, `steam:///`, `shell:` или `::{` — раньше ошибочно считался пригодным для открытия. Если за ним оставался высокий исторический рейтинг, программа могла предпочесть его работающему приложению. Теперь такие очевидно неполные команды исключаются из автоматических рекомендаций.

Корректные адреса Steam, `shell:AppsFolder` и полные адреса пространств имён Shell продолжают обрабатываться как прежде. Правила пользователя «Всегда» и «Никогда», исходные файлы, история, настройки, уже размещённые ярлыки и безопасный откат не перезаписываются. Новых служб, сетевых запросов и телеметрии нет.

## Проверка

Регрессионный тест создаёт настоящие `.url`-файлы, читает их штатным парсером, присваивает испорченным ярлыкам высокий сохранённый рейтинг и проверяет фактический алгоритм выбора при одном доступном месте. Рабочий ярлык остаётся выбранным; неисправные не становятся рекомендациями, байты оригиналов сохраняются. Отдельные положительные примеры защищают обработку корректных Steam- и Shell-адресов.

На исходной ветке изменение прошло строгие проверки Windows Server 2022 и 2025: тесты Rust, нативные интеграционные сценарии, форматирование, Clippy без предупреждений, сборку и проверки публикации. Тот же обязательный набор повторяется для коммита выпуска. Источники и воспроизведение: [исследование неполных протоколов](../research/2026-11-02-empty-protocol-shortcuts.md).

Это синтетические сценарии на настоящем коде программы, не измерение экономии времени пользователей. Физический Windows 11, взаимодействие с реальным Steam, интерфейс при масштабе 100–200% и отключаемые устройства остаются отдельными проверками.

## Установка

Скачайте **DesktopPilot-0.2.88-windows-x64.zip** из релиза, распакуйте и запустите `desktop-pilot.exe`. Сравните SHA-256 с **SHA256SUMS.txt**. Исходники доступны в **DesktopPilot-0.2.88-source.zip**. Исполняемый файл пока не имеет цифровой подписи.

## English

Desktop Pilot 0.2.88 prevents obviously incomplete `.url` targets such as `steam://`, `shell:` and `::{` from appearing as working recommendations. Previously, a malformed saved shortcut with a strong historic score could displace a usable link. Correct Steam commands and Shell namespace targets remain supported. Existing user originals, preferences, layout, history and Undo are preserved.

A production-path regression reads real `.url` fixtures and runs the actual one-slot selection with high saved scores, checking valid controls and unchanged file bytes. The unchanged strict Windows Server 2022/2025 checks cover Rust tests, native integration, formatting, Clippy, build and release guards. This does not claim real-world time savings or physical Windows 11 interface acceptance. The Windows executable is unsigned.
