Desktop Pilot 0.2.71 — надёжная пауза адаптации при одновременной фоновой проверке.

## Что исправлено

Устранена гонка между сохранением настройки «Приостановить наблюдение» и уже начатой фоновой проверкой рекомендаций. В 0.2.70 новая проверка после паузы не запускалась, однако проверка, успевшая прочитать прежний режим, могла переставить быстрые ярлыки уже **после** сохранения паузы.

Теперь проверка непосредственно перед изменением расположения повторно сверяет сохранённое разрешение на сбор активности. Это происходит под той же блокировкой, что защищает размещение ярлыков. Если пользователь приостановил сбор, запланированное изменение отменяется.

Если перестановка уже выполняется, окно настроек сохраняет паузу только после её завершения — никаких подтверждений сохранения до окончания операции. Ожидание выполняется в рабочем потоке, а не в потоке интерфейса; после 12 секунд без завершения выводится понятная ошибка, настройки не объявляются сохранёнными. **Ручное управление остаётся доступным**, правила «Всегда»/«Никогда», оригиналы, история и Undo не изменяются.

Дополнительно устранена возможная коллизия временных каталогов при параллельном выполнении регрессионных тестов на Windows.

## Проверки и ограничения

Причина воспроизведена на настоящем механизме Desktop Pilot с SQLite и проверкой исходных ярлыков: до исправления на Windows Server 2022 и 2025 тест обнаруживал одну недопустимую перестановку, после исправления такой проход блокируется. Другой сценарий проверяет реальное сохранение настроек параллельно с удержанием Windows-блокировки размещения. Тесты используют изолированные файлы и синтетические события — это **не измерение экономии времени реальных пользователей**.

Выпуск формируется только после успешных тестов, форматирования, строгого Clippy, сборки, нативных интеграционных сценариев и проверок публикации на Windows Server 2022 и 2025. Отдельно требуются испытания физической Windows 11 при масштабе 200%, сетевых отключений, выхода из гибернации и долгой смены рабочих проектов.

Для Windows x64 распакуйте **DesktopPilot-0.2.71-windows-x64.zip** и запустите `desktop-pilot.exe`. Контрольные суммы размещены в **SHA256SUMS.txt**. Программа не имеет цифровой подписи.

## English

Desktop Pilot 0.2.71 closes the scheduling race between **pausing activity observation** and a previously eligible background desktop review. Immediately before automatic placement, the worker rechecks the persisted permission while holding the same Windows mutex as the placement transaction. A saved pause therefore stops even previously queued automatic changes.

An in-flight placement now finishes before Settings acknowledges a successful pause. This is handled off the UI thread; a bounded 12-second wait reports an explicit save failure rather than silently pretending the pause succeeded. Manual Apply, Always/Never rules, original shortcuts, history and Undo remain intact.

The failure-first Windows Server 2022/2025 regression uses the actual SQLite Store, native inert shortcuts, ranking and placement implementation. A companion test checks a concurrent Settings save and Windows mutex. Parallel test profile directories also have guaranteed unique names. Synthetic test outcomes do not establish real-user time savings. Real Windows 11 high-DPI, network disruptions and long-term adaptation still need device-level verification. The Windows x64 executable is unsigned.
