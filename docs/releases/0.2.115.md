# Desktop Pilot 0.2.115 — точный поиск ярлыков по пути с пробелами

## Что улучшено

**Поиск по полному пути больше не смешивает разные профили запуска, если в имени папки есть пробелы.** Например, поиск по пути "C:\Users\Editor\Team Alpha\Shortcuts\editor.lnk" теперь рассматривает его как единое расположение, а не набор независимых слов. Раньше похожий ярлык с папкой Team Beta мог попасть в результаты, если другое поле содержало оставшуюся часть названия пути.

Исправление распространяется на пути с диском (C:\...) и сетевые UNC-пути (\\server\share\...); работают прямые и обратные разделители и кавычки, которые добавляет Проводник Windows. Обычный поиск по нескольким словам, сортировка и ручные фильтры остаются прежними. Исходные ярлыки, настройки, правила «Всегда» и «Никогда», данные SQLite, история и возможность отмены не меняются.

## Проверки и ограничения

Регрессионный тест использует настоящие механизмы каталога и хранилища SQLite. В синтетическом наборе из трёх профилей проверяются точное совпадение, защита от чужого профиля с похожими словами в разных полях, кавычки, пробелы, цели исполняемых файлов, сетевой путь, ручное исключение, отсутствующий ярлык, свободный многословный поиск и сохранение исходного пути. Исправление прошло проверки ветки на Windows Server 2022 и 2025: Rust, форматирование, строгий Clippy, сборка и нативные сценарии.

Итоговые проверки выпуска и согласованность тега с бинарным архивом должны подтвердиться штатной публикацией. Синтетические сценарии не доказывают экономию времени людей; работа интерфейса на физической Windows 11 при масштабировании 100–200% и реальных сетевых источниках не проверялась. Черновая функция упорядочивания рабочего стола остаётся вне выпуска.

## Установка

Скачайте DesktopPilot-0.2.115-windows-x64.zip, распакуйте и запустите desktop-pilot.exe. Сверьте архив с SHA256SUMS.txt. Исходники доступны в DesktopPilot-0.2.115-source.zip. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.115** prevents incorrect launch-profile matches when a copied absolute shortcut path contains spaces. A drive-rooted or UNC path now matches as a contiguous location rather than allowing pieces from unrelated metadata fields to satisfy the query. Explorer-style quotes and either path separator are accepted for search only. Free-form multiword search, manual rules, sorting, stored paths, local history, source files and Undo remain unchanged.

The production catalog and SQLite regression checks three launch profiles, an ambiguous lookalike, drive and UNC paths, executable targets, filters, negative matches and persisted source integrity. The source branch passed Windows Server 2022/2025 CI; final release checks and artifact verification are required for publication. The synthetic regression does not measure real-user productivity or replace physical Windows 11/UI/DPI acceptance.
