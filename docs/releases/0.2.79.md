Desktop Pilot 0.2.79 — надёжнее сохраняет привычные быстрые ярлыки и историю работы после паузы наблюдения.

## Что улучшено

**Временная недоступность источника больше не приводит к лишней замене ярлыка из-за дублированных записей старого профиля.** Если в сохранённом состоянии одна и та же программа встречается несколько раз, при определении фактической вместимости учитываются уникальные приложения. Привычное место остаётся защищённым в пределах обычной 72-часовой отсрочки, если пользователь сам не уменьшил число мест и не исключил программу. Ручные правила сохраняют приоритет.

**Удаление и отмена изменений работают безопаснее при дублированных старых записях.** Повторно сохранённые сведения об одном физическом ярлыке больше не вызывают конфликт одинаковых резервных имён. Разные копии сохраняются для отката отдельно; неоднозначные записи с противоречащими ручными признаками блокируют операцию до проверки, не изменяя пользовательские файлы.

**Быстрая пауза наблюдения не портит учёт подтверждённых посещений.** Если пользователь приостановил наблюдение в настройках ровно между получением свидетельства активности и записью в SQLite, отвергнутые данные больше не считаются сохранённым первым сеансом. При возобновлении учёт начинается с новых подтверждённых действий. Уже сохранённые сведения, ручные закрепления и раскладка рабочего стола не меняются.

Повышена устойчивость очистки временных тестовых профилей при кратковременных блокировках Windows. Новых настроек, фоновых сетевых обращений, внешних сервисов, телеметрии и изменений формата пользовательской базы данных нет.

## Проверки и ограничения

Детерминированные регрессии используют настоящий SQLite-профиль и штатную логику отбора, применения/отмены и учёта использования. Сценарии проверяют ручные запреты, временную недоступность, повторяющиеся данные, корректное восстановление файлов и быстрые паузы между двумя приложениями. Синтетические последовательности не доказывают экономию времени реальных пользователей.

Стандартные проверки Windows Server 2022 и 2025 включают полный набор Rust-тестов, 29 нативных интеграционных сценариев, 9 защитных проверок выпуска, rustfmt, Clippy без предупреждений и сборку. Публикация Windows x64 выполняется только отдельным штатным процессом после успешной сборки и проверки контрольных сумм пакетов. Физическая Windows 11, интерфейс с масштабом 200%, реальные отключаемые накопители и длительные пользовательские исследования не проверены.

Изменения и сценарии: [сохранение ярлыка при дубликатах](https://github.com/TechWisard/desktop-pilot/pull/106), [безопасный откат старых копий](https://github.com/TechWisard/desktop-pilot/pull/107), [точный учёт после паузы](https://github.com/TechWisard/desktop-pilot/pull/108).

Для Windows x64 распакуйте `DesktopPilot-0.2.79-windows-x64.zip`, запустите `desktop-pilot.exe` и сравните SHA-256 с `SHA256SUMS.txt`. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.79 improves continuity during temporary source outages in profiles with duplicate historical shortcut records, makes removal and Undo of legacy duplicate copies safer, and discards uncommitted foreground evidence when observation is paused at the SQLite write boundary. Existing manual choices, user files, history, Undo, and offline-only operation are preserved.

Reproducible regressions exercise the real selection and SQLite code paths with controlled synthetic scenarios. Windows Server 2022/2025 checks and the package publication workflow are required; this does not demonstrate field-user time savings or interactive Windows 11 GUI acceptance. The executable is unsigned.
