Desktop Pilot 0.2.52 уточняет поведение после команды «Отключить».

## Исправлено

Запоздавший запуск из автозагрузки Windows теперь не пытается устанавливать системные обработчики ввода клавиатуры и мыши, если пользователь уже отключил Desktop Pilot. Программа сразу завершает такой запуск без фонового наблюдения. Если отключение происходит непосредственно во время запуска, действующая повторная проверка по-прежнему не позволяет возобновить фоновую работу вопреки выбору пользователя.

Ручные правила, список ярлыков, их расположение, история, исходные файлы и отмена изменений не затронуты. Новых настроек, разрешений, зависимостей и телеметрии нет.

Добавлены проверки отсутствия попытки установки обработчиков после отключения и повторной проверки при одновременном отключении. Выпуск сопровождается обычными Windows-тестами и проверкой релизного файла.

Скачайте `DesktopPilot-0.2.52-windows-x64.zip`, распакуйте архив и запустите `desktop-pilot.exe`. SHA-256 опубликованы в `SHA256SUMS.txt`. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.52 avoids installing global keyboard and mouse input hooks for a delayed Windows startup after the user explicitly selected Turn off. If Turn off overlaps startup, the existing transactional admission check still denies the background session.

Manual choices, shortcut positions, saved history, original files and Undo are unchanged. Regression tests cover a disabled startup and an intervening disable during hook initialization. No new settings, dependencies, permissions or telemetry. The Windows x64 executable is unsigned; SHA-256 checksums are included.
