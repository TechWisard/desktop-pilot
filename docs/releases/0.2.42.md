Desktop Pilot 0.2.42 устраняет лишнюю перезапись большого каталога при очистке истории использования.

## Что изменилось

Команда «Очистить историю» теперь обновляет только те записи приложений, где действительно сохранились прежние исторические приоритеты. Ярлыки с уже нулевыми приоритетами не перезаписываются, поэтому операция не удерживает базу данных для тысяч ненужных обновлений.

Существующие ручные правила «Всегда» и «Не добавлять», положение ярлыков, заметки, оригинальные файлы и возможность отмены размещения сохраняются. Очистка истории по-прежнему атомарна: при ошибке записи прежняя история не теряется.

Регрессионные проверки используют реальную базу SQLite, 1000 дополнительных файлов ярлыков, повторную очистку, преднамеренную ошибку записи и Undo. Сокращение числа записей в тестах не означает измеренную экономию времени пользователей.

Распакуйте `DesktopPilot-0.2.42-windows-x64.zip` и запустите `desktop-pilot.exe`. Контрольные суммы — `SHA256SUMS.txt`. Программа работает локально, без новой телеметрии или зависимости от сетевых сервисов. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.42 avoids rewriting unchanged catalog rows when clearing usage history. Only entries with nonzero historical seed values need an app-row update; daily usage, learning checkpoints and session history are still cleared transactionally. Manual rules, notes, positions, originals and Undo remain intact. A failed write still rolls back the entire clear operation.

Production-path tests cover 1,000 inert shortcut files alongside a protected existing shortcut, repeated clears, a forced SQLite failure, recovery and Undo. Row-write counts are regression evidence, not measured human time savings. No new dependency, schema, setting, service or telemetry. Windows x64 executable is unsigned.
