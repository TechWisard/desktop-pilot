# Desktop Pilot 0.2.106 — меньше фоновых блокировок после обучения

## Улучшено

**После завершения первоначального обучения программа больше не занимает блокировку записи SQLite ради повторной проверки уже завершённого этапа.** Раньше каждый подтверждённый отрезок активности продолжал открывать транзакцию записи, хотя накопление начального обучения было окончено. При одновременном изменении настроек, импорте ярлыков или других операциях с базой такие лишние попытки могли создавать конкуренцию за единственный механизм записи и задерживать наблюдение.

Теперь завершение проверяется чтением уже сохранённого состояния. Для незавершённого обучения действуют прежние атомарные транзакции, проверки разрешения на учёт и сохранение подтверждённой активности. Прогресс не сбрасывается, пороги не меняются. Ручные правила, исходные ярлыки, позиции, история, откат и локальная конфиденциальность остаются неизменными.

## Проверка и ограничения

[Разбор причины и воспроизводимый сценарий](../research/2026-11-03-completed-learning-write-avoidance.md). Регрессионный тест использует настоящую базу SQLite и производственный обработчик обучения. Режим SQLite `query_only` гарантированно запрещает захват пишущей транзакции: завершённое обучение должно возвращаться без ошибки и изменения данных, тогда как сброшенное пользователем незавершённое обучение по-прежнему требует разрешённой записи. Проверены дальнейшее накопление активности, сохранение начального состояния и прежние сценарии задержек SQLite.

Обязательный Windows CI выполняет форматирование, все тесты Rust, строгий Clippy, сборку, нативные интеграционные проверки и защиту публикации на Windows Server 2022 и 2025. Это подтверждает корректность кода на тестовых сценариях, но не измеряет энергопотребление, скорость реального рабочего стола и экономию времени. Испытания интерфейса Windows 11 и системного масштабирования остаются отдельной задачей.

## Установка

Скачайте **DesktopPilot-0.2.106-windows-x64.zip**, распакуйте и запустите программу. Сверьте контрольную сумму с **SHA256SUMS.txt**. Исходники предоставлены в **DesktopPilot-0.2.106-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.106 avoids acquiring a SQLite write transaction for each confirmed foreground observation **after initial learning has already completed**. The durable completion marker is checked using a read; unfinished or explicitly reset learning still passes through the existing transactional permission and persistence checks. This reduces unnecessary background writer contention without modifying settings, shortcuts, manual rules, user files, history, Undo or offline privacy.

A production-path SQLite regression uses `PRAGMA query_only` to enforce the no-writer boundary for completed profiles and to verify that unfinished profiles cannot bypass required transactions. The standard Windows Server 2022 and 2025 checks cover formatting, Rust tests, strict Clippy, build, native integration and release publication guards. No measured battery, CPU, user task-time or physical Windows 11 GUI claims are made.
