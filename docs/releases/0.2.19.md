Desktop Pilot 0.2.19 делает первые автоматические рекомендации более осмысленными, сохраняя стабильность привычного размещения.

## Что изменилось

Одного краткого обращения к приложению теперь недостаточно, чтобы занять свободное место быстрым ярлыком. Подтверждённая рабочая сессия около пяти минут или несколько повторных обращений могут дать обоснованную рекомендацию. При этом единичный давний интерес постепенно теряет вес.

Для замены уже знакомого ярлыка сохранён отдельный, более строгий порог. Ручное закрепление и исключение приложений остаются приоритетными; прежние ярлыки не перемещаются из-за нового порога. Сохранена возможность добавлять ярлыки приложений Windows Shell после подтверждённого десятиминутного использования.

Настройки, исходные файлы, история, позиции и безопасный откат не изменены. Нет дополнительных сервисов, зависимостей, телеметрии и аккаунтов.

Скачайте **DesktopPilot-0.2.19-windows-x64.zip**, распакуйте архив и запустите `desktop-pilot.exe`. Проверяйте архив по **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.19 avoids filling a new automatic shortcut slot after one incidental foreground visit, while still offering a shortcut after meaningful confirmed use. The eligibility gate for a new shortcut uses a 2.5 decayed-score boundary; displacing an existing familiar shortcut still requires the separate three-point advantage and the configured multiplier. The ten-minute packaged Windows Shell shortcut scenario remains supported.

Manual choices, existing owned copies, original shortcuts, history, positions and Undo are retained. No new dependencies, tracking, online services or settings were added. Tests evaluate real application logic with synthetic activity; they do not establish actual human time savings.

Download **DesktopPilot-0.2.19-windows-x64.zip**, check its **SHA256SUMS.txt**, and launch `desktop-pilot.exe`. The executable is unsigned.
