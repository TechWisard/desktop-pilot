Desktop Pilot 0.2.44 исправляет несогласованность времени при определении срока временной недоступности ярлыков.

## Что исправлено

При построении рекомендаций программа уже использовала единый момент времени для оценки активности, но отдельно запрашивала системные часы при проверке 72-часового периода сохранения автоматически размещённого ярлыка с недоступным источником. Вблизи границы этого периода, особенно при коррекции системных часов, предварительный расчёт мог учитывать два разных момента.

Теперь оценка активности и срок временной недоступности рассчитываются для одного момента. Ручное правило «Всегда» продолжает сохранять выбранный ярлык, а «Не добавлять» сохраняет приоритет над автоматикой. Исходные файлы, настройки, расположение, история и отмена изменений не меняются.

Регрессионный сценарий с настоящей SQLite-базой, Windows-ярлыками и рабочим расчётом выбора проверяет мгновение до и после истечения срока, ручные исключения и неизменность исходников. Это детерминированная проверка логики, а не измеренная экономия времени. Новых зависимостей, телеметрии и настроек нет.

Скачайте `DesktopPilot-0.2.44-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — `SHA256SUMS.txt`. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.44 uses one consistent snapshot time for recommendation scoring and the 72-hour unavailable-source grace of automatically managed shortcuts. Previously those checks read different clocks, allowing a boundary-time inconsistency. Manually protected Always shortcuts remain protected; Never still takes precedence. Existing files, placement, settings, history and Undo are unchanged.

The regression uses the real SQLite store, native Windows shortcut parser and production preview immediately before and after the expiry boundary. This is a deterministic correctness test, not a human productivity measurement. No new settings, dependencies or telemetry. The Windows x64 executable is unsigned.
