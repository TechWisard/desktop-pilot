Desktop Pilot 0.2.39 уменьшает ненужные фоновые обращения к базе данных, не меняя обучение, ручные правила и размещение ярлыков.

## Изменения

Периодическая проверка готовности обучения раньше повторно записывала неизменившееся состояние в SQLite. Это происходило даже в ручном режиме или после полного завершения обучения, когда сохранять было нечего. Теперь запись производится только при фактическом первом завершении обучения. Уменьшается лишняя активность базы и вероятность конфликта с записью пользовательских изменений.

Регрессионные проверки выполняют настоящую логику фоновой проверки на реальной SQLite WAL: неизменённые состояния, переход между режимами, первое завершение обучения и параллельный писатель. Сохранение истории, настроек, исходных ярлыков, Undo и обычной логики рекомендаций не менялось. Новых зависимостей, постоянных фоновых служб и телеметрии нет.

Скачайте **DesktopPilot-0.2.39-windows-x64.zip**, распакуйте и запустите desktop-pilot.exe. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.39 avoids redundant SQLite writes during periodic learning readiness reviews. A completed or unchanged learning state is now read without rewriting it; the first real transition to completed is still persisted exactly once. This reduces unnecessary writer contention while keeping all manual rules, saved history, placement and Undo unchanged.

Production-path tests exercise real SQLite WAL and the actual review function across Manual, Observe, completed and not-yet-due automatic states, including a concurrent writer. No new dependencies, settings, services or telemetry. Windows x64 executable is unsigned.
