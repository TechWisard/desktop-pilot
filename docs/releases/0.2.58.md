Desktop Pilot 0.2.58 — сохранение обычных настроек больше не зависит от доступа к автозапуску Windows.

## Что изменилось

Изменение количества быстрых ярлыков, параметров обучения, режима или других настроек больше не обращается к реестру автозапуска Windows, если сам переключатель автозапуска не менялся. Ранее отказ записи в реестр мог заблокировать сохранение совершенно другой настройки.

При явном включении или отключении автозапуска проверка Windows сохраняется: при ошибке программа не сообщает об успешном сохранении и оставляет прежнее значение. Ручные правила, накопленная история, файлы ярлыков, размещение и безопасная отмена сохраняются.

Регрессионная проверка запускает настоящий асинхронный путь сохранения Settings и SQLite, воспроизводит отказ регистрации автозапуска, затем проверяет изменение независимого параметра, ошибку явного включения и успешное повторение после восстановления. Проверки не изменяют реестр рабочей системы.

Windows x64 EXE не подписан цифровой подписью. Контрольные суммы находятся в SHA256SUMS.txt. Новых зависимостей, настроек, служб или телеметрии нет.

## English

Desktop Pilot 0.2.58 lets unrelated preferences save even when Windows startup registration is unavailable. Registry changes are attempted only when the user actually changes the autostart preference. Explicit startup changes continue to report failures rather than falsely claiming success.

The regression uses the real asynchronous Settings save, SQLite and saved shortcut/Undo paths, with a deterministic startup-registration error. No live Windows registry policy was changed. User shortcuts, rules and usage history remain intact. No new dependency, service, setting or telemetry. Windows x64 executable is unsigned.
