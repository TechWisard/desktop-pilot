Desktop Pilot 0.2.21 предотвращает попытку запуска старого быстрого ярлыка, если его цель больше недоступна.

## Что исправлено

Если исходный .lnk сохранился, но приложение удалено или его диск отключён, команда запуска раньше могла передать нерабочий ярлык в оболочку Windows. Теперь недоступная цель или заданная рабочая папка обнаруживается до запуска; появляется понятная подсказка о восстановлении приложения или подключении диска.

Команда `--validate-launch` и фактический `--launch` теперь используют одну проверку. После восстановления приложения прежний ярлык снова распознаётся без переимпорта, потери истории или ручных настроек. Изменённая цель запуска по-прежнему отклоняется, а рабочие Windows- и интернет-ярлыки не блокируются.

Это исправление касается старых управляемых ярлыков, использующих `--launch`. Обычные быстрые копии продолжают открываться Windows непосредственно. Исходные файлы, история, расположение и отмена не изменяются. Новых настроек, зависимостей, сетевых сервисов и телеметрии нет.

Скачайте **DesktopPilot-0.2.21-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверьте **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.21 rejects legacy managed launch requests when the original .lnk still exists but its target or configured working folder is unavailable. Both `--launch` and `--validate-launch` now use the same verified-original guard, with a clear recovery message.

Restoring the program makes the unchanged shortcut valid again without losing rules or history. Edited launch identities are still rejected and healthy local/web links remain accepted. Ordinary copied desktop shortcuts still open directly in Windows; this change applies to the legacy launcher.

No added settings, dependencies, online services or telemetry; no changes to desktop files, placement or Undo. Download **DesktopPilot-0.2.21-windows-x64.zip** and check **SHA256SUMS.txt**. The executable is unsigned.
