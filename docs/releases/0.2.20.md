Desktop Pilot 0.2.20 точнее обновляет сведения об исходных ярлыках без неожиданного изменения рабочего стола.

## Что исправлено

Если у существующего ярлыка Windows изменились только путь к значку и его индекс, повторное сканирование теперь обновляет эти сведения в локальном каталоге, а не оставляет старую запись. Поддерживаются обычные ярлыки .lnk и интернет-ярлыки .url.

Ручные правила, история обращений и позиции быстрых копий сохраняются. Временная недоступность исходного ярлыка не подменяет проверенные сведения; после восстановления данные обновляются. Если изменена цель запуска, прежнее ручное правило не переносится на новое приложение. Быстрая копия на рабочем столе специально не переписывается без отдельного действия пользователя.

Не добавлено новых настроек, зависимостей, сетевых сервисов или телеметрии. Исполняемый файл не подписан цифровой подписью. Скачайте **DesktopPilot-0.2.20-windows-x64.zip** и проверьте контрольную сумму по **SHA256SUMS.txt**.

## English

Desktop Pilot 0.2.20 refreshes original shortcut icon paths and indices when their launch identity remains unchanged. Both Windows .lnk and Internet .url shortcuts are covered. Temporary source loss retains the last verified metadata; an edited target is treated as a different launch identity, not allowed to inherit manual rules.

Managed desktop copies, their bytes and positions, manual choices, usage history and Undo remain unchanged. This corrects local catalog metadata and does not automatically replace an existing desktop icon or claim measured productivity benefits.

No new settings, dependencies, online services or telemetry. Download **DesktopPilot-0.2.20-windows-x64.zip**, verify **SHA256SUMS.txt** and run the unsigned executable.
