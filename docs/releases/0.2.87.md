# Desktop Pilot 0.2.87 — устойчивое обнаружение ярлыков

## Что изменилось

**Предсказуемый каталог при большом количестве ярлыков.** При сканировании вложенных папок программа теперь действительно соблюдает общий предел в 6 000 найденных ярлыков: заполнение лимита в дочерней папке останавливает обход оставшихся элементов и родительских папок. До исправления вложенная структура могла приводить к выходу за этот предел и лишнему чтению файлов.

**Стабильный выбор при достижении предела.** Содержимое каждой папки упорядочивается перед применением лимита. При неизменных файлах состав обнаруженной части каталога больше не зависит от случайного порядка перечисления каталога файловой системой. Порядок исходных корней (рабочий стол перед меню «Пуск») сохранён. Если число ярлыков достигло предела, показывается предупреждение; уже сохранённые записи и ручные правила не удаляются.

**Уважение актуальной настройки панели задач.** Если пользователь включил или отключил пропуск уже закреплённых приложений во время длительного сканирования, устаревший результат не публикуется. Программа повторно проверяет эту настройку и, при её изменении, пересканирует каталог, прежде чем рекомендовать ярлыки.

Работа остаётся локальной и не требует дополнительных разрешений или телеметрии. Исходные ярлыки, ручные решения, настройки, история и безопасный откат не меняются.

## Проверки

Регрессионные тесты используют штатный обход файловой системы, реальные папки с URL-ярлыками, настоящее хранилище SQLite, проверки выбора и применения/отката. В частности, проверяются вложенные папки и два разных порядка создания файлов, 5 000 источников, ручные правила «Всегда»/«Никогда» и переключение фильтра панели задач во время сканирования. Стандартные CI-проверки охватывают Windows Server 2022 и Windows Server 2025: заблокированные зависимости, Rust-тесты, строгий Clippy, форматирование, сборку, нативные интеграционные тесты и проверки публикации. Подробности: [ограниченный обход](../research/2026-11-02-stable-bounded-discovery.md), [изменение фильтра во время сканирования](../research/2026-11-02-taskbar-scan-permission-race.md).

Это воспроизводимые искусственные сценарии на настоящем коде, а не измерение времени, сэкономленного реальными пользователями. Отдельно остаются проверки на физическом рабочем столе Windows 11, отключаемых дисках и визуальная при масштабировании 100–200%.

## Установка

Для Windows x64 скачайте **DesktopPilot-0.2.87-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Исходники и контрольные суммы доступны в **DesktopPilot-0.2.87-source.zip** и **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.87 makes large nested shortcut scans bounded and predictable. Reaching the shared 6,000-item limit in a subdirectory stops the parent traversal, while sorting individual directories before applying the limit keeps the retained catalog subset consistent across repeated scans. Existing saved entries, manual pin and exclusion rules, source files and Undo are preserved.

A taskbar pin-filter setting changed during a long scan now invalidates that scan before its result is committed; the catalog is refreshed with the latest preference.

The regressions exercise real Windows filesystem directories, .url parsing, SQLite, preview/Apply/Undo, and unchanged strict Windows Server 2022/2025 checks. No actual user time savings or physical Windows 11 UI acceptance are claimed. No telemetry or additional background services are introduced; the Windows binary remains unsigned.
