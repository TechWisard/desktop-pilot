Desktop Pilot 0.2.33 делает сообщения о добавлении ярлыков точными и понятными.

## Что изменилось

Повторный выбор уже известного ярлыка больше не выдаётся за добавление нового приложения: программа сообщает «Уже в списке» и «Без изменений». Если одновременно выбраны новый и уже известный ярлыки, результат разделяет эти случаи. При замене исходного ярлыка другого пути с тем же профилем запуска показывается «Обновлено», а не «Добавлено».

Фильтр после операции теперь называется «Последний импорт», отметка элемента — «Выбрано». Оригиналы файлов, пользовательские правила, статистика, расположение и отмена остаются без изменений. Новых зависимостей, настроек, сервисов и телеметрии нет.

Скачайте **DesktopPilot-0.2.33-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверьте файл **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.33 reports shortcut imports accurately. Reimporting an already managed quick shortcut now says "Already in list" and "No changes made" instead of claiming a new app was added. Mixed batches distinguish truly added, updated and already listed entries. A second original for the same launch profile is reported as an update, not another app.

The post-import filter now says "Last import", and highlighted results say "Selected". Existing file ownership, user choices, history, placement, and Undo are preserved. No dependency, schema, settings, network service or telemetry is added. Download **DesktopPilot-0.2.33-windows-x64.zip**, verify **SHA256SUMS.txt**, and run `desktop-pilot.exe`. The executable is unsigned.
