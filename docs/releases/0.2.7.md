Desktop Pilot 0.2.7 исправляет недоучёт регулярных коротких обращений к приложениям при переключении окон.

## Что изменено

- Краткие подтверждённые взаимодействия с одним и тем же приложением теперь суммируются в течение 20 минут, даже если пользователь переключается на другие программы. Повторяющиеся полезные обращения по 5–10 секунд больше не исчезают из статистики только из-за переключения фокуса.
- Первый тик после переключения по-прежнему не учитывается; одиночные случайные переключения и неподтверждённый ввод не создают спрос. Длительные паузы и выход из сна сбрасывают неполные наблюдения. Память ограничена 128 приложениями и не сохраняется между перезапусками.
- Схема SQLite, ручные закрепления, размещение значков, алгоритм замены, настройки, исходные ярлыки, конфиденциальность и отсутствие телеметрии не изменены.

## Проверки и ограничения

Регрессионные тесты используют реальную цепочку наблюдения и записи SQLite: чередование коротких сеансов, защита от случайных переключений, истечение времени, длительные паузы и ограничение памяти; сохраняется прежний сценарий непрерывной работы. Windows CI требует форматирование, тесты, Clippy, сборку и нативные проверки на Windows Server 2022 и 2025. При публикации отдельно проверяются исполняемый файл, упаковка и SHA-256. Измерения экономии времени реальных пользователей и интерактивные испытания на физическом Windows 11 не проводились.

Скачайте **DesktopPilot-0.2.7-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Настройки и история сохраняются. Проверьте архив с помощью `SHA256SUMS.txt`. Сборка предварительная, без цифровой подписи.

## English

Desktop Pilot 0.2.7 preserves meaningful evidence from repeated short foreground visits across application switches.

- Confirmed interactions lasting only a few seconds can now accumulate for the same app across switches within a 20-minute memory window. Previously, each switch discarded this partial evidence.
- One-off focus changes and the first ambiguous tick after each switch still do not count. Incomplete evidence expires after inactivity or a stalled/sleep interval, and at most 128 partial app entries are retained in memory.
- Existing SQLite layout, manual rules, shortcut placement, replacement safeguards, privacy protections and no-telemetry operation remain unchanged.

Regression fixtures exercise production foreground accounting plus real SQLite usage records with alternating short visits, false-positive rejection, inactivity expiry, bounded memory and uninterrupted work. Windows CI gates formatting, tests, Clippy, build and native fixtures on Windows Server 2022/2025; the release process additionally verifies the packaged executable and checksums. No real-user time-savings study or physical Windows 11 Explorer test was performed.

Download **DesktopPilot-0.2.7-windows-x64.zip**, extract and run `desktop-pilot.exe`. Existing preferences and history are preserved. Verify `SHA256SUMS.txt`. This is an unsigned preview.
