Desktop Pilot 0.2.66 сохраняет уже созданные быстрые ярлыки при ручном управлении, даже если приложение позже закрепили на панели задач Windows.

## Что изменилось

Раньше пользователь мог перейти из режима наблюдения в **Ручной**, затем закрепить приложение на панели задач Windows и нажать **Применить**. Программа иногда предлагала удалить уже находящийся на рабочем столе собственный быстрый ярлык, хотя пользователь не выбирал «Не добавлять» и не уменьшал число мест. Это противоречило смыслу ручного управления.

Теперь в ручном режиме уже созданные действительные ярлыки сохраняются без самопроизвольного удаления из-за нового закрепления на панели задач. Для **новых** рекомендаций фильтр закреплённых приложений продолжает действовать. Режим наблюдения, явные правила «Не добавлять» и «Добавлять всегда», изменение вместимости и отмена действий работают по прежним правилам.

Регрессии выполнялись на реальной логике ранжирования и выбора, с настоящими SQLite, чтением изолированного ярлыка .url и расчётом предварительного размещения. Исходный файл и управляемая копия в тесте не менялись. Проверки не заменяют испытания настоящей панели задач Windows 11 и не являются измерением экономии времени пользователя.

Скачайте **DesktopPilot-0.2.66-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверочные суммы находятся в **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.66 preserves an existing managed quick shortcut in **Manual** mode when the same app is subsequently pinned to the Windows taskbar. Previously, pressing Apply could propose removing the quick shortcut without an explicit user decision. The taskbar-pin filter still applies to new suggestions, and Observe/Adaptive behavior, explicit Never/Always choices, capacity changes, and Undo are unchanged.

Regression tests cover the real selection and SQLite preview paths with inert Internet Shortcut files and unchanged source bytes. The tests do not simulate actual Windows taskbar interaction or measure end-user time savings. No new background service, telemetry, persistent setting, dependency or profile migration was added. The Windows x64 executable is unsigned.
