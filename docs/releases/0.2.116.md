# Desktop Pilot 0.2.116 — точный выбор профиля по скопированному пути

## Что улучшено

**Полный путь к ярлыку больше не находит его резервные копии или посторонние записи, в которых этот путь лишь упоминается.** Если вставить из Проводника путь к `.lnk` или `.url`, каталог ищет только точный исходный ярлык. Например, `C:\Users\Editor\Team Alpha\Shortcuts\editor.lnk` не выбирает `editor.lnk.old` и чужую запись с таким же текстом в примечании.

Полный путь к `.exe` сопоставляется с точным исполняемым файлом в источнике или цели. При этом разные профили одного приложения, использующие разные аргументы запуска, по-прежнему отображаются раздельно. Неполные пути к папкам, обычный поиск по словам, сортировка и фильтры сохраняют прежнее поведение. Работают пути с диском, UNC, кавычками и обоими разделителями.

Исправление уменьшает риск применить «Всегда» или «Никогда» не к тому профилю. Программа не переписывает ярлыки, оригинальные файлы, настройки, историю, ручные правила и журнал отмены.

## Проверка и границы

Регрессионный сценарий работает с реальным каталогом, механизмом ранжирования и базой SQLite. В синтетическом наборе присутствуют обычный и сетевой ярлыки, резервная копия `.lnk.old`, чужое примечание с совпадающим путём, исполняемый файл с лишним суффиксом, несколько профилей, ручной фильтр «Никогда» и неполный путь к папке. До исправления старое сравнение подстрок ошибочно находило посторонние записи; новая проверка требует совпадения полного имени источника или исполняемого файла.

Требуются штатные проверки Windows Server 2022 и 2025: все тесты Rust, нативные интеграционные сценарии, форматирование, строгий Clippy, сборка, проверки публикации, итоговая сборка EXE и контрольные суммы. Прохождение синтетических тестов не равно измеренной экономии времени пользователей. Физическая Windows 11, масштабирование интерфейса 100–200%, реальные сетевые задержки и черновое упорядочивание файлов требуют отдельной приёмки.

## Установка

Скачайте `DesktopPilot-0.2.116-windows-x64.zip`, распакуйте и запустите `desktop-pilot.exe`. Сверьте архив с `SHA256SUMS.txt`. Исходники — в `DesktopPilot-0.2.116-source.zip`. Исполняемый файл не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.116** matches a pasted complete `.lnk` or `.url` path only to that shortcut's exact saved source. A stale backup, a note containing the path, or an unrelated profile cannot impersonate it. A complete executable path matches an exact source or target without conflating distinct launch profiles that share the same executable. Partial directory searches, normal keywords, filters, sorting and personal preferences are unchanged.

A production catalog/SQLite regression covers source and executable suffix decoys, quoted drive and UNC paths, manual exclusion filters and partial folder lookup. The change requires unchanged Windows Server 2022/2025 CI and release artifact verification before publication. Synthetic correctness is not real-user time savings; live Windows 11 and high-DPI acceptance remains open.
