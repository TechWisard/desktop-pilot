Desktop Pilot 0.2.2 упрощает добавление приложений и отключение программы, исправляет работу в небольшом окне и устраняет ошибки отката, обновления и длительного наблюдения.

## Интерфейс и настройка

- **Добавление нескольких ярлыков:** выберите файлы, вставьте пути по одному на строку или перетащите `.lnk` / `.url` в окно. Новые записи сразу видны; правила и история существующих приложений сохраняются.
- **Настройку можно продолжить позже:** при закрытии мастера сохраните выбранные параметры и текущий шаг. До завершения мастера наблюдение не включается.
- **Полное отключение из окна:** раздел «Данные» останавливает фон и отключает наблюдение, автоматические изменения и автозапуск. Открытие настроек и обновление сохраняют это решение до явного возобновления.
- **Маленькое окно и крупный масштаб:** исправлены переносы фильтров, кнопки, длинные пути и диалоги подтверждения. Диалоги удерживают фокус; содержимое можно прокрутить.
- **Меньше лишних действий:** Ctrl+F открывает поиск, F5 обновляет данные, исходный ярлык можно показать в Проводнике. Если ручных правил «Всегда» больше доступных мест, сообщение ведёт к нужной настройке.
- **Быстрее большой каталог:** история группируется за один проход, а окно повторно использует рассчитанный рейтинг. Формула и порядок результатов сохранены.

## Надёжность

- Исправлен последовательный откат нескольких замен одного ярлыка. Пользовательские изменения и файлы по-прежнему защищены.
- База нового профиля создаётся одной транзакцией. Сбой инициализации не оставляет непригодный частичный профиль.
- После перезапуска старые команды применения и отката отменяются с записью результата; новая команда выполняется один раз.
- Неудачная замена EXE восстанавливает ранее работавший фон. Подготовка резервной копии выполняется до его остановки; запуск, остановка и установка согласованы между процессами.
- Недоступность значка трея не останавливает учёт: программа повторяет попытки восстановления и показывает состояние в настройках.
- Короткие посещения больше не вытесняют полноценные дни из прогресса длительного первоначального наблюдения.
- Каталог учитывает общий рабочий стол Windows. Ссылки пользовательских протоколов сохраняют значимый регистр и содержимое адреса.
- Экспорт отчётов проверяет назначение до действия и сохраняет файл атомарно. Базу, EXE и ярлыки нельзя случайно заменить отчётом, в том числе через короткое имя Windows.

## Обновление

Закройте окно настроек, распакуйте **DesktopPilot-0.2.2-windows-x64.zip** и запустите новый `desktop-pilot.exe`. Настройки, статистика, правила и данные отката сохраняются; прежний EXE остаётся в резервной копии. Полностью отключённый профиль останется отключённым. Права администратора не нужны.

Сборка предназначена для **Windows 10/11 x64** со стандартным рабочим столом Проводника. Это предварительный выпуск без цифровой подписи. Среда выполнения C включена в EXE. Контрольные суммы архивов находятся в **SHA256SUMS.txt**.

Публикация проходит тесты на Windows Server 2022 и 2025, 24 нативных сценария и проверку состава и SHA-256 загруженных файлов. Ограничения физического тестирования перечислены в отчёте.

## English

Desktop Pilot 0.2.2 improves batch shortcut import, small-window layouts, setup continuity and complete disable controls. Select multiple files, paste one path per line or drag shortcuts into the window. New entries appear immediately without losing existing rules or history. Setup can be saved and resumed without enabling observation. Disabling the app from Data persists through opening Settings and updates until you explicitly resume.

The release fixes consecutive undo of shortcut replacements, partial database initialization, stale command replay after restart, recovery after executable replacement fails, and long observation periods interrupted by brief visits. Tray unavailability no longer terminates background work. Discovery includes the shared desktop and preserves custom-protocol address identity. Large catalogs reuse an indexed ranking calculation with unchanged results.

Reports are validated before actions and written atomically. Database, executable and shortcut destinations are protected, including Windows short-name aliases. Publication checks the exact commit and uploaded asset digests before making the release public.

To upgrade, close Settings, extract **DesktopPilot-0.2.2-windows-x64.zip** and run `desktop-pilot.exe`. Your profile and a backup of the previous executable are retained. Disabled profiles remain disabled. This is an unsigned preview for Windows 10/11 x64 with Explorer; the C runtime is included. Verify the archive against **SHA256SUMS.txt**.
