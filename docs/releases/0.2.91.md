# Desktop Pilot 0.2.91 — сохранение ручных правил при одновременном обновлении каталога

## Что улучшено

**Ручной выбор «Всегда» или «Никогда» больше не может перезаписать новые данные приложения из-за параллельной операции.** Раньше сохранение правила читало карточку приложения до получения права записи в SQLite. Если одновременно обновлялись название ярлыка или пользовательская заметка, запись правила могла вернуть старую карточку поверх нового изменения.

Теперь чтение и сохранение ручного правила выполняются в одной защищённой транзакции. Новые названия и заметки сохраняются вместе с пользовательским выбором. Повторная смена «Всегда» на «Авто» также не теряет эти данные. Оригиналы ярлыков и файлы рабочего стола не изменяются. Формат базы, прежние настройки, откат и полностью локальная работа сохранены; телеметрия не добавлена.

## Проверки

Добавлен воспроизводимый тест на двух независимых соединениях с настоящей SQLite-базой Desktop Pilot. Одно соединение обновляет данные карточки, удерживая блокировку записи; второе пытается сохранить правило. Тест проверяет, что второе соединение не читает устаревшую карточку, а после освобождения записи видит новое имя и заметку. Проверяются оба перехода: сохранение «Всегда» и возврат к «Авто». [Исследование и условия сценария](../research/2026-11-02-concurrent-policy-metadata.md).

Используется существующий обязательный набор проверок Windows Server 2022 и 2025: форматирование, тесты Rust, строгий Clippy, сборка, нативная интеграция, инструкция и проверка процедуры выпуска. Сборка релиза проходит дополнительную проверку Windows x64 и целостности опубликованных архивов. Синтетическая конкуренция записей подтверждает корректность заданного сценария, а не измеренную экономию времени у людей.

Остаются физические испытания Windows 11, длительное совместное использование с проводником, масштабирование интерфейса 100–200%, отключаемые источники и пользовательские испытания.

## Установка

Скачайте **DesktopPilot-0.2.91-windows-x64.zip**, распакуйте и запустите программу. Проверочные суммы — **SHA256SUMS.txt**. Исходный код — **DesktopPilot-0.2.91-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.91 protects user-selected **Always** and **Never** rules against a concurrent catalog or import edit. The policy operation now takes the SQLite writer before reading and updating a shortcut record. Newly edited display names and user notes are preserved, including after a subsequent reversal to Auto. Existing original shortcuts, local profiles, Undo and settings remain unchanged; no telemetry or new permissions are introduced.

Two production SQLite connections and a deterministic writer-contention regression cover the stale-read boundary and preserved metadata. This is a synthetic correctness check rather than measured human time savings. Standard strict Windows Server 2022/2025 and release verification gates remain required. Physical Windows 11 and interactive GUI acceptance remain outstanding. The executable remains unsigned.
