Desktop Pilot 0.2.75 — сохранение привычных быстрых ярлыков при переводе системных часов через полночь.

## Что улучшено

Когда Windows переводит часы назад через полночь после работы за компьютером, запись активности за недавно начавшийся день может выглядеть как событие из будущего. Ранее Desktop Pilot полностью исключал её из оценки даже для уже размещённого знакомого ярлыка. Из-за этого программа могла ошибочно предложить заменить полезный ярлык другим приложением.

Теперь сохранённые записи активности не более чем на **24 часа впереди** исправленного времени учитываются **исключительно для ярлыков, которыми Desktop Pilot уже управляет**. Такая запись не получает дополнительного веса за «будущее» время. Новые и ещё не размещённые приложения не получают преимуществ из будущих данных. Явное правило «Никогда» по-прежнему имеет безусловный приоритет. Ручное размещение, сохранённые правила, оригинальные файлы, история и отмена изменений защищены.

Нет новых зависимостей, пользовательских настроек, фоновых служб, обращений в сеть и телеметрии.

## Воспроизведение и проверки

Новый регрессионный сценарий на штатной логике использует настоящую SQLite-базу, разбор Windows `.url` и предварительный просмотр с одним местом на рабочем столе. Он моделирует записанные после полуночи 12 сеансов и два часа корректировки часов назад. До исправления симуляция выявила **одну лишнюю предложенную замену**: [красный CI](https://github.com/TechWisard/desktop-pilot/actions/runs/41185718406) — 342 успешных теста и один воспроизводимо падающий на каждой из двух Windows Server. После исправления [проверки PR #95](https://github.com/TechWisard/desktop-pilot/pull/95) и [Windows CI](https://github.com/TechWisard/desktop-pilot/actions/runs/41186389494) прошли на Windows Server 2022/2025, включая Rust-тесты, строгий Clippy, форматирование, сборку, интеграционные проверки и защиту публикации. Исследование и ограничения: `docs/research/2026-10-31-managed-midnight-boundary.md`.

Это синтетическая проверка правильности выбора в настоящем коде, не измерение экономии времени реальных пользователей. Физический экран Windows 11 при масштабе 200%, сетевые отключения и длительная смена проектов остаются отдельными задачами.

Для Windows x64: распакуйте **DesktopPilot-0.2.75-windows-x64.zip** и запустите `desktop-pilot.exe`. Сверяйте архив с **SHA256SUMS.txt**; исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.75 preserves familiar managed desktop shortcuts when a small backward Windows clock correction crosses midnight. Previously, a freshly recorded local-day usage bucket could suddenly appear future-dated and be excluded from ranking, resulting in an unnecessary suggestion to replace an established shortcut.

Recent day-bucket evidence up to 24 hours ahead of the corrected clock is now retained **only for an already managed shortcut**, without additional future-time weight. Unmanaged candidates cannot gain eligibility from future history. Explicit Never, manual placement, original shortcut bytes, user history and Undo remain protected. No new permissions, dependencies, settings, telemetry or network traffic.

A failure-first regression uses the real SQLite Store, Windows Internet Shortcut reader and production ranking/selection, with an existing one-slot managed copy. Before the correction, the test detected one unwarranted proposed replacement on both Windows Server 2022 and 2025. The fixed code passed the full unchanged Windows Rust, format, strict Clippy, build, native and release-guard checks. These are synthetic correctness checks rather than measured human productivity improvements. Physical Windows 11 at 200% DPI, prolonged workflow changes and actual network disconnections remain unverified. Windows x64 executable is unsigned.
