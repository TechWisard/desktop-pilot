# Desktop Pilot 0.2.89 — защита обучения и достоверности ярлыков

## Что изменилось

**Обучение не завершается преждевременно из-за неправильных дат.** При восстановлении старой истории программа больше не засчитывает некорректные календарные даты или правдоподобно записанные, но находящиеся далеко в будущем дни. Например, 89 настоящих дней и одна дата на 400 дней вперед не должны считаться 90 днями обучения. Если сохранённая будущая дата занимает последнее место в ограниченной истории, она уступает место новому реальному дню, чтобы его пять минут активности могли накопиться.

**Некорректные ссылки Shell не вытесняют работающие приложения.** Проверка Windows Shell namespace теперь отклоняет неполные или неправильные CLSID-идентификаторы, а корректные цели и обычные ярлыки работают по-прежнему.

Завершённое ранее обучение не сбрасывается. Пользовательские правила «Всегда» и «Никогда», оригиналы ярлыков, их размещение, история, настройки и возможность отката сохраняются. Никакой скрытой телеметрии, сети или новых разрешений не требуется.

## Проверка

Использована штатная реализация подсчёта обучения, настоящая база SQLite и последовательность из 150 двухсекундных наблюдений. До исправления восстановленная история с 89 подлинными днями и одной будущей датой ошибочно допускала перестановки; после исправления только 90-й реальный день завершает обучение. Есть регрессии для неправильных дат и сохранения уже завершённого состояния. Отдельные проверки распознают корректные и некорректные Windows Shell CLSID.

На ветке проверены стандартные Windows Server 2022 и Windows Server 2025: форматирование, закрытый набор Rust-тестов с Cargo.lock, Clippy с запретом предупреждений, сборка, интеграционные проверки Windows и проверки публикации. Для итогового коммита выпуска стандартный CI повторяется без отключения защитных этапов. Исследование и сценарии: [будущие даты обучения](../research/2026-11-02-future-saved-learning-days.md), [неверные даты](../research/2026-11-02-learning-invalid-saved-days.md), [Shell CLSID](../research/2026-11-02-shell-namespace-clsid-validation.md).

Это синтетические регрессионные данные, не доказательство выигрыша времени у реальных людей. Физические испытания Windows 11 с изменением часов, интерфейсом на 100–200% и отключаемыми дисками остаются необходимы.

## Установка

Скачайте **DesktopPilot-0.2.89-windows-x64.zip** из этого релиза и распакуйте. Проверить архив можно с помощью **SHA256SUMS.txt**. Архив исходников — **DesktopPilot-0.2.89-source.zip**. Исполняемый файл пока не имеет цифровой подписи.

## English

Desktop Pilot 0.2.89 prevents malformed calendar entries and distant future-dated restored learning records from prematurely enabling automatic changes or blocking a genuine next learning day. Previously completed training is preserved. It also rejects malformed Windows Shell namespace CLSIDs while retaining legitimate shortcuts.

Regressions exercise the actual learning accumulator, SQLite persistence, and valid/invalid Shell identifiers. Existing Windows Server 2022/2025 checks cover Rust tests, native integration, strict formatting and linting, build and release guards. This is not a physical Windows 11 acceptance test or a measured user-time saving. The Windows executable remains unsigned.
