Desktop Pilot 0.2.5 быстрее восстанавливает полезные ярлыки в свободных местах, не меняя привычный порядок без необходимости.

## Исправлено

- **Заполнение пустых мест:** если после удаления, исключения или недоступности нескольких быстрых ярлыков освободились позиции, программа может заполнить их подходящими приложениями за один ближайший пересмотр. Раньше ограничение одной замены ошибочно позволяло заполнить только одну пустоту за пересмотр.
- **Защита стабильности:** лимит обычных замен по-прежнему ограничивает вытеснение существующих ярлыков. Для замены требуется прежнее преимущество в рейтинге — минимум в 1,5 раза и на 3 балла. Ручное закрепление, правила «Не добавлять» и исходные ярлыки сохраняются.
- **Проверяемость:** два новых регрессионных сценария проходят через фактическую функцию выбора приложения, используемую предварительным просмотром и применением изменений. Один проверяет заполнение трёх пустот при лимите одной замены, другой — совместное заполнение двух пустот и ровно одну допустимую замену.

## Проверки и ограничения

В Windows CI проверяются форматирование, модульные и интеграционные тесты, Clippy, сборка и нативные сценарии на средах Windows Server 2022 и 2025. Релизный EXE повторно проверяется перед упаковкой, а скрипт публикации сверяет коммит, теги и SHA-256. Успех этих проверок не является измерением экономии времени для реальных пользователей и не подтверждает поведение всех физических рабочих столов.

Доработка касается только выбора ярлыков: личная статистика, ручные позиции, файлы исходных ярлыков и журналы отката не изменяют свой формат. Программа продолжает работать локально, без скрытой телеметрии.

Для обновления закройте настройки, распакуйте **DesktopPilot-0.2.5-windows-x64.zip** и запустите новый `desktop-pilot.exe`. Пользовательский профиль и данные отката сохраняются. Сверьте SHA-256 с **SHA256SUMS.txt**. Версия остаётся предварительной и не имеет цифровой подписи.

## English

Desktop Pilot 0.2.5 fills genuinely vacant quick-access positions without unnecessarily displacing familiar shortcuts.

- **Vacancy recovery:** an ordinary review can fill several empty quick-access slots at once rather than waiting for one slot per review interval. Empty-slot additions no longer count against the existing-shortcut replacement budget.
- **Stable layout:** real replacements still require the configured score advantage and honor the maximum per-review replacement count. Explicit manual choices, original shortcuts and undo history are preserved.
- **Regressions:** two new tests exercise the production selection routine with multiple vacancies, protected positions and competing candidates.

Windows CI checks formatting, unit and integration tests, Clippy, compilation and native fixtures on Windows Server 2022 and 2025. The optimized release EXE is checked again before packaging and SHA-256 verification. These fixtures do not demonstrate measured time savings for real users or all physical desktops. The application remains local and unsigned.

Close Settings, extract **DesktopPilot-0.2.5-windows-x64.zip**, run the new `desktop-pilot.exe`, and verify the supplied **SHA256SUMS.txt**.
