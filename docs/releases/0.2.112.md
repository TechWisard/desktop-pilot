# Desktop Pilot 0.2.112 — защита привычного расположения при удержании клавиш

## Что улучшено

Автоматическая подстройка рабочего стола теперь **не начинает и не завершает перестановку быстрых ярлыков, пока удерживаются Ctrl, Shift, Alt или клавиша Windows**. Раньше программа проверяла только удержание кнопок мыши и время последнего события ввода. Если клавиша оставалась нажатой без новых событий более 15 секунд, компьютер ошибочно мог считаться свободным для перестановки.

Дополнительно перед разрешением изменений проверяется, что активное окно не сменилось во время оценки его размеров. Это защищает от применения решения, рассчитанного для уже неактивного окна. Сохраняются прежние условия по времени бездействия, проверка полноэкранных приложений и защита от перетаскивания мышью. Не меняются правила «Всегда» / «Не добавлять», история, исходные ярлыки, права доступа, настройки, откат и локальная работа.

## Как проверено

Регрессионный тест использует тот же обработчик состояний клавиш, что и рабочая проверка перед размещением: проверяет Ctrl, Shift, Alt, Win, пять кнопок мыши, отсутствие нажатий и обычную клавишу. Существующие интеграционные сценарии Desktop Pilot дополнительно проверяют отказ от записи SQLite и перемещения ярлыков, если поздняя проверка обнаружила активность пользователя.

[Исследование и границы проверки](../research/2026-11-04-held-input-quiet-review.md). Полные штатные проверки Rust, форматирования, строгого Clippy, сборки, нативных интеграционных сценариев и защиты выпуска выполняются на Windows Server 2022 и 2025. Синтетические проверки не являются измерением экономии времени реальных пользователей. Остаются испытания с реальными клавиатурами, окнами и масштабированием 100–200% на Windows 11.

## Установка

Скачайте **DesktopPilot-0.2.112-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверьте контрольную сумму по **SHA256SUMS.txt**. Архив исходников: **DesktopPilot-0.2.112-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

**Desktop Pilot 0.2.112** defers automatic desktop shortcut changes while Ctrl, Shift, Alt or either Windows key is physically held. Previously, the idle check covered mouse buttons and the time of the last input event, but not sustained modifier-key holds without new events. It also verifies that the foreground window has not changed while assessing whether the desktop is quiet.

The existing idle interval, fullscreen/drag safeguards, explicit placement rules, history, source files and Undo behavior are unchanged. No extra input hooks, background services, settings, telemetry or network requests are added.

The regression drives the actual held-input predicate used by the Windows guard, and the existing native/SQLite scenarios protect the late-cancellation behavior of automatic reviews. Normal Windows Server 2022/2025 format, locked tests, strict Clippy, build, native integration and release guards are required. The synthetic checks do not establish measured user time savings or replace physical Windows 11 keyboard, focus and 100–200% DPI acceptance. See the [research and reproducible scenario](../research/2026-11-04-held-input-quiet-review.md).
