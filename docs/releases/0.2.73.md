Desktop Pilot 0.2.73 — точное состояние автоматической проверки на главном экране.

## Что улучшено

На главном экране Desktop Pilot ранее мог сообщать, что автоматическое обновление быстрых ярлыков произойдёт при ближайшем бездействии, даже если пользователь приостановил наблюдение. Но сама программа правильно запрещала автоматические изменения. Теперь главный экран явно объясняет, что обновление приостановлено, пока наблюдение выключено; если фоновая работа отключена отдельно, это тоже отражается.

Дополнительно исправлено объяснение даты проверки при переводе системных часов назад. Когда прежняя отметка проверки оказалась далеко в будущем, реальный механизм восстановления уже разрешал ближайшую проверку, а главный экран мог показывать дату через несколько недель. Теперь экран использует ту же проверку срока, что и рабочий механизм, и не создаёт ложных ожиданий.

**Настоящее расписание, ручное «Применить», исходные ярлыки, пользовательские правила «Всегда»/«Никогда», история и отмена действий не менялись.** Никаких новых фоновых процессов, сетевых зависимостей и телеметрии.

## Проверка и ограничения

Ошибка сообщения при выключенном наблюдении сначала воспроизведена тестом реального Settings/SQLite, без изменения алгоритма размещения: [Windows CI 41169001740](https://github.com/TechWisard/desktop-pilot/actions/runs/41169001740) завершился именно на новом утверждении с неверным текстом на Windows Server 2022 и 2025. Исправление затем прошло [проверки исходной ветки](https://github.com/TechWisard/desktop-pilot/actions/runs/41169332142) и [PR #91](https://github.com/TechWisard/desktop-pilot/pull/91) с [CI 41169343919](https://github.com/TechWisard/desktop-pilot/actions/runs/41169343919): тесты Rust, форматирование, строгий Clippy, сборка, нативные сценарии и защиты публикации на Windows 2022/2025. Подробности — `docs/research/2026-10-31-review-schedule-status.md`.

Это синтетический порядок событий на реальном коде приложения, **не** измерение производительности людей. Не выполнена физическая проверка интерфейса Windows 11 при 200% масштабе, длительные отключения настоящих сетевых каталогов и наблюдения за многодневными сменами проектов.

Для Windows x64: распакуйте **DesktopPilot-0.2.73-windows-x64.zip**, запустите `desktop-pilot.exe` и проверьте архив по **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.73 makes the Home screen's next-review message reflect the actual automatic-review permissions and scheduling predicate. When observation is paused, Home no longer promises unattended shortcut changes. When background work has been explicitly turned off, it says so. After a large backward system-clock correction, Home no longer displays a misleading review date weeks away while the production reviewer considers the review due.

No changes to the placement engine's scheduling policy, manual Apply, original shortcuts, Always/Never choices, history or Undo. No new telemetry or dependencies. A failure-first regression on the real Settings/SQLite path reproduced the incorrect Home message on both Windows Server 2022 and 2025. The correction passed the repository's Windows Rust, strict Clippy, native and release-guard checks. Synthetic correctness evidence is not a human productivity measurement. Physical Windows 11 at 200% display scale, real network disconnections and multiday project-change use remain unverified. Windows x64 executable is unsigned.
