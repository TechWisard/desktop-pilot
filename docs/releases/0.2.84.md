Desktop Pilot 0.2.84 — защита пользовательских сценариев и установочных файлов при экспорте отчётов.

## Что исправлено

Параметр `--out` сохраняет диагностический отчёт как JSON. Раньше ошибочно указанный путь к существующему `.cmd`, `.bat`, `.ps1`, `.vbs`, `.hta`, `.msi` или `.reg` допускался, поэтому отчёт мог заменить полезный пользовательский файл.

Теперь распространённые исполняемые файлы, сценарии Windows, установочные пакеты и файлы реестра нельзя использовать как место сохранения JSON-отчёта. Проверка выполняется ещё до применения или отмены размещения ярлыков. Обычные отчёты `.json` по-прежнему записываются атомарно, включая разрешённое обновление ранее созданного отчёта.

Изменение не затрагивает алгоритм рекомендаций, размещение значков, правила «Всегда» и «Никогда», историю, настройки, SQLite, исходные ярлыки и откат. Новые службы, телеметрия и сетевые обращения не добавлены.

## Проверка

Регрессионные тесты используют настоящие функции проверки и записи отчётов и файлы с искусственными данными в изолированном временном каталоге. Проверяются сохранение исходных байтов восьми защищённых файлов, запрет на запись по их путям, успешная публикация обычного JSON-отчёта и отсутствие временных файлов. Существующие проверки защищают ярлыки, базу, зарезервированные имена Windows и отказ публикации при заблокированном файле.

[Изменение и сценарий](https://github.com/TechWisard/desktop-pilot/pull/121), [проверенная ветка](https://github.com/TechWisard/desktop-pilot/actions/runs/41350289765), [исследование](https://github.com/TechWisard/desktop-pilot/blob/main/docs/research/2026-11-02-report-script-protection.md).

Автоматизированные проверки Windows Server 2022/2025 не заменяют физическое испытание Windows 11 и интерфейса при масштабировании 200%. Нет измерений экономии времени реальных пользователей.

Для Windows x64 распакуйте **DesktopPilot-0.2.84-windows-x64.zip** и запустите `desktop-pilot.exe`. Проверьте архив по **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.84 protects existing Windows scripts, executable launchers, installers and registry files from accidental replacement by the `--out` JSON report option. Validation rejects these extensions before a file-changing Apply or Undo. Normal JSON reports retain atomic publication. No change to user shortcuts, saved rules, ranking, history, rollback or telemetry.

Production-path tests protect existing script bytes, verify a normal JSON report is still published, and cover temporary-file cleanup. The existing Windows Server 2022/2025 checks remain mandatory, and the release workflow verifies binary/source consistency and uploaded asset digests. A real Windows 11 interactive desktop and measured end-user task times remain outside automated coverage. The Windows executable is unsigned.
