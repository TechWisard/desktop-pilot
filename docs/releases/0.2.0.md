## Интерфейс, которым проще пользоваться

Desktop Pilot 0.2.0 перерабатывает настройку программы и исправляет работу с ярлыками, обновлением и фоновым учётом.

- **Крупнее и свободнее:** увеличенный текст и кнопки, масштаб 100/125/150%, понятная навигация и адаптация к размеру окна.
- **Настройка по шагам:** режим работы, количество ярлыков и период наблюдения, область размещения. Автоматический режим, только наблюдение и ручное управление выбираются понятными карточками.
- **Размещение на схеме:** выберите свободные клетки рабочего стола или поручите программе подобрать область. Точные параметры доступны отдельно.
- **Удобный каталог:** поиск, фильтры, сортировка, страницы и правила для каждого приложения. Ярлыки обнаруживаются на рабочем столе и в меню «Пуск».
- **Предсказуемые действия:** показаны действующие настройки и конкретный следующий состав ярлыков. Черновик можно сохранить или отменить; случайное закрытие его не теряет.
- **Понятное состояние:** видны остановленный фон, выполняемые команды, ошибки и история. Долгие операции выполняются без блокировки окна.

## Исправления

- Различаются приложения с одинаковыми именами. Копии ярлыков больше не могут подменить друг друга.
- Удалённая управляемая копия не приводит к захвату исходного ярлыка. Ручные изменения и переименования определяются по содержимому и идентификатору файла.
- Прерванный откат продолжается по сохранённому журналу; изменённые пользователем файлы не перезаписываются. Незавершённые операции блокируют новые изменения до восстановления.
- Настройки, изменённые в трее и в открытом окне, согласуются без потери независимых правок. Обновления базы выполняются транзакционно.
- Исправлены учёт после сна и перезапуска, подтверждение активности при переключении окон и работа обработчиков ввода.
- Исправлены профили, автозапуск, повторный запуск, восстановление значка после перезапуска Проводника и обработка `.url` в разных кодировках.
- Среда выполнения C включена в EXE: отдельная установка Visual C++ Redistributable не нужна.
- Добавлены значок приложения, сведения о версии в свойствах EXE и поддержка масштаба Windows.

## Обновление с 0.1.1

Закройте открытое окно настроек, распакуйте **DesktopPilot-0.2.0-windows-x64.zip** и запустите новый `desktop-pilot.exe`. Программа обновит установленную копию и перезапустит фон. Настройки, история использования, правила и данные отката сохраняются; прежний EXE остаётся в локальной резервной копии. Права администратора не нужны.

Сборка предназначена для **Windows 10/11 x64** со стандартным рабочим столом Проводника. Это предварительный выпуск без цифровой подписи. Контрольные суммы архивов находятся в **SHA256SUMS.txt**.

## English

Desktop Pilot 0.2.0 introduces larger controls, adjustable interface scale, a three-step setup, separate settings pages, a desktop placement map, searchable app cards and clear saved/draft states. Automatic adaptation, observation only and manual control are easier to configure.

This release fixes duplicate shortcut names, ownership after manual rename or deletion, interrupted undo recovery, concurrent settings changes, activity accounting, profile selection, startup and tray lifecycle, and Internet shortcut encodings. App discovery includes the Start menu. Installation safely replaces the executable while retaining the profile and a backup of the previous executable.

To upgrade, close Settings, extract the Windows x64 ZIP and run the new `desktop-pilot.exe`. Settings, history, rules and undo records are retained. This is an unsigned preview for Windows 10/11 x64 with Explorer. Archive checksums are included in **SHA256SUMS.txt**.
