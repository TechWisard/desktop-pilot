# Desktop Pilot 0.2.108 — очистка статистики действительно сбрасывает незавершённое обучение

## Исправлено

**Очистка истории использования больше не превращает незавершённое обучение в завершённое.** Когда пользователь уже набрал необходимое количество сеансов или дней, но фоновый обзор ещё не подтвердил завершение обучения, команда «Очистить статистику» ранее могла сначала сохранить отметку о завершении, а потом удалить набранные сеансы. В результате новые ярлыки могли появиться без нового периода наблюдения, вопреки выбранному пользователем сбросу.

Теперь очистка удаляет накопленный прогресс незавершённого обучения и не создаёт новую отметку завершения. Если обучение действительно было завершено и сохранено ранее, его завершённое состояние остаётся действительным — очистка статистики не заставляет пользователя повторять первоначальную настройку. Существующие ярлыки, ручные правила, настройки, история размещений и возможность отката сохраняются.

## Воспроизведение и проверки

[Технический сценарий, первичные источники и ограничения](../research/2026-11-04-clear-history-unfinished-learning.md). Два регрессионных теста используют настоящие команду очистки, SQLite-профиль и последующий фоновый обзор. На прежней логике тест с незавершённым обучением падал на обеих Windows Server: 409 других тестов проходили, а новое условие показывало ошибочную отметку завершения. Исправление сохраняет уже завершённое обучение, не пропускает новое и не нарушает предыдущие проверки большого каталога, ручного выбора, файлов и Undo.

Стандартный Windows CI выполняет форматирование, тесты Rust, строгий Clippy, сборку, нативные интеграционные проверки и проверки публикации на Windows Server 2022 и 2025. Технические симуляции не заменяют физические испытания Windows 11, интерактивное масштабирование интерфейса или измерение экономии времени людей.

## Установка

Скачайте **DesktopPilot-0.2.108-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Проверьте опубликованный **SHA256SUMS.txt**. Исходный код находится в **DesktopPilot-0.2.108-source.zip**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.108 fixes an explicit user-control inconsistency: clearing usage statistics after accumulating enough observation sessions, but before learning completion was committed, could silently mark that discarded learning as permanently complete. Clearing now resets unfinished progress without granting completion. Learning **already completed and saved** before the clear remains complete. Shortcut files, manual rules, positions, existing transaction history, and Undo are not changed.

Failure-first production-path regressions replay the actual clear-history command, SQLite state and subsequent idle review; the pending-completion assertion failed on the previous implementation on both stock Windows Server runners. Related finished-learning, large-catalog, file-integrity and Undo regressions remain. Standard CI covers Rust tests, formatting, strict Clippy, locked build, native integration and release guards. No physical Windows 11 testing or measured end-user time savings are claimed.
