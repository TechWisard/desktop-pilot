Desktop Pilot 0.2.23 устраняет самопроизвольное добавление и замену ярлыков в ручном режиме.

## Что изменилось

Когда выбран режим **«Управлять вручную»**, кнопка «Применить сейчас» теперь выполняет только предусмотренные пользователем изменения. Ранее сохранённая статистика могла сама добавить популярное приложение или заменить привычный ярлык, несмотря на выключенную автоматику и сбор статистики. Теперь предложения можно по-прежнему посмотреть, но они не изменяют рабочий стол без ручного выбора «Всегда на столе».

Переключение между режимами проверено на последовательности действий: ручной выбор → наблюдение с подтверждённым применением → возвращение в ручной режим → запрет приложения → безопасная отмена. Уже созданные копии, позиции, исходные ярлыки, история и собственные правила сохраняются. Уменьшение числа мест и явное «Не добавлять» продолжают действовать. Режим «Только наблюдать» по-прежнему разрешает применять рекомендации вручную.

Регрессионные тесты воспроизвели неправильный выбор и лишнюю замену на прежнем коде. Это проверки корректности пользовательских решений, а не измеренная экономия времени реальных людей. Не добавлены настройки, зависимости, службы или телеметрия.

## English

Desktop Pilot 0.2.23 makes **Manual control** honor your choices. Previously saved usage rankings could add new shortcuts or replace familiar ones when you clicked Apply now despite automatic adaptation and usage collection both being off. Manual mode now keeps existing managed shortcuts stable and adds only apps explicitly marked Always, while still respecting Never and reduced capacity. Saved recommendations remain available as information, not unrequested changes.

The regression covers switching Manual → Observe → Manual, deliberate proposal application, new activity, explicit Never and a real SQLite/Windows-shortcut Undo path. Observe-only continues to let you apply recommendations; existing originals, local history, manual positions and privacy remain unchanged. No new services, dependencies, settings or telemetry.
