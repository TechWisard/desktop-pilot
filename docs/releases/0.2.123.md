# Desktop Pilot 0.2.123 — точный поиск ярлыков по скопированному пути

## Что исправлено

**При поиске по полному пути из Проводника больше не смешиваются два разных одноимённых ярлыка.** Например, на диске одновременно существуют папка с буквальным названием `%USERNAME%` и папка с реальным именем пользователя. Раньше поиск на вкладке «Приложения» дополнительно разворачивал переменные окружения в уже существующих путях; в результате вместо нужного ярлыка могли показываться оба, хотя у них разные пользовательские правила «Всегда» и «Не добавлять».

Теперь конкретный абсолютный путь и уже сохранённое имя исходного файла сравниваются как буквальные Windows-пути. Ввод сокращённого пути `%SystemRoot%\...`, поиск по названию, сортировка, фильтрация и правила запуска сохраняют прежнее поведение. Исправление касается только поиска и не трогает исходные файлы, базу, историю, ручное расположение и настроенные правила.

## Воспроизведение и проверка

[PR #218](https://github.com/TechWisard/desktop-pilot/pull/218) содержит регрессию: две настоящие разные папки Windows и два одноимённых `.url` с разными целями считываются штатным Windows-парсером ярлыков, сохраняются в SQLite и находятся реальным механизмом поиска каталога. Проверяются оба порядка выбора, фильтры разных ручных правил, пути в кавычках, прямые и обратные разделители, чужая заметка со ссылкой на другой путь, отсутствие ложных совпадений и неизменность исходных файлов.

Для исправления завершились полные штатные проверки на Windows Server 2022 и 2025, в том числе 427 Rust-тестов, форматирование, строгий Clippy, сборка, нативные сценарии и проверки защиты публикации: [PR-проверка](https://github.com/TechWisard/desktop-pilot/actions/runs/42294698569) и [проверка ветки](https://github.com/TechWisard/desktop-pilot/actions/runs/42294691492). Примеры синтетические, но файлы, Windows-парсер и SQLite настоящие; это не статистика экономии времени реальных пользователей. [Причина и ограничения](../research/2026-11-06-literal-copied-path-search.md).

Перед публикацией автоматическая сборка релиза отдельно проверяет Windows x64 PE, версию бинарного файла, зависимости, диагностические сценарии, целостность архивов и SHA-256. Выпуск не объявляет законченной отдельную функцию организации рабочего стола: она остаётся в [PR #211](https://github.com/TechWisard/desktop-pilot/pull/211) до интерактивной приёмки на Windows 11 x64, OneDrive и нескольких мониторах.

## Установка

Скачайте `DesktopPilot-0.2.123-windows-x64.zip` из [релизов](https://github.com/TechWisard/desktop-pilot/releases), распакуйте и запустите `desktop-pilot.exe`. Существующую папку профиля, базу `usage.sqlite` и историю сохраняйте. Сверьте `SHA256SUMS.txt`; сборка не подписана цифровой подписью.
