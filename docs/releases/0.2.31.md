Desktop Pilot 0.2.31 уменьшает лишнюю работу при обновлении больших каталогов ярлыков.

## Что изменилось

При повторной проверке сотен и тысяч сохранённых ярлыков программа больше не перебирает весь каталог для поиска совпадения каждого обнаруженного приложения. Сопоставление выполняется через индекс полного адреса запуска, включая параметры профиля. Это сокращает вычислительную работу на больших наборах и сохраняет прежнюю логику выбора исходного ярлыка при совпадающих запусках.

Проверены каталоги из 100 и 1 000 настоящих ярлыков Windows с ручными правилами «Всегда» и «Не добавлять», историей, предварительным просмотром, размещением и откатом. Количество вычислений идентификаторов ограничено линейной проверкой. Это не измерение экономии времени пользователя и не замер физического сетевого диска.

Не изменены исходные файлы, действующие быстрые ярлыки, их расположение, правила, история, настройки, база данных, зависимости и телеметрия.

Скачайте **DesktopPilot-0.2.31-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.31 reduces redundant computation when rescanning large saved shortcut catalogs. Rather than comparing each discovered shortcut against the entire list, the scanner indexes complete launch identities once. The first-match semantics, distinct launch arguments, existing manual decisions and recovery behavior are preserved.

Production-path Windows/SQLite regressions cover 100 and 1,000 real shortcut files, Always/Never rules, usage history, stable quick copies, preview and Undo. Identity-evaluation bounds check linear work. This is not a claim of measured human task-time or real network-drive speedup.

Original shortcuts, layout, settings, history, dependencies and telemetry are unchanged. Download **DesktopPilot-0.2.31-windows-x64.zip** and verify **SHA256SUMS.txt**. The executable is unsigned.
