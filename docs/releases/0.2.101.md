# Desktop Pilot 0.2.101 — корректный выбор интернет-ярлыков

## Исправлено

**Некорректные интернет-адреса больше не вытесняют рабочие ярлыки.** При импорте файлов `.url` Desktop Pilot теперь проверяет недопустимые и неправильно закодированные символы в имени сервера HTTP(S)-адреса. Ранее адрес вроде `https://work%2Fproject.invalid/dashboard` мог считаться пригодным для открытия, и накопленная история использования позволяла ему занимать одно из ограниченных мест быстрого доступа. Теперь этот ярлык исключается из автоматических рекомендаций; исправный кандидат сохраняет место.

Обычная кодировка адреса в пути, параметрах, имени пользователя и допустимых буквах имени сервера не блокируется. Исходные файлы не переписываются, ручные правила «Всегда» и «Никогда», размещение, история, отмена изменений и автономная работа сохранены. Скрытая телеметрия не добавлена.

## Проверка

[Воспроизводимый сценарий](../research/2026-11-03-percent-encoded-host-shortcuts.md) использует настоящие Windows Internet Shortcut, SQLite, производственную проверку адреса и предпросмотр рекомендаций с одним доступным местом. До исправления регрессия падала на обеих проверяемых Windows; после исправления проверки прошли. Набор также защищает допустимые варианты кодирования. Стандартные проверки включают форматирование, Rust-тесты, строгий Clippy, сборку, нативные интеграционные сценарии и контроль выпуска на Windows Server 2022/2025.

Это синтетическая проверка правильности рекомендации, а не измеренная экономия времени реальных пользователей. Работа настоящего браузера, интерфейс Windows 11, масштабирование 100–200% и долгосрочные изменения привычек отдельно не проверялись.

## Установка

Скачайте **DesktopPilot-0.2.101-windows-x64.zip**, распакуйте и запустите. Проверьте SHA-256 по **SHA256SUMS.txt**. Архив исходников: **DesktopPilot-0.2.101-source.zip**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.101 prevents malformed HTTP(S) Internet Shortcut hostnames from taking scarce quick-access places. Percent-encoded forbidden host bytes and malformed escapes no longer make an imported `.url` appear usable. Legitimate encodings in the URL path, query, userinfo and hostname letters remain supported. Original shortcuts, manual Always/Never choices, history, locations, Undo and offline operation are unchanged.

Native Windows `.url` parsing, SQLite and the production recommendation preview are exercised in regression tests; the failing behavior was reproduced before the correction. CI verifies the source and release packaging on Windows Server 2022/2025. Interactive Windows 11 use, actual browser behavior, interface scaling and human productivity gains remain unmeasured.
