Desktop Pilot 0.2.4 точнее распознаёт приложения Windows и помогает работать с несколькими профилями одного приложения.

## Исправления

- **Системные приложения:** проверенные цели запуска `shell:`, пространства имён Windows и зарегистрированные URI-протоколы больше не получают ошибочное «Не добавлять» при первоначальном обнаружении только потому, что цель не похожа на путь к EXE.
- **Поиск профилей:** в разделе «Приложения» можно искать по аргументам командной строки, рабочему каталогу и пользовательским заметкам, отличая одноимённые ярлыки.
- **Сохранение правил:** старые и новые пользовательские правила «Не добавлять» не снимаются автоматически. Если нужное системное приложение было исключено старой версией, измените правило на «Автоматический выбор» вручную.

## Проверка и границы

Тесты Windows проходят через настоящий код обнаружения Shell-ярлыка, распознавания App ID, учёта использования, рейтинга, предварительного просмотра, безопасного копирования и ручного исключения. Проверяются байты исходного файла и поиск разных профилей. Это не заменяет интерактивное тестирование всех сторонних приложений и URI-обработчиков. Выпуск остаётся предварительным, без цифровой подписи.

Для обновления закройте настройки, распакуйте **DesktopPilot-0.2.4-windows-x64.zip** и запустите `desktop-pilot.exe`. Настройки, правила, история и данные отката сохраняются; резервная копия старого EXE остаётся. Сверьте контрольные суммы с **SHA256SUMS.txt**.

## English

Desktop Pilot 0.2.4 improves Windows application discovery and search for distinct profiles of the same program.

- **Recognized Shell targets:** valid `shell:`, Windows namespace and registered URI targets no longer receive accidental **Never add** rules merely because they lack a physical EXE path; unresolved invalid targets remain excluded.
- **Profile search:** locate shortcuts using command-line arguments, working directories and personal notes.
- **Manual choices:** persisted Never rules are never lifted silently, even if an older version set one on a valid system app. Change the rule explicitly if desired.

Windows regression tests cover real catalog discovery, App ID recognition, qualified usage, ranking, preview, safe copying, original-file preservation, manual exclusions and profile search. They do not establish interactive launch success of every URI handler. This remains an unsigned preview for Windows 10/11 x64 with Explorer.

Close Settings, extract **DesktopPilot-0.2.4-windows-x64.zip** and run the new `desktop-pilot.exe`; existing settings, usage history and rollback information are retained. Verify archives against **SHA256SUMS.txt**.
