# Desktop Pilot 0.2.102 — сохранение прогресса первоначального обучения

## Исправлено

**Ошибочная календарная запись больше не обнуляет незавершённый сеанс обучения.** Если после восстановления локального профиля поступит некорректная календарная дата одновременно с более ранней временной отметкой, Desktop Pilot теперь отклонит такую запись *до* проверки перевода часов. Раньше одна недействительная запись могла сбросить уже накопленные минуты ещё не завершённого сеанса и отложить появление первых рекомендаций.

Это защитный случай для ошибочного входного состояния: штатный фоновый процесс получает корректную локальную дату Windows. Не изменены обычное обучение, требования к продолжительности сеанса, сохранённые завершённые сеансы, ручные закрепления, исходные ярлыки, история и возможность отката. Новые службы, настройки и телеметрия не добавлены.

## Проверки

[Исследование и регрессионный сценарий](../research/2026-11-03-malformed-learning-day-rewind.md) используют настоящее хранилище SQLite, сохранение и повторное открытие профиля, производственную логику наблюдения, проверку выполнения условий и последующее сохранение. Сценарий: 240 подтверждённых секунд, две неверные календарные записи с более ранними отметками, затем 60 реальных секунд. Прогресс должен остаться целым, и обучение должно учесть ровно один завершённый сеанс. Ошибка до исправления установлена по коду, отдельный падающий CI со старой версией не запускался.

Стандартные проверки проекта выполняются на Windows Server 2022 и 2025: форматирование, Rust, строгий Clippy, сборка, нативные интеграционные сценарии и контроль публикации. Это не подтверждение реальных изменений системных часов, масштабирования интерфейса Windows 11 или экономии времени пользователя.

## Установка

Скачайте **DesktopPilot-0.2.102-windows-x64.zip**, распакуйте и запустите программу. Сверьте контрольную сумму файла с **SHA256SUMS.txt**. Исходники: **DesktopPilot-0.2.102-source.zip**. Исполняемый файл не имеет цифровой подписи.

## English

Desktop Pilot 0.2.102 preserves unfinished first-use learning when an invalid calendar sample is paired with an earlier wall-clock timestamp. Invalid samples are rejected before they can reset a previously saved partial session. Regular foreground monitoring supplies valid local dates, so this is a defensive recovery fix rather than a common observed Windows failure. User shortcuts, manual preferences, placement, Undo, offline operation and local privacy remain unchanged.

The regression exercises production learning logic and a real SQLite profile through save, reload and gate completion. Windows CI checks the source and packaging. Physical Windows 11 clock/DPI behavior and human time savings remain unmeasured.
