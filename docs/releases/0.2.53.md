Desktop Pilot 0.2.53 no longer keeps system-wide keyboard and mouse hooks installed when activity tracking is paused.

## Что изменилось

В ручном режиме фоновый процесс теперь обслуживает значок в трее, правила ярлыков и команды пользователя без установки низкоуровневых перехватчиков ввода Windows. При переходе к наблюдению перехватчики создаются только при необходимости, а при паузе освобождаются. При возобновлении не создаются дублирующиеся обработчики. Если режим меняется или пользователь выключает программу во время установки, незавершённое подключение не активируется.

Ручное размещение, история, исходные ярлыки, уже созданные копии, правила Always/Never и Undo не менялись. Новых служб, аккаунтов, сетевых запросов, настроек или телеметрии нет.

Проверки охватывают повторные переходы между ручным режимом и наблюдением, одновременное выключение и установку обработчиков, штатный запуск и остановку фонового процесса. Тесты проверяют жизненный цикл, но не устанавливают экономию энергии на реальном компьютере.

Windows x64: распакуйте `DesktopPilot-0.2.53-windows-x64.zip` и запустите `desktop-pilot.exe`. Контрольные суммы в `SHA256SUMS.txt`. Исполняемый файл не подписан цифровой подписью.

## English

The background process now runs manual-only control without installing system-wide low-level keyboard/mouse hooks. Starting activity observation installs one set of hooks only when needed; pausing releases them. A concurrent Turn off or mode switch during installation prevents activation of stale hooks. Existing rules, user files, positions, history and Undo remain unchanged. No new service, account, telemetry or dependencies. Windows x64 executable is unsigned.

Windows CI exercises real program and native shortcut behavior along with mode-lifecycle and concurrent-stop regressions. No physical Windows 11 battery or user productivity measurements are claimed.
