Desktop Pilot 0.2.74 — стабильные привычные ярлыки после небольшой корректировки часов Windows.

## Что улучшено

Если Windows переводит системное время назад на несколько часов, Desktop Pilot больше не теряет всю ранее накопленную оценку важности уже размещённого программой ярлыка только из-за даты сохранения. Раньше это могло привести к неожиданному предложению заменить привычный ярлык менее полезным приложением при очередном пересмотре.

Сохранённая оценка учитывается без дополнительного старения, только если ярлык **уже управляется Desktop Pilot**, дата сохранения находится **не более чем на 24 часа впереди** текущего времени и оценка корректна. Для новых и неуправляемых ярлыков будущая дата по-прежнему не подтверждает рекомендацию. Необычно далёкие будущие отметки остаются недостоверными. Явное правило «Никогда» всегда имеет приоритет.

Обычное ранжирование, пользовательские перестановки, правила «Всегда» и «Никогда», исходные ярлыки, история и отмена не менялись. Нет новых зависимостей, телеметрии, фоновых служб, обращения в сеть или переноса пользовательских данных.

## Проверка

Регрессионный сценарий работает с реальной SQLite-базой, исходными Windows .url-ярлыками, применением рабочего стола и штатным предпросмотром. Сначала он воспроизвёл ошибочную замену на неизменённом коде: [Windows CI 41170859229](https://github.com/TechWisard/desktop-pilot/actions/runs/41170859229), обе системы Windows Server 2022/2025 — 341 успешный тест и один специально падающий. Исправленная ветка и [PR #93](https://github.com/TechWisard/desktop-pilot/pull/93) прошли [Windows CI 41172035905](https://github.com/TechWisard/desktop-pilot/actions/runs/41172035905) на обеих системах: Rust, форматирование, строгий Clippy, сборка, нативные сценарии и защитные проверки выпуска. Технические ограничения и правила — `docs/research/2026-10-31-recent-rewind-seed-stability.md`.

Это проверка синтетической последовательности событий на настоящем коде программы, а не доказанная экономия времени реального человека. Отдельно не проверены физическая Windows 11 с масштабом 200%, реальные сетевые отключения, многодневное изменение рабочих привычек и последствия больших корректировок часов.

Для Windows x64: распакуйте **DesktopPilot-0.2.74-windows-x64.zip**, запустите `desktop-pilot.exe` и сверяйте архив с **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.74 prevents an already managed, familiar shortcut from losing its entire historical priority following a small backward Windows wall-clock correction. Previously, a future-dated saved checkpoint could discard the score and prompt an unnecessary swap with a less useful shortcut.

The existing historical score is retained, with zero elapsed aging, only for a shortcut that Desktop Pilot already owns and only when the valid saved checkpoint lies at most 24 hours ahead. Newly discovered or unmanaged shortcuts do not gain eligibility from future timestamps; farther-ahead checkpoints remain untrusted. Explicit Never overrides the recovered history. Original files, manual placements, Always/Never rules, Undo, local-only operation and privacy behavior are preserved. No new dependencies or telemetry.

The regression first reproduced the unwanted replacement with the production SQLite, native Windows shortcuts, real desktop apply and preview paths, and then passed unchanged Windows Server 2022/2025 Rust, formatting, strict Clippy, build, native integration and publication-guard checks. These are synthetic correctness tests, not measured human productivity gains. Physical Windows 11 at 200% scaling, real network outages, multi-day project transitions and large clock corrections remain unverified. Windows x64 executable is unsigned.
