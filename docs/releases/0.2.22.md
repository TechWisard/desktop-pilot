Desktop Pilot 0.2.22 быстрее подготавливает сохранённый список приложений при открытии настроек и после обновления данных.

## Что изменилось

Устранено повторное чтение и разбор всего каталога ярлыков из SQLite на одном обновлении окна. Список приложений и расчёт рекомендуемых быстрых ярлыков теперь используют один согласованный снимок данных: вместо двух полных чтений каталога выполняется одно. Особенно важно для больших сохранённых библиотек после перезапуска и для частых переходов к настройкам.

При этом порядок ручных закреплений рассчитывается до сортировки списка по названиям, чтобы не менять прежние решения пользователя. Поиск по сохранённым данным, явные правила «Всегда» и «Никогда», история, предупреждения при неверных настройках, пользовательские ярлыки и отмена сохранены. Новых зависимостей, фоновых служб или телеметрии нет.

Сравнение 2 → 1 относится к числу обращений к каталогу в программе, а не к измеренному ускорению на реальном компьютере. Проверки охватывают сохранённые каталоги на 100, 1000 и 5000 записей.

Скачайте **DesktopPilot-0.2.22-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не имеет цифровой подписи.

[Подробности и границы проверки](https://github.com/TechWisard/desktop-pilot/blob/v0.2.22/docs/research/2026-10-27-catalog-snapshot.md)

## English

Desktop Pilot 0.2.22 avoids re-reading and parsing the entire saved shortcut catalog twice for each Settings startup or refresh. The visible app list and recommendation preview share one consistent SQLite snapshot, reducing full catalog reads from two to one. This is a verified operation-count reduction, not a measured improvement in real-world startup time.

Selection still uses the original ID order before the on-screen list is sorted by name. Saved search, manual Always/Never choices, history, invalid-settings warnings, original shortcuts and Undo remain unchanged. Regression fixtures cover 100, 1,000 and 5,000 persisted entries, including an unavailable optional source drive. No added service, dependency, telemetry or settings. Download **DesktopPilot-0.2.22-windows-x64.zip** and verify **SHA256SUMS.txt**. The executable is unsigned.
