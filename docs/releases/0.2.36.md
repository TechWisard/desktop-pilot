Desktop Pilot 0.2.36 позволяет обнаруживать большие каталоги из 5 000 ярлыков без прежнего ограничения на 3 000.

## Что изменилось

При первом поиске приложений с рабочего стола и из меню «Пуск» программа теперь обрабатывает до 6 000 ярлыков за одну проверку. Раньше на 3 000 поиск прерывался, поэтому в крупном каталоге часть приложений отсутствовала в списке и не могла быть выбрана вручную. Ограничение сохранено, чтобы случайно не обходить безграничные деревья папок; при его достижении показывается предупреждение на выбранном языке, а уже сохранённые приложения остаются в каталоге. Старые сообщения об ограничении в 3 000 ярлыков продолжают правильно отображаться в истории.

Проверка больших каталогов использует существующее отдельное фоновое сканирование. Изменение не затрагивает оценку активности, ручные закрепления и запреты, исходные файлы, расположение значков, историю и откат. Новых настроек, служб, зависимостей и телеметрии нет.

Скачайте **DesktopPilot-0.2.36-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Контрольные суммы — **SHA256SUMS.txt**. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.36 supports discovering a 5,000-shortcut desktop/Start-menu catalog instead of stopping after the previous 3,000-link bound. Discovery remains bounded to 6,000 shortcuts to protect against unexpectedly large directory trees. Reaching that bound still produces a warning, and previously saved catalog entries are retained.

This change uses the existing background scanning path; it does not alter automatic ranking, manual Always/Never decisions, file contents, desktop placement, history, Undo, dependencies or telemetry. The new Windows/SQLite regression creates 5,000 real inert internet shortcuts, checks catalog completeness and then verifies that manual rules survive a second scan. Synthetic catalog counts are not user task-time measurements.

Download **DesktopPilot-0.2.36-windows-x64.zip** and verify **SHA256SUMS.txt**. The executable is unsigned.
