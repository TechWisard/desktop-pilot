# Desktop Pilot 0.3.0 — «Навести порядок»

## Главное изменение

Функция упорядочивания рабочего стола включена в основной выпуск. Откройте **«Использование → Навести порядок»**: программа покажет, какие ярлыки можно объединить в тематические папки. Проверьте план, снимите выбор с нужных вам объектов и подтвердите действие. Анализ сам по себе ничего не перемещает, а уборка никогда не запускается по расписанию.

По умолчанию обрабатываются ярлыки `.lnk` и `.url`. Обычные файлы требуют отдельного включения. Папки проектов, программы, скрипты, облачные заполнители и специальные ссылки не переносятся. Уже существующие чужие папки не присваиваются программе. Ручные правила, быстрые ярлыки и известные зависимости файлов сохраняют приоритет.

## Предсказуемое применение и отмена

Перед операцией повторно проверяются все объекты, включая оставленные на месте. Изменение, удаление или подмена файла после просмотра отменяет устаревший план до начала переноса. Решение оставить всё можно запомнить без перемещений и лишней записи отмены.

Исходники перемещаются в пределах личного локального рабочего стола с сохранением идентичности. Постоянный журнал позволяет восстановить прерванную операцию. Отмена не перезаписывает посторонний файл с совпавшим именем, распознаёт уже возвращённые оригиналы и не сбрасывает их новые ручные позиции. Новые файлы, которые вы добавили в созданную папку, не удаляются.

Исправлена обработка обновляющегося списка значков Explorer: если перенос меняет индексы во время чтения, программа повторяет чтение целиком в пределах ограниченного ожидания. Частичная информация не принимается за свободное место. Постоянная ошибка и смена геометрии экранов остаются явными препятствиями, а не скрываются ради успешного завершения.

## Интерфейс

Предварительный просмотр поддерживает поиск, страницы и индивидуальный выбор. Новый анализ сбрасывает старый фильтр, чтобы предложения не оставались незаметными. Неизменившийся план не пересчитывает размещение при каждой перерисовке. Русский и английский интерфейс проверены в работающем приложении при масштабе 100% и 200%, включая нижние разделы после прокрутки.

## Проверки и границы

Проверены настоящие файловые операции, SQLite/WAL, запуск и остановка фонового процесса, перенос и отмена в Explorer. Отдельный процесс принудительно завершается после первого и последнего переноса; повторное открытие профиля и отмена восстанавливают исходные файлы, правила и историю. Это не имитация отключения питания или неисправного накопителя.

[Полная приёмка объединённой реализации](https://github.com/TechWisard/desktop-pilot/actions/runs/42265853722) прошла на Windows Server 2022/2025 и Windows 11. Тестовая Windows 11 — ARM64 с эмуляцией x64; снимки используют программный рендерер только в тестовой среде. Физические многомониторные конфигурации, аппаратные видеодрайверы и синхронизация с действующей учётной записью OneDrive не сертифицированы. Защитные проверки таких объектов и смены геометрии сохранены. Выпуск дополнительно проходит полный CI и проверку релизного EXE, состава архивов, тега и SHA-256.

Проверки используют синтетические данные и настоящую логику программы. Они подтверждают перечисленные сценарии, но не являются измерением экономии времени реальных пользователей или обещанием отсутствия всех ошибок.

## Обновление

Скачайте `DesktopPilot-0.3.0-windows-x64.zip`, проверьте `SHA256SUMS.txt`, распакуйте и запустите `desktop-pilot.exe`. Существующий локальный профиль, настройки, ручные правила и история сохраняются. EXE не имеет цифровой подписи. Исходники: `DesktopPilot-0.3.0-source.zip`. Новых сетевых служб, учётных записей и телеметрии нет.

## English

Desktop Pilot 0.3.0 adds the explicit **Usage → Organize desktop** workflow: a read-only preview, individual keep choices, optional ordinary files, safe category folders and separate Undo/recovery. It preserves manual rules and file identities, rejects stale plans and conflicting replacements, and does not silently reorganize cloud placeholders or project folders. Actual process-termination recovery, native Explorer round trips and bilingual 100%/200% scrolled UI captures are covered. Windows 11 evidence uses x64 emulation on an ARM64 hosted machine and an app-local software renderer; it is not physical multi-monitor/GPU or live OneDrive-account certification. Existing profiles are retained. Check the published SHA-256 before running the unsigned executable.
