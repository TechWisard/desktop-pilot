# Desktop Pilot 0.2.121 — надёжный импорт разных ярлыков

## Что изменилось

**При добавлении нескольких ярлыков программа больше не пропускает отдельный файл из-за похожего названия каталога.** Например, папка с буквальным именем `%USERNAME%` и папка с настоящим именем пользователя Windows — разные объекты. Раньше повторная подстановка переменной при сравнении двух уже указанных полных путей могла ошибочно считать их одинаковыми. Теперь оба ярлыка попадают в список импорта, а сокращённые пути, которые пользователь действительно ввёл с переменными окружения, продолжают раскрываться.

Это узкое исправление импорта. Оно не меняет алгоритм адаптации, исходные файлы, ручные правила, историю, настройки и наблюдение. Дополнительная телеметрия не добавлена. **Черновое упорядочивание рабочего стола из PR #98 в выпуск не входит.**

## Проверки

Регрессионный тест создаёт два настоящих файла `.url` в разных папках Windows, проверяет ввод обоих абсолютных путей через штатный обработчик, прочитывает цели через штатный считыватель ярлыков и сверяет исходные байты. Тестируется отсутствие ложного объединения при повторном импорте, без переноса или перезаписи файлов.

[Исследование, границы и воспроизведение](../research/2026-11-06-literal-percent-shortcut-import.md). [Проверенный исходный код и CI](https://github.com/TechWisard/desktop-pilot/pull/212). Фикстура показывает два корректно разобранных файла вместо одного, **не измеренное ускорение действий пользователей**. Стандартные проверки Windows Server 2022 и 2025: тесты Rust, форматирование, Clippy, сборка, нативные проверки и тесты публикации. Перед выпуском отдельно должны пройти сборка исполняемого файла, проверки PE и контроль архивов и SHA-256.

Не проводились физические проверки интерфейса Windows 11, OneDrive и масштабирования 100–200% на реальном рабочем столе. Органайзер остаётся черновым до прохождения этих сценариев.

## Установка

Скачайте `DesktopPilot-0.2.121-windows-x64.zip` из [релиза](https://github.com/TechWisard/desktop-pilot/releases/tag/v0.2.121), распакуйте и запустите `desktop-pilot.exe`. Проверяйте `SHA256SUMS.txt`. Исходный архив: `DesktopPilot-0.2.121-source.zip`. Программа не имеет цифровой подписи.

## English

**Desktop Pilot 0.2.121** fixes a false-duplicate check in bulk shortcut import. A literal directory named `%USERNAME%` and a directory whose name is the Windows username can hold distinct `.url` shortcuts with the same leaf name. Both concrete absolute paths now reach the native reader; intentional expansion of abbreviated input paths remains unchanged. Source files, manual policies, history and local-only operation are preserved. Windows CI checks real-file fixtures, not user-time measurements. Draft organizer PR #98 is not part of this release.
