# Desktop Pilot 0.2.126 — разные пути запуска, разные профили

## Исправление

При обнаружении программ Desktop Pilot теперь различает два реальных абсолютных пути: каталог, буквально называющийся `%USERNAME%`, и каталог с именем пользователя Windows. Прежде безусловная подстановка переменных в пути запуска и рабочем каталоге могла объединить их в один идентификатор и смешать отдельные настройки «Всегда» и «Не добавлять». Проверка доступности могла смотреть на другой файл и ошибочно считать нужную программу доступной либо отсутствующей.

Абсолютные пути проверяются буквально; для относительных шаблонов вроде `%SystemRoot%\System32\notepad.exe` подстановка по-прежнему работает. При временной потере файла повторная проверка не использует его одноимённый аналог из другого каталога. Данные SQLite, исходные ярлыки, позиции, история, настройки и пользовательские файлы не переписываются.

## Проверка

[Исследование и регрессия](../research/2026-11-07-absolute-target-identity.md) используют настоящие временные файлы Windows и рабочие функции `native::valid_target`, `App::identity`, SQLite, ранжирование и выбор ярлыка. Проверены независимые правила, их изменение, отсутствие и возвращение исходного файла, разные рабочие каталоги, сохранность содержимого и совместимость сокращённых путей.

[Windows 2022/2025 — проверенный исправленный коммит](https://github.com/TechWisard/desktop-pilot/actions/runs/42374021733): форматирование, Rust-тесты, строгий Clippy, сборка, нативные интеграционные проверки и правила публикации прошли успешно. Публикация релиза выполняет независимые проверки главной ветки, исполняемого файла и архивов. Это регрессии на рабочей логике, а не оценка экономии времени реальными пользователями.

Организация рабочего стола остаётся в [PR #211](https://github.com/TechWisard/desktop-pilot/pull/211) до отдельной приёмки на реальной Windows 11 с разными мониторами, масштабами, OneDrive и восстановлением после прерывания.

## Установка

Скачайте архив **DesktopPilot-0.2.126-windows-x64.zip** с [Releases](https://github.com/TechWisard/desktop-pilot/releases) и сравните SHA-256 с приложенным `SHA256SUMS.txt`. Программа не имеет цифровой подписи.
