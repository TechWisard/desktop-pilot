Desktop Pilot 0.2.8 сохраняет работающие быстрые ярлыки при сокращении числа мест и повышает согласованность статистики после ошибок сохранения.

## Что изменилось

- Если одна из программ временно недоступна, но прежде была востребована, её высокий прошлый рейтинг больше не заставит удалить работающий ярлык при уменьшении числа мест быстрого доступа. Сначала освобождается место за счёт недоступной автоматической копии, без ненужного перемещения оставшихся ярлыков.
- **«Всегда на столе»** по-прежнему важнее автоматического выбора. При неизменном числе мест сохраняется прежняя 72-часовая защита от временной недоступности оригинала. Исходные ярлыки и ручные настройки не изменяются.
- При отказе записи в SQLite оперативная отметка последнего сеанса обновляется только после успешного коммита. Сбой не может продвинуть кэш сеансов относительно отменённой транзакции.

## Проверка и ограничения

Перед исправлением три новых теста воспроизвели ошибки на настоящем коде выбора, управлении файлами и SQLite; остальные 164 теста прошли: [до исправления](https://github.com/TechWisard/desktop-pilot/actions/runs/40325563091). [После исправления](https://github.com/TechWisard/desktop-pilot/actions/runs/40326209390) форматирование, 167 тестов Rust, Clippy, сборка, нативные сценарии и проверки публикации прошли на Windows Server 2022 и 2025. Выпуск отдельно проверяет нативную сборку, версию EXE, содержимое архивов и SHA-256. Сборка предварительная, без цифровой подписи. Испытания на физическом рабочем столе Windows 11 и измерения экономии времени реальных людей не проводились. Это не гарантия автоматического устранения ошибок диска.

Скачайте **DesktopPilot-0.2.8-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Сохранённые данные и настройки остаются на месте. Контрольные суммы — в **SHA256SUMS.txt**.

## English

Desktop Pilot 0.2.8 keeps usable quick-access shortcuts in place when users reduce capacity during a temporary source outage, and makes usage accounting consistent after failed storage writes.

- A temporarily missing app with a high historical score no longer displaces a working, lower-scored owned shortcut when the user lowers the slot count. The unavailable, non-manually-protected copy is removed first. Other positions remain stable.
- Explicit **Always on desktop** selections still take precedence. With unchanged capacity the existing 72-hour temporary-unavailability protection is retained. Original shortcuts, saved preferences and undo controls stay intact.
- A failed SQLite session checkpoint no longer advances the in-memory session history beyond a rolled-back transaction.

Three regressions demonstrated these failures in real production selection, file-copy/preview/apply and SQLite transaction paths ([before](https://github.com/TechWisard/desktop-pilot/actions/runs/40325563091), [after](https://github.com/TechWisard/desktop-pilot/actions/runs/40326209390)). Both Windows Server 2022/2025 jobs passed 167 Rust tests, formatting, Clippy, build, native fixtures and release safeguards. Release publication separately validates the packaged native EXE and checksums. This remains an unsigned preview; physical Windows 11 Explorer interaction and human time savings are not established. Unhandled disk errors are not automatically repaired.

Download **DesktopPilot-0.2.8-windows-x64.zip**, extract and launch `desktop-pilot.exe`. Existing data and settings are preserved. Verify with **SHA256SUMS.txt**.
