Desktop Pilot 0.2.12 устраняет обманчивое предложение удалить уже размещённый ярлык после перевода системных часов назад при недоступном исходнике.

## Что изменилось

- Предварительный просмотр больше не воспринимает сохранённую дату исчезновения исходного ярлыка в будущем как истечение защиты существующей копии. Состав, показанный до применения, соответствует осторожному поведению повторной проверки.
- Правила «Всегда», ручные перемещения и запрет «Не добавлять» сохраняют приоритет. Для обычных автоматических копий при последующем сканировании продолжает работать прежний 72-часовой период защиты. Из недоступного источника новые копии не создаются; при изменении цели запуска прежняя копия не защищается.
- Регрессионные сценарии проверяют реальные Windows-ярлыки, SQLite, предварительный просмотр, применение и явный отказ от закрепления, а также сохранение пути, позиции, байтов и идентичности файла. Это воспроизводимые искусственные сценарии, не замеры времени работы людей и не физическое испытание Windows 11.

Скачайте **DesktopPilot-0.2.12-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Сверьте архив по **SHA256SUMS.txt**. Программа работает локально без учётной записи, сетевой телеметрии и подписки. Исходные файлы, ручные решения, история, настройки и безопасный откат сохранены. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.12 corrects a misleading removal preview after a backward system-clock correction while the original shortcut is unavailable.

- A saved future outage timestamp no longer makes Settings propose removing an already managed quick copy. The preview agrees with the protective filesystem refresh performed before changes are applied.
- **Always**, manually moved shortcuts and explicit **Never add** remain authoritative. Automatically managed copies keep the existing temporary 72-hour grace once the next scan establishes the true outage time. A missing original never creates a new copy; changed launch identity remains a reason to release management.
- Regression cases exercise real local SQLite/Store, Windows .url shortcuts, preview, apply and manual rule changes, preserving file identity, position, path and bytes. These are deterministic fixtures, not measured improvements in human task time or physical Windows 11 tests.

Download **DesktopPilot-0.2.12-windows-x64.zip**, extract and run `desktop-pilot.exe`. Verify the archives using **SHA256SUMS.txt**. Original files, local-only data, personal choices, settings, history and safe Undo remain intact. No account, subscription or hidden telemetry is introduced. The executable is unsigned.
