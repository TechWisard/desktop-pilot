Desktop Pilot 0.2.11 восстанавливает корректный учёт работы и расписание автоматических пересмотров после значительного перевода системных часов назад.

## Что изменилось

- После коррекции времени подтверждённый новый сеанс больше не теряется из-за отметки последней работы, оставшейся в будущем. Короткие поправки часов по-прежнему не создают лишних сеансов.
- Если отметка последнего автоматического пересмотра оказалась больше чем на сутки в будущем, программе не нужно ждать этого ошибочного срока. Обязательные условия не обходятся: пользователь должен разрешить автоматические изменения, завершить обучение и оставить рабочий стол свободным для изменений.
- Повторный немедленный пересмотр не производится. Уже размещённые ярлыки с ручным выбором остаются на прежнем месте, а исходные файлы не меняются.

Проверки моделируют запуск после сдвига часов на два часа, сохранённый пересмотр на 14–21 день в будущем, короткие обращения к приложению, паузы, ручное закрепление и разрешение/запрет автоматических изменений. Проверяются реальные пути учёта, SQLite и управления ярлыками; это не испытания на физическом Windows 11 ПК и не измерение времени пользователей.

Скачайте **DesktopPilot-0.2.11-windows-x64.zip**, распакуйте и запустите `desktop-pilot.exe`. Для сверки архивов используйте **SHA256SUMS.txt**. Программа работает локально, без скрытой телеметрии и учётной записи. Существующие настройки, история, исходные файлы и механизм отката сохраняются. Исполняемый файл не подписан цифровой подписью.

## English

Desktop Pilot 0.2.11 restores trustworthy usage sessions and automatic-review scheduling after a large backward system-clock correction.

- A confirmed new session is no longer lost because an old activity timestamp now appears in the future. Small clock adjustments still cannot inflate session counts.
- A review checkpoint more than 24 hours in the future can recover without waiting weeks. The app still requires your automatic-review opt-in, completed learning, and a quiet desktop.
- An immediate duplicate review is blocked. Existing manual shortcut choices remain in place; original shortcut files are preserved.

Regression fixtures exercise real activity recording, SQLite and shortcut-management logic after simulated two-hour and multiweek timestamp corrections, including user opt-out and manually selected shortcuts. They are not physical Windows 11 clock-change tests or measured human time savings.

Download **DesktopPilot-0.2.11-windows-x64.zip**, extract and run `desktop-pilot.exe`; compare the archives with **SHA256SUMS.txt**. Existing settings, usage history, original files, safe Undo and entirely local operation are retained. No hidden telemetry, online account or new service is introduced. The executable is unsigned.
