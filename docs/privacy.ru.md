# Приватность

[English](privacy.md) · [Главная](../README.ru.md)

У Desktop Pilot нет телеметрии, учётных записей, синхронизации и собственных сетевых запросов. Запуск исходного ярлыка, разумеется, может открыть приложение, использующее сеть.

Данные хранятся в `%LOCALAPPDATA%\DesktopPilot`:

| Данные | Назначение и хранение |
| --- | --- |
| Имена приложений, пути, аргументы, рабочие каталоги и признаки закрепления | Идентификация и запуск; остаются в каталоге |
| Дневные запуски, сеансы и активные секунды | Рейтинг; строки старше 90 дней удаляются при обслуживании |
| Правила, настройки, пути и позиции быстрых ярлыков | Сохранение решений пользователя и размещения |
| Прогресс обучения, число сеансов, время последней активности и дневные активные секунды | Порог пассивного наблюдения; до 90 дневных итогов, без последовательности событий окон/приложений |
| События операций | При обслуживании остаются последние 2000; в окне показываются последние 100 |
| Результаты команд, журнал операций и резервные байты ярлыков | Диагностика и откат; сохраняются до удаления локальных данных |
| Текст последней ошибки | Диагностика; заменяется следующей ошибкой |

Читаются идентификатор активного процесса и время бездействия Windows. Обработчики ввода Windows проверяют только тип события и признак программного внедрения. В оперативной памяти находится последняя метка времени подходящего взаимодействия, порядковый номер и дескриптор окна. Коды клавиш, текст, номера кнопок и координаты курсора не сохраняются; координаты временно используются лишь для определения получателя события мыши. При выключенном сборе новые метаданные взаимодействий не сохраняются. Не записываются клавиши, заголовки окон, содержимое документов, история браузера, звук или изображение экрана. Явная диагностическая команда `--ui-smoke` сохраняет изображения собственного окна настроек в указанную папку; при обычной работе она не вызывается.

Отключение **Собирать статистику** прекращает новые наблюдения. **Очистить статистику** удаляет дневные счётчики и начальные приоритеты, сохраняя ярлыки, правила и журнал отката. Незавершённое первоначальное наблюдение начинается с нуля; завершённое остаётся завершённым. Пауза автоматических изменений сама по себе не останавливает наблюдение. Выход из трея останавливает оба режима до следующего запуска; автозапуск Windows отключается отдельно.

Локальная база не зашифрована. Она и журнал могут содержать личные пути и аргументы приложений. Используйте защиту своей учётной записи Windows и не прикладывайте эти файлы к публичным сообщениям. Снимки публичной документации используют вымышленные данные. В релизе нет базы использования, личного списка ярлыков, снимков рабочего стола или резервных копий пользователя.
