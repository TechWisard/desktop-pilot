# Desktop Pilot

**Умные ярлыки для Windows: нужные приложения рядом, привычный порядок сохранён.**

Desktop Pilot — локальный органайзер рабочего стола и менеджер ярлыков Windows. Программа изучает использование приложений и поддерживает небольшую, стабильную группу ярлыков быстрого доступа. Исходные ярлыки, тематические папки и выбранные вручную позиции остаются под вашим контролем.

![Обзор Desktop Pilot на вымышленных демонстрационных данных](docs/images/overview-ru.png)

*На снимке используются вымышленные демонстрационные данные.*

## Начало работы

1. Скачайте и распакуйте **DesktopPilot-0.1.0-windows-x64.zip** на странице [релизов](https://github.com/TechWisard/desktop-pilot/releases/latest).
2. Запустите `desktop-pilot.exe`. Выберите **Русский** или **English**, проверьте область размещения и автозапуск, затем нажмите **Начать работу**.
3. Пользуйтесь компьютером как обычно. Автоматический выбор появится после трёх разных дней использования. Для немедленного добавления выберите **Всегда на столе** на вкладке «Приложения» и нажмите **Применить сейчас**.

Программа устанавливается для текущего пользователя в `%LOCALAPPDATA%\DesktopPilot`, без прав администратора. Настройки доступны через значок в трее и меню «Пуск». Предварительная сборка не имеет цифровой подписи; скачивайте её со страницы релизов этого репозитория и проверяйте опубликованную сумму SHA-256.

## Рабочий стол без постоянных перестановок

| Параметр | После первоначальной настройки |
| --- | --- |
| Область быстрого доступа | 4 ярлыка в свободной области основного монитора |
| Пересмотр | Раз в 7 дней, во время бездействия и вне полноэкранных приложений |
| Обычные замены | Не более 1 за пересмотр |
| Минимум наблюдений | 3 разных дня использования |
| Порог замены | Преимущество в 1,5 раза **и** минимум на 3 балла |
| Давность | Вес уменьшается вдвое за 14 дней; статистика хранится 90 дней |
| Панель задач | Закреплённые приложения исключаются, кроме ручного выбора |
| Ручное управление | Всегда / Автоматически / Не добавлять; перемещённые быстрые ярлыки закрепляются |

Первоначальное заполнение и явные изменения правил могут затронуть несколько ярлыков. Удалённый вручную быстрый ярлык не возвращается автоматически. Изменённые пользователем файлы выходят из-под управления. Все изменения имеют журнал и **Откат**; откат не перезаписывает изменённые файлы.

## Удобство важнее одного счётчика

Учитываются разные дни активности, сеансы работы, давность, явные запуски быстрых ярлыков, закрепления панели задач и ручные правила. Для программы, которую вы открываете через документ, контекстное меню или горячую клавишу, выбирайте **Не добавлять**. По активности процесса нельзя надёжно угадать такое предпочтение.

Каталог собирается из папок с ярлыками на рабочем столе до трёх уровней вложенности. Другие `.lnk` и `.url` можно добавить в настройках; все установленные программы автоматически не добавляются. Неоднозначные профили одного EXE не объединяются. Игры Steam и приложения Windows сопоставляются по отдельным каталогам или идентификаторам, когда соответствие однозначно.

## Данные остаются на компьютере

Без учётной записи, аналитики, облачной синхронизации и сетевого сервиса. Локально хранятся пути приложений, дневные счётчики, настройки и данные отката. Программа не читает клавиши, заголовки окон, содержимое документов или историю браузера. **Не публикуйте свою базу данных и папку отката.** [Подробности](docs/privacy.ru.md)

## Совместимость и проверки

Версия **0.1.0 — предварительная**, предназначена для Windows 10/11 x64 со стандартным рабочим столом Проводника. Реальная работа проверена на Windows 11. Автоматические тесты геометрии охватывают 100 сочетаний разрешения, масштаба и начала координат, а также пустой, занятый и слишком маленький рабочий стол. Это не заменяет испытания на физических многомониторных системах.

Для размещения нужно отключить автоупорядочивание Проводника. При изменении геометрии размещение приостанавливается до её подтверждения. Неизвестный формат закреплений панели задач останавливает изменения; фильтр можно явно отключить. Альтернативные оболочки и менеджеры виртуальных рабочих столов не проверены. [Границы проверки](docs/verification.ru.md)

## Сборка

Установите Rust **1.93.1** с MSVC и Visual Studio C++ Build Tools:

```powershell
pwsh -File scripts/build-release.ps1
```

Скрипт проверяет форматирование, тесты и Clippy, затем собирает `target/release/desktop-pilot.exe` с заменой локальных путей сборки. Программа написана на **Rust**: egui/eframe, SQLite и Windows Shell API. [Устройство, использование и отключение](docs/guide.ru.md)
